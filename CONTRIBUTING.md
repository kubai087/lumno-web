# Contributing to lumno-web

Thanks for helping with the Lumno website. Issues and pull requests in Chinese or English are both welcome.

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).

## Where things go

- **The website** (pages, layout, animations, translations, help center text, performance, accessibility): this repository.
- **The extension** (bugs, features, its own settings and onboarding): [lumno-extension](https://github.com/kubai087/lumno-extension/issues).
- **Security issues**: never in a public issue. See [SECURITY.md](SECURITY.md).

For anything larger than a fix, open an issue first so we can agree on the direction before you spend time on it. The project is maintained as described in the extension's [GOVERNANCE.md](https://github.com/kubai087/lumno-extension/blob/main/GOVERNANCE.md).

## Setup

```bash
npm ci
npm run dev
```

Node.js 22.12 or later. No `.env` is needed; see [`.env.example`](.env.example) for optional features.

## Before opening a pull request

```bash
npm run check   # types
npm run build   # tests, build and help search evaluation
```

Both must pass; CI runs the same commands. For visual changes, attach before and after screenshots at desktop and phone widths, and check Safari if you touched SVG, filters or transforms.

## Conventions

[AGENTS.md](AGENTS.md) holds the project's working notes, written for people and coding agents alike. The ones that most often matter:

- **Copy.** Simplified Chinese is the source text. Traditional Chinese should read naturally rather than be machine-converted, and English should read like product copy rather than a literal translation. If you change visible text, change it in every language or say in the pull request which ones still need it.
- **Locales.** Every page ships in all ten languages. Above-the-fold text, `aria-label`, `alt` and other helper text are rendered in the page's language in the static HTML.
- **SEO.** UI strings and `<title>`/`<meta>` text use separate keys. Keep the existing routes stable; add a redirect in `astro.config.mjs` when you move a page.
- **Performance.** Don't add a `client:load` island for something the first paint doesn't need; prefer `client:idle` or `client:visible`. `/release/` and `/privacy/` ship no React.
- **Motion.** Server HTML must be a complete, readable frame. Respect `prefers-reduced-motion`.
- **Help center.** When you rename or add a section, update its search aliases in `src/content/guides/search/`. When you fix a search miss, add a case to `src/content/guides/search/eval/`.
- **Fonts and icons.** After using a new `ri-*` icon class, rerun `scripts/subset-fonts.py`.
- **Commits.** One change per commit, with a short imperative subject that says what the change does for the reader of the site, for example "Keep the footer's painted sea below the text".
