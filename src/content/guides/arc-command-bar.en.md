Since Arc stopped getting new features, plenty of people have moved to Chrome, Dia or Edge, and the command bar is usually what they miss most. Lumno's design takes its cue from Arc. Install it and the command bar is back.

Lumno is an independent open-source project, not affiliated with Arc or The Browser Company.

## What you're used to, and where it lives now {#mapping}

| In Arc | In Lumno |
| --- | --- |
| `⌘ T` opens the command bar | `⌘ ⇧ K` opens the command bar, or set it to `⌘ T` |
| Switch to an open tab from the command bar | Results marked "Opened"; press Return to switch |
| `⌃ Tab` switches recent tabs | `⌥ Q` opens the recent tab switcher |
| `⌘ ⇧ C` copies the URL | Give "Copy Current Page URL" a shortcut on the extensions page |
| New tab | Lumno's new tab (not available in Dia yet) |

## Four steps to move over {#steps}

1. [Install Lumno](../install/): from the Chrome Web Store for Chrome and Dia, from Edge Add-ons for Edge.
2. Open `chrome://extensions/shortcuts` and set "Open command bar" to `⌘ T`. See [Keyboard shortcuts](../keyboard-shortcuts/#change).
3. Press `⌘ T` and try [searching your tabs, bookmarks and history](../search-tabs-bookmarks-history/).
4. To bounce between your last few pages, press `⌥ Q` for the [recent tab switcher](../tab-switcher/).

If the shortcut does nothing in Dia, change its scope from "In Dia" to "Global" on the extensions page.

## What Arc has that Lumno doesn't {#limits}

A sidebar, Spaces and split view need the browser itself; an extension can't add them. If you can't live without them, try [Zen Browser](https://zen-browser.app/), a Firefox-based browser that feels a lot like Arc, or [Vivaldi](https://vivaldi.com/), which also has a sidebar, workspaces and split view. More in [What Lumno can't do](../limitations/).
