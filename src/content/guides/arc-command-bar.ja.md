Arc の新機能の開発が止まってから、多くのユーザーが Chrome、Dia、Edge に移行しました。その際にいちばん惜しまれるのは、たいていコマンドバーです。Lumno の操作は Arc を参考にしているため、これらのブラウザでも使い慣れたコマンドバーを使用できます。

Lumno は独立したオープンソースプロジェクトであり、Arc および The Browser Company とは一切関係ありません。

## Arc と Lumno の操作対応表 {#mapping}

| Arc | Lumno |
| --- | --- |
| `⌘ T` でコマンドバーを開く | `⌘ ⇧ K` でコマンドバーを開く（`⌘ T` に変更可能） |
| コマンドバーから開いているタブに切り替える | 「開いている」と表示された結果を選択して Enter キーを押す |
| `⌃ Tab` で最近のタブを切り替える | `⌥ Q` で最近のタブ切り替えを開く |
| `⌘ ⇧ C` で URL をコピーする | 拡張機能のショートカット設定で「現在のページURLをコピー」にショートカットを割り当てる |
| 新しいタブ | Lumno の新しいタブ（Dia では未対応） |

## 移行の手順 {#steps}

1. [Lumno をインストール](../install/)します。Chrome と Dia では Chrome ウェブストアから、Edge では Edge アドオンからインストールします。
2. `chrome://extensions/shortcuts` を開き、「Lumnoを開く」を `⌘ T` に変更します。詳しくは、[キーボードショートカット](../keyboard-shortcuts/#change)を参照してください。
3. `⌘ T` を押して、[タブ・ブックマーク・履歴の検索](../search-tabs-bookmarks-history/)を試します。
4. 直前の数ページを行き来するときは、`⌥ Q` を押して[最近のタブ切り替え](../tab-switcher/)を開きます。

Dia でショートカットキーが反応しない場合は、拡張機能のショートカット設定ページで範囲を「Dia 内」から「グローバル」に変更してください。

## Lumno では提供できない Arc の機能 {#limits}

サイドバー、Spaces、分割表示はブラウザ本体の機能であり、拡張機能では追加できません。これらの機能が必要な場合は、Arc によく似た Firefox ベースのブラウザ [Zen Browser](https://zen-browser.app/) や、サイドバー、ワークスペース、分割表示を備えた [Vivaldi](https://vivaldi.com/) を検討してください。詳しくは、[Lumno にできないこと](../limitations/)を参照してください。
