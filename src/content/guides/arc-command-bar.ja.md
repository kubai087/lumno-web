Arc の新機能開発が止まってから、多くの人が Chrome や Dia、Edge に移りました。いちばん恋しくなるのは、たいていコマンドバーです。Lumno のデザインは Arc を参考にしています。インストールすれば、あのコマンドバーが戻ってきます。

Lumno は独立したオープンソースプロジェクトで、Arc や The Browser Company とは関係ありません。

## 慣れた操作は、ここにあります {#mapping}

| Arc では | Lumno では |
| --- | --- |
| `⌘ T` でコマンドバー | `⌘ ⇧ K` でコマンドバー。`⌘ T` にも変更できます |
| コマンドバーから開いているタブに切り替え | 「開いている」の結果で Enter |
| `⌃ Tab` で最近のタブを切り替え | `⌥ Q` で最近のタブ切り替え |
| `⌘ ⇧ C` で URL をコピー | 拡張機能のショートカット設定で「現在のページURLをコピー」に割り当て |
| 新しいタブ | Lumno の新しいタブ（Dia ではまだ使えません） |

## 乗り換えは 4 ステップ {#steps}

1. [Lumno をインストール](../install/)します。Chrome と Dia は Chrome ウェブストア、Edge は Edge アドオンから。
2. `chrome://extensions/shortcuts` を開き、「Lumnoを開く」を `⌘ T` にします。[キーボードショートカット](../keyboard-shortcuts/#change)をご覧ください。
3. `⌘ T` を押して、[タブ・ブックマーク・履歴の検索](../search-tabs-bookmarks-history/)を試します。
4. 直前の数ページを行き来するなら、`⌥ Q` で[最近のタブ切り替え](../tab-switcher/)を。

Dia でショートカットが反応しないときは、拡張機能のショートカット設定で範囲を「Dia 内」から「グローバル」に変えてください。

## Arc にあって Lumno にないもの {#limits}

サイドバー、Spaces、分割表示はブラウザ自体の機能で、拡張機能では追加できません。手放せないなら、Arc によく似た Firefox ベースのブラウザ [Zen Browser](https://zen-browser.app/) や、サイドバー・ワークスペース・分割表示を備えた [Vivaldi](https://vivaldi.com/) を試してみてください。詳しくは [Lumno にできないこと](../limitations/)へ。
