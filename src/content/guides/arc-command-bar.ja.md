[Arc](https://arc.net/) は 2026年12月22日に提供を終了し、それ以降は Mac 版と Windows 版の Arc を開けなくなります。Arc を離れる前にデータを移し、新しいブラウザを選びましょう。Lumno は、コマンドバー、最近のタブの切り替え、再起動後の固定タブの復元、動画の自動ピクチャー・イン・ピクチャーなど、Arc の操作を参考にしており、Chrome、Dia、Edge にインストールすれば引き続き使えます。

Lumno は独立したオープンソースプロジェクトであり、Arc および The Browser Company とは一切関係ありません。

## Arc の提供終了スケジュール {#timeline}

- **10月22日**：Arc の提供終了が発表され、新しい Arc アカウントを作成できなくなりました。
- **11月23日**：iOS 版と Android 版の Arc Search で AI 機能が終了し、サインインと同期もできなくなります。通常のブラウザとしては引き続き使えます。
- **12月15日**：Arc アカウントの個人データの写しや削除を申請できる最終日です。
- **12月22日**：Mac 版と Windows 版の Arc が動作しなくなり、すべてのアカウントが無効になります。アカウントに関連する個人データは 30 日以内に削除されます。

提供終了後は、このコンピュータに保存された Arc のデータも開けなくなります。詳しくは Arc 公式の [Arc Sunset: Key Dates and What to Expect](https://resources.arc.net/hc/en-us/articles/44412972248471) を参照してください。

## 12月22日までにデータを書き出す {#export}

- **Dia に移る場合**：書き出しは不要です。Dia をインストールして Arc からの読み込みを選ぶと、Spaces、固定タブ、フォルダ、ブックマーク、履歴、パスワード、拡張機能がそのまま移り、Spaces は Dia の Profiles になります。読み込みが終わるまで Arc はアンインストールしないでください。詳しくは [Move from Arc to Dia](https://resources.arc.net/hc/en-us/articles/44413129117591) を参照してください。
- **ほかのブラウザに移る場合**：Arc の設定で「Advanced」を開き、「Export Data」を選びます。Arc は `Arc Data Export.md` というファイルを保存し、お気に入り、固定タブ、フォルダ内のリンクを Space ごとに一覧にします。ブックマークファイルではなくリンクの一覧なので、新しいブラウザで必要なリンクを開くかブックマークに追加してください。詳しくは [How Do I Export My Data from Arc?](https://resources.arc.net/hc/en-us/articles/25583851606039) を参照してください。

Easel と Boost は書き出せず、Dia にも移りません。

## Arc で Lumno を使っていた場合は設定を持ち出す {#lumno-settings}

Lumno の設定はインストールしたブラウザの中に保存されるため、Arc が使えなくなると取り出せません。ブラウザを移る前に Lumno の設定画面で[エクスポート](../sync/#export)を行い、新しいブラウザに Lumno をインストールしてからインポートしてください。[WebDAV 同期](../sync/)をオンにすれば、アイコンや壁紙も一緒に移せます。

Dia に移るときに拡張機能も読み込まれますが、念のため先にエクスポートしておくことをおすすめします。

## 次のブラウザを選ぶ {#choose}

| ブラウザ | Arc と似ている点 | Lumno との組み合わせ |
| --- | --- | --- |
| Dia | 同じチームが開発。サイドバー、固定タブ、タブスイッチャーがあり、Arc から直接読み込める | コマンドバーは使えます。新しいタブは未対応 |
| Chrome、Edge | サイドバーや Spaces はないが、拡張機能がもっとも充実 | すべての機能が使えます |
| [Zen Browser](https://zen-browser.app/) | Firefox ベースで、サイドバー、ワークスペース、分割表示があり、Arc によく似ている | Firefox アドオンからインストール。一部の機能は使えません |
| [Vivaldi](https://vivaldi.com/) | サイドバー、ワークスペース、分割表示がある | すべての機能が使えます |

ブラウザごとの対応状況は[ブラウザ互換性](../browser-compatibility/)を参照してください。

## Arc と Lumno の操作対応表 {#mapping}

| Arc | Lumno |
| --- | --- |
| `⌘ T` でコマンドバーを開く | `⌘ ⇧ K` でコマンドバーを開く（`⌘ T` に変更可能） |
| コマンドバーから開いているタブに切り替える | 「開いている」と表示された結果を選択して Enter キーを押す |
| `⌃ Tab` で最近のタブを切り替える | `⌥ Q` で最近のタブ切り替えを開く |
| `⌘ ⇧ C` で URL をコピーする | 拡張機能のショートカット設定で「現在のページURLをコピー」にショートカットを割り当てる |
| 再起動後も固定タブを残す | Lumno の設定で「再起動後に固定タブを復元」をオンにする |
| タブを切り替えると動画がピクチャー・イン・ピクチャーになる | [動画の自動ピクチャー・イン・ピクチャー](../auto-pip/)（初期設定でオン） |
| 新しいタブ | Lumno の新しいタブ（Dia では未対応） |

## 移行の手順 {#steps}

1. [Lumno をインストール](../install/)します。Chrome と Dia では Chrome ウェブストアから、Edge では Edge アドオンからインストールします。
2. `chrome://extensions/shortcuts` を開き、「Lumnoを開く」を Arc や [Zen](https://zen-browser.app/) と同じ `⌘ T` に変更します。詳しくは、[キーボードショートカット](../keyboard-shortcuts/#change)を参照してください。Dia では、先に `⌘ T` を空けてください（下記参照）。
3. `⌘ T` を押して、[タブ・ブックマーク・履歴の検索](../search-tabs-bookmarks-history/)を試します。
4. 直前の数ページを行き来するときは、`⌥ Q` を押して[最近のタブ切り替え](../tab-switcher/)を開きます。

Dia 自体のショートカットが優先されるため、Dia では先に Settings → Shortcuts を開き、「New Tab」の `⌘ T` を別のキーに変更してください。詳しくは、[ブラウザ互換性](../browser-compatibility/#dia)を参照してください。Dia でショートカットキーが反応しない場合は、拡張機能のショートカット設定ページで範囲を「In Dia」から「Global」に変更してください。

## Lumno では提供できない Arc の機能 {#limits}

サイドバー、Spaces、分割表示はブラウザ本体の機能であり、拡張機能では追加できません。これらの機能が必要な場合は、上の表の Dia、Zen、Vivaldi から選んでください。詳しくは、[Lumno にできないこと](../limitations/)を参照してください。
