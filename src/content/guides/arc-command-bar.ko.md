Arc에 새 기능이 더 이상 나오지 않으면서 많은 사람이 Chrome, Dia, Edge로 옮겼고, 대개 가장 아쉬워하는 게 명령 바예요. Lumno는 Arc에서 디자인의 실마리를 얻었어요. 설치하면 명령 바가 돌아옵니다.

Lumno는 독립 오픈소스 프로젝트이며, Arc나 The Browser Company와는 관련이 없어요.

## 익숙한 기능, 이제는 여기에 {#mapping}

| Arc에서는 | Lumno에서는 |
| --- | --- |
| `⌘ T`로 명령 바 열기 | `⌘ ⇧ K`로 명령 바 열기, 또는 `⌘ T`로 설정 |
| 명령 바에서 열린 탭으로 전환 | "Opened" 표시가 있는 결과에서 Return으로 전환 |
| `⌃ Tab`으로 최근 탭 전환 | `⌥ Q`로 최근 탭 전환기 열기 |
| `⌘ ⇧ C`로 URL 복사 | 확장 프로그램 페이지에서 "Copy Current Page URL"에 단축키 지정 |
| 새 탭 | Lumno 새 탭(Dia에서는 아직 지원하지 않음) |

## 네 단계로 옮기기 {#steps}

1. [Lumno를 설치하세요](../install/). Chrome과 Dia는 Chrome 웹 스토어에서, Edge는 Edge 추가 기능에서 설치해요.
2. `chrome://extensions/shortcuts`를 열고 "Open command bar"를 `⌘ T`로 바꾸세요. [단축키](../keyboard-shortcuts/#change)를 참고하세요.
3. `⌘ T`를 누르고 [탭, 북마크, 방문 기록 검색](../search-tabs-bookmarks-history/)을 써 보세요.
4. 방금 본 몇 페이지 사이를 오가려면 `⌥ Q`로 [최근 탭 전환기](../tab-switcher/)를 여세요.

Dia에서 단축키가 동작하지 않으면 확장 프로그램 페이지에서 범위를 "In Dia"에서 "Global"로 바꾸세요.

## Arc에는 있고 Lumno에는 없는 것 {#limits}

사이드바, Spaces, 화면 분할은 브라우저 자체가 지원해야 해서 확장 프로그램으로는 더할 수 없어요. 꼭 필요하다면 Arc와 느낌이 아주 비슷한 Firefox 기반 브라우저 [Zen Browser](https://zen-browser.app/)나, 사이드바·작업 공간·화면 분할을 갖춘 [Vivaldi](https://vivaldi.com/)를 써 보세요. 자세한 내용은 [Lumno가 못 하는 것](../limitations/)에 있어요.
