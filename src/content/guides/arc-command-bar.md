Arc 不再更新新功能后，不少人搬去了 Chrome、Dia 或 Edge，最舍不得的往往是那个命令栏。Lumno 的交互参考了 Arc，装上它，熟悉的命令栏就回来了。

Lumno 是独立的开源项目，和 Arc、The Browser Company 没有关系。

## 你熟悉的操作，在这里 {#mapping}

| 在 Arc 里 | 在 Lumno 里 |
| --- | --- |
| `⌘ T` 打开命令栏 | `⌘ ⇧ K` 唤出命令栏，也可以改成 `⌘ T` |
| 在命令栏里切到开着的标签页 | 结果标着「已打开」，回车切过去 |
| `⌃ Tab` 切换最近的标签页 | `⌥ Q` 打开最近标签页切换器 |
| `⌘ ⇧ C` 复制当前网址 | 在扩展快捷键页给「复制当前网页链接」配一个快捷键 |
| 新标签页 | Lumno 新标签页（Dia 里暂时用不了） |

## 四步搬过来 {#steps}

1. [安装 Lumno](../install/)：Chrome、Dia 从 Chrome 应用商店装，Edge 从 Edge 加载项装。
2. 打开 `chrome://extensions/shortcuts`，把「唤起聚焦搜索窗口」改成 `⌘ T`，见[快捷键](../keyboard-shortcuts/#change)。
3. 按 `⌘ T`，试试[搜索标签页、书签和历史记录](../search-tabs-bookmarks-history/)。
4. 在最近几个页面之间来回跳，用 `⌥ Q` 打开[最近标签页切换器](../tab-switcher/)。

在 Dia 里按快捷键没反应的话，到扩展快捷键页把范围从「在 Dia 中」改成「全局」。

## Arc 有、Lumno 没有的 {#limits}

侧边栏、Spaces 和分屏需要浏览器本身支持，扩展做不到。如果你离不开它们，可以试试 [Zen Browser](https://zen-browser.app/)，它是基于 Firefox、和 Arc 很像的浏览器；或者 [Vivaldi](https://vivaldi.com/)，也有侧边栏、工作区和分屏。更多说明见 [Lumno 做不到的事](../limitations/)。
