Desde que o Arc parou de ganhar recursos novos, muita gente foi para o Chrome, o Dia ou o Edge, e o que mais costuma fazer falta é a barra de comandos. O design do Lumno se inspira no Arc. Instale e a barra de comandos está de volta.

O Lumno é um projeto independente de código aberto, sem vínculo com o Arc nem com a The Browser Company.

## O que você já conhece, e onde está agora {#mapping}

| No Arc | No Lumno |
| --- | --- |
| `⌘ T` abre a barra de comandos | `⌘ ⇧ K` abre a barra de comandos, ou mude para `⌘ T` |
| Ir para uma guia aberta pela barra | Resultados marcados como "Opened"; aperte Enter para ir até ela |
| `⌃ Tab` alterna entre guias recentes | `⌥ Q` abre o alternador de guias recentes |
| `⌘ ⇧ C` copia a URL | Dê um atalho a "Copy Current Page URL" na página de extensões |
| Nova guia | A nova guia do Lumno (ainda não disponível no Dia) |

## Quatro passos para mudar {#steps}

1. [Instale o Lumno](../install/): pela Chrome Web Store para Chrome e Dia, pelos Complementos do Edge para o Edge.
2. Abra `chrome://extensions/shortcuts` e mude "Open command bar" para `⌘ T`. Veja [Atalhos de teclado](../keyboard-shortcuts/#change).
3. Aperte `⌘ T` e experimente [pesquisar suas guias, favoritos e histórico](../search-tabs-bookmarks-history/).
4. Para pular entre as últimas páginas, aperte `⌥ Q` e abra o [alternador de guias recentes](../tab-switcher/).

Se o atalho não fizer nada no Dia, mude o escopo dele de "In Dia" para "Global" na página de extensões.

## O que o Arc tem e o Lumno não {#limits}

Barra lateral, Spaces e tela dividida dependem do próprio navegador; uma extensão não consegue adicioná-los. Se você não vive sem eles, experimente o [Zen Browser](https://zen-browser.app/), um navegador baseado no Firefox muito parecido com o Arc, ou o [Vivaldi](https://vivaldi.com/), que também tem barra lateral, espaços de trabalho e tela dividida. Mais em [O que o Lumno não faz](../limitations/).
