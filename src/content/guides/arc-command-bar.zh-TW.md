Arc 不再加入新功能後，不少人搬到 Chrome、Dia 或 Edge，最捨不得的往往是那個命令列。Lumno 的互動參考了 Arc，裝上它，熟悉的命令列就回來了。

Lumno 是獨立的開源專案，和 Arc、The Browser Company 沒有關係。

## 你熟悉的操作，在這裡 {#mapping}

| 在 Arc 裡 | 在 Lumno 裡 |
| --- | --- |
| `⌘ T` 開啟命令列 | `⌘ ⇧ K` 叫出命令列，也可以改成 `⌘ T` |
| 在命令列裡切到開著的分頁 | 結果標著「已開啟」，按 Enter 切過去 |
| `⌃ Tab` 切換最近的分頁 | `⌥ Q` 開啟最近分頁切換器 |
| `⌘ ⇧ C` 複製目前網址 | 在擴充功能快速鍵頁幫「複製目前網頁連結」設一組快速鍵 |
| 新分頁 | Lumno 新分頁（Dia 裡暫時無法使用） |

## 四步搬過來 {#steps}

1. [安裝 Lumno](../install/)：Chrome、Dia 從 Chrome 線上應用程式商店安裝，Edge 從 Edge 附加元件安裝。
2. 開啟 `chrome://extensions/shortcuts`，把「叫出聚焦搜尋視窗」改成 `⌘ T`，見[快速鍵](../keyboard-shortcuts/#change)。
3. 按 `⌘ T`，試試[搜尋分頁、書籤和瀏覽紀錄](../search-tabs-bookmarks-history/)。
4. 在最近幾個頁面之間來回跳，用 `⌥ Q` 開啟[最近分頁切換器](../tab-switcher/)。

在 Dia 裡按快速鍵沒反應的話，到擴充功能快速鍵頁把範圍從「在 Dia 中」改成「全域」。

## Arc 有、Lumno 沒有的 {#limits}

側邊欄、Spaces 和分割畫面需要瀏覽器本身支援，擴充功能做不到。如果你離不開它們，可以試試 [Zen Browser](https://zen-browser.app/)，它是以 Firefox 為基礎、和 Arc 很像的瀏覽器；或是 [Vivaldi](https://vivaldi.com/)，也有側邊欄、工作區和分割畫面。更多說明見 [Lumno 做不到的事](../limitations/)。
