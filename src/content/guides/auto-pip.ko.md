웹 페이지에서 동영상을 재생하다가 다른 탭으로 이동하면, 재생 중인 동영상이 자동으로 작은 PIP 창으로 옮겨져 계속 재생됩니다. 원래 탭으로 돌아오면 작은 창이 닫히고 동영상이 페이지에서 이어서 재생됩니다. [Arc](https://arc.net/) 브라우저의 자동 PIP와 비슷한 기능입니다.

## 자동으로 PIP가 시작되는 조건 {#when}

다른 탭으로 이동할 때 다음 조건을 만족하는 동영상이 PIP로 재생됩니다.

- 동영상이 재생 중이며 일시 정지되거나 끝나지 않았습니다.
- 해당 페이지에서 재생 버튼을 클릭하는 등 직접 조작한 적이 있습니다.
- 동영상이 페이지에서 충분히 크게 표시됩니다. 작은 미리보기나 움직이는 썸네일은 대상이 아닙니다.

페이지에 동영상이 여러 개 있으면 화면이 더 크고 소리가 있는 동영상을 우선합니다.

## 원래 탭으로 돌아오면 {#return}

동영상이 있는 탭으로 돌아오면 PIP 창이 닫히고 동영상이 페이지에서 계속 재생됩니다. 작은 창에서 동영상을 일시 정지했다면 돌아온 후에도 일시 정지 상태가 유지됩니다.

## 자동으로 PIP가 시작되지 않는 경우 {#excluded}

- 쇼핑 사이트와 피드형 사이트에서는 동영상이 자동으로 재생되는 경우가 많습니다. 방해가 되지 않도록 Lumno는 JD, Taobao, X(Twitter), Weibo에서는 PIP를 자동으로 시작하지 않습니다.
- 사이트 정책으로 PIP가 비활성화된 경우에는 브라우저가 PIP를 허용하지 않습니다.
- [웹 클립](../web-clip/) 창이 열려 있는 동안에는 동영상 PIP가 자동으로 시작되지 않습니다.

## Helium 등의 브라우저에서 반응이 없는 경우 {#site-permission}

직접 허용하지 않으면 브라우저는 동영상을 자주 보는 사이트에서만 PIP를 자동으로 시작합니다. Chrome에는 자주 쓰이는 동영상 사이트 목록이 들어 있어 설치 직후부터 YouTube 등에서 사용할 수 있습니다. Helium, ungoogled-chromium 등의 브라우저는 이 목록을 제거했기 때문에, 새로 설치한 상태에서는 해당 사이트에서 한동안 동영상을 본 뒤에야 작동합니다.

바로 사용하려면 사이트를 직접 허용하세요.

1. 동영상 사이트를 열고 주소 표시줄 왼쪽의 사이트 정보 아이콘을 클릭한 다음 "사이트 설정"을 선택합니다.
2. "자동 PIP 모드"를 찾아 "허용"으로 바꿉니다.
3. 동영상 페이지로 돌아가 동영상을 재생한 다음 다른 탭으로 전환합니다.

사용하려는 동영상 사이트마다 한 번씩 설정해야 합니다. Chrome에서도 탭을 전환해도 반응하지 않는 사이트가 있으면 같은 방법으로 설정할 수 있습니다.

## 켜기 또는 끄기 {#toggle}

이 기능은 기본적으로 켜져 있습니다. 필요하지 않다면 Lumno 설정에서 "Auto Picture-in-Picture"를 끄세요.

Firefox는 확장 프로그램이 웹 동영상을 자동으로 PIP로 재생하는 것을 허용하지 않으므로, Firefox 버전에서는 이 기능을 제공하지 않습니다.
