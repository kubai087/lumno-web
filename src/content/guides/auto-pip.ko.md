웹 페이지에서 동영상을 재생하다가 다른 탭으로 이동하면, 재생 중인 동영상이 자동으로 작은 PIP 창으로 옮겨져 계속 재생됩니다. 원래 탭으로 돌아오면 작은 창이 닫히고 동영상이 페이지에서 이어서 재생됩니다. Arc 브라우저의 자동 PIP와 비슷한 기능입니다.

## 자동으로 PIP가 시작되는 조건 {#when}

다른 탭으로 이동할 때 다음 조건을 만족하는 동영상이 PIP로 재생됩니다.

- 동영상이 재생 중이며 일시 정지되거나 끝나지 않았습니다.
- 해당 페이지에서 재생 버튼을 클릭하는 등 직접 조작한 적이 있습니다.
- 동영상이 페이지에서 충분히 크게 표시됩니다. 작은 미리보기나 움직이는 썸네일은 대상이 아닙니다.

페이지에 동영상이 여러 개 있으면 화면이 더 크고 소리가 있는 동영상을 우선합니다.

## 원래 탭으로 돌아오면 {#return}

동영상이 있는 탭으로 돌아오면 PIP 창이 닫히고 동영상이 페이지에서 계속 재생됩니다. 작은 창에서 동영상을 일시 정지했다면 돌아온 후에도 일시 정지 상태가 유지됩니다.

## 자동으로 PIP가 시작되지 않는 경우 {#excluded}

- 쇼핑 사이트와 피드형 사이트에서는 동영상이 자동으로 재생되는 경우가 많습니다. 방해가 되지 않도록 Lumno는 JD, Taobao, X(Twitter), Weibo에서는 PIP를 자동으로 시작하지 않습니다.
- 사이트 정책으로 PIP가 비활성화된 경우에는 브라우저가 PIP를 허용하지 않습니다.
- [웹 클립](../what-is-lumno/#more) 창이 열려 있는 동안에는 동영상 PIP가 자동으로 시작되지 않습니다.

## 켜기 또는 끄기 {#toggle}

이 기능은 기본적으로 켜져 있습니다. 필요하지 않다면 Lumno 설정에서 "Auto Picture-in-Picture"를 끄세요.

Firefox는 확장 프로그램이 웹 동영상을 자동으로 PIP로 재생하는 것을 허용하지 않으므로, Firefox 버전에서는 이 기능을 제공하지 않습니다.
