Lumno は Chromium 系ブラウザ向けに開発されており、Firefox 版も提供しています。ブラウザごとに使用できる機能は次のとおりです。

## 対応状況 {#support}

| ブラウザ | コマンドバー | 新しいタブ | 入手先 |
| --- | --- | --- | --- |
| Google Chrome | 対応 | 対応 | Chrome ウェブストア |
| Microsoft Edge | 対応 | 対応 | Edge アドオン |
| Brave、Arc、Vivaldi、Opera | 対応 | 対応 | Chrome ウェブストア |
| Dia | 対応 | 未対応 | Chrome ウェブストア |
| Firefox、Zen など | 一部対応 | 対応 | 下記を参照 |
| Safari | 非対応 | 非対応 | — |

スマートフォンとタブレットのブラウザには、現在対応していません。

## Dia {#dia}

Dia では拡張機能が新しいタブを置き換えることができないため、Lumno の新しいタブは使用できません。コマンドバーは通常どおり使用できます。

ショートカットキーが反応しない場合は、拡張機能のショートカット設定ページを開き、Lumno の右側にある範囲を「Dia 内」から「グローバル」に変更してください。

## Firefox {#firefox}

Firefox 版は、まだ Firefox Add-ons に掲載されていません。掲載後は、このサイトからインストールできるようになります。Firefox 140 以降のほか、Zen、LibreWolf、Floorp などの Firefox ベースのブラウザに対応しています。

Firefox の拡張機能 API は Chromium と異なるため、次の機能は使用できません。

| 機能 | Firefox での状況 |
| --- | --- |
| 動画の自動ピクチャー・イン・ピクチャー | 使用できません。Firefox では、拡張機能がウェブ動画をピクチャー・イン・ピクチャーにすることが許可されていません |
| Webクリップ | 使用できません。Firefox はドキュメントのピクチャー・イン・ピクチャーに対応していません |
| `about:` ページとアドオンサイトでのコマンドバー | 使用できません |
| ショートカットやコマンドバーから `about:` ページを開く | 使用できません |
| ローカルの `file://` ページでのコマンドバー | 使用できません |
| サイトのアイコン | アクセスしたことのないサイトでは、最初に仮のアイコンが表示される場合があります |

Firefox 自体が `⌘ ⇧ K` を使用しているため、Firefox 版の初期設定は macOS では `⌃ ⇧ K`、Windows と Linux では `Alt + K` です。`Alt + Q` は変わりません。

## Safari {#safari}

Safari の拡張機能の仕組みは Chromium と大きく異なるため、Lumno の Safari 版は現在提供していません。Mac で同様のシステム全体の検索を使用したい場合は、[Raycast](https://www.raycast.com/) や [Alfred](https://www.alfredapp.com/) を検討してください。

## 表示言語 {#languages}

拡張機能は、日本語、英語、簡体字中国語、繁体字中国語に対応しています。初期設定ではブラウザの言語が使用され、設定で変更することもできます。
