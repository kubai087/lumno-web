Lumno は Chromium 系ブラウザ向けに開発されており、Firefox 版も提供しています。ブラウザごとに使用できる機能は次のとおりです。

## 対応状況 {#support}

| ブラウザ | コマンドバー | 新しいタブ | 入手先 |
| --- | --- | --- | --- |
| Google Chrome | 対応 | 対応 | Chrome ウェブストア |
| Microsoft Edge | 対応 | 対応 | Edge アドオン |
| Brave、[Arc](https://arc.net/)、Vivaldi、Opera | 対応 | 対応 | Chrome ウェブストア |
| Dia | 対応 | 未対応 | Chrome ウェブストア |
| Firefox、[Zen](https://zen-browser.app/) など | 一部対応 | 対応 | Firefox アドオン |
| Safari | 非対応 | 非対応 | — |

スマートフォンとタブレットのブラウザには、現在対応していません。スマートフォンでこのサイトを開いていて、Google アカウントにログインしている場合は、先にインストールをタップしておけます。あとで同じ Google アカウントでログインし、同期をオンにしたパソコンの Chrome を開くと、Lumno が自動的にインストールされます。

## Dia {#dia}

Dia では拡張機能が新しいタブを置き換えることができないため、Lumno の新しいタブは使用できません。コマンドバーは通常どおり使用できます。

`⌘ T` でコマンドバーを開くには、Dia 自体のショートカットが優先されるため、先に Dia で `⌘ T` を空ける必要があります。

1. Dia の Settings → Shortcuts を開き、「New Tab」のショートカットを `⌘ T` から別のキーに変更します。
2. `dia://extensions/shortcuts` を開き、Lumno の「Open command bar」を `⌘ T` に変更します。

![Dia の設定の Shortcuts ページ。「New Tab」を ⌘T から別のキーに変更済み](dia-newtab "手順 1：Dia の Settings → Shortcuts で「New Tab」を別のキーに変更")

![Dia の拡張機能のショートカットページ。Lumno の「Open command bar」が ⌘T](dia-shortcuts "手順 2：dia://extensions/shortcuts で「Open command bar」を ⌘T に設定")

ショートカットキーが反応しない場合は、拡張機能のショートカット設定ページを開き、Lumno の右側にある範囲を「In Dia」から「Global」に変更してください。

## Firefox {#firefox}

Firefox 版は [Firefox アドオン](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/)で公開しています。Firefox 140 以降のほか、Zen、LibreWolf、Floorp などの Firefox ベースのブラウザにも同じ方法でインストールできます。

Firefox の拡張機能 API は Chromium と異なるため、次の機能は使用できません。

| 機能 | Firefox での状況 |
| --- | --- |
| 動画の自動ピクチャー・イン・ピクチャー | 使用できません。Firefox では、拡張機能がウェブ動画をピクチャー・イン・ピクチャーにすることが許可されていません |
| Webクリップ | 使用できません。Firefox はドキュメントのピクチャー・イン・ピクチャーに対応していません |
| `about:` ページとアドオンサイトでのコマンドバー | 使用できません |
| ショートカットやコマンドバーから `about:` ページを開く | 使用できません |
| ローカルの `file://` ページでのコマンドバー | 使用できません |
| サイトのアイコン | アクセスしたことのないサイトでは、最初に仮のアイコンが表示される場合があります |
| 新しいタブのリキッドグラス | ガラスの質感のみで、ふちの屈折は表示されません |

Firefox 自体が `⌘ ⇧ K` を使用しているため、Firefox 版の初期設定は `⌃ ⇧ K | Alt + K` です。`⌥ Q` は変わりません。変更するには、`about:addons` を開き、右上の歯車ボタンから「拡張機能のショートカットキーの管理」を選びます。

## Safari {#safari}

Safari の拡張機能の仕組みは Chromium と大きく異なるため、Lumno の Safari 版は現在提供していません。Mac で同様のシステム全体の検索を使用したい場合は、[Raycast](https://www.raycast.com/) や [Alfred](https://www.alfredapp.com/) を検討してください。

## グラフィック アクセラレーション {#graphics-acceleration}

グラフィック アクセラレーションがオフになっていると、ブラウザはページを CPU で描画するため、スクロールやアニメーションがカクつきやすく、Lumno の壁紙エフェクトやガラスも重くなります。ブラウザがグラフィックカードで描画していないことを検出すると、Lumno は新しいタブの検索ボックスの下と、コマンドバーの上に「グラフィック アクセラレーションがオフです」と表示します。

![新しいタブの検索ボックスの下に表示された案内。グラフィック アクセラレーションがオフです、オンにするとページがより滑らかになります（ブラウザの再起動が必要です）と書かれ、右側に「オンにする」ボタンがある](graphics-notice "グラフィック アクセラレーションの案内")

1. 案内の「オンにする」をクリックすると、ブラウザのシステム設定（`chrome://settings/system`。Edge と Brave ではそれぞれの同じページ）が開きます。
2. 「グラフィック アクセラレーションが使用可能な場合は使用する」をオンにします。
3. 「再起動」をクリックします。ブラウザが再起動すると反映されます。

オンにしない場合は、案内の右側にある閉じるボタンをクリックすると、このパソコンでは再び表示されません。オンにして再起動したあとも案内が表示される場合は、グラフィック ドライバ、仮想マシン、リモート デスクトップなどが原因で、ブラウザがグラフィックカードを使えない可能性があります。`chrome://gpu` で詳細を確認できます。Firefox 版ではこの案内は表示されません。

## 表示言語 {#languages}

バージョン 1.2.0 から、拡張機能は 10 言語に対応しています：日本語、英語、簡体字中国語、繁体字中国語、韓国語、ドイツ語、スペイン語、フランス語、ポルトガル語（ブラジル）、ロシア語。初期設定ではブラウザの言語が使用され、設定で変更することもできます。
