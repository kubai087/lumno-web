Lumno создан для браузеров на Chromium, но есть и версия для Firefox. Вот что и где работает.

## Коротко {#support}

| Браузер | Командная строка | Новая вкладка | Где взять |
| --- | --- | --- | --- |
| Google Chrome | Да | Да | Интернет-магазин Chrome |
| Microsoft Edge | Да | Да | Надстройки Edge |
| Brave, Arc, Vivaldi, Opera | Да | Да | Интернет-магазин Chrome |
| Dia | Да | Пока нет | Интернет-магазин Chrome |
| Firefox, Zen и другие | Частично | Да | См. ниже |
| Safari | Нет | Нет | — |

Браузеры на телефонах и планшетах пока не поддерживаются.

## Dia {#dia}

Dia не позволяет расширениям заменять новую вкладку, поэтому новая вкладка Lumno там недоступна. Командная строка работает как обычно.

Если сочетание клавиш не срабатывает, откройте страницу сочетаний клавиш для расширений и переключите область действия рядом с Lumno с «In Dia» на «Global».

## Firefox {#firefox}

Версии для Firefox пока нет в каталоге дополнений Firefox; как только она там появится, этот сайт даст на неё ссылку. Она рассчитана на Firefox 140 и новее, а также на браузеры на основе Firefox — Zen, LibreWolf и Floorp.

API расширений в Firefox отличаются от Chromium, поэтому кое-что не работает:

| Функция | В Firefox |
| --- | --- |
| Автоматическая «картинка в картинке» | Недоступна: Firefox не позволяет расширениям переводить веб-видео в режим «картинка в картинке» |
| Веб-вырезка | Недоступна: Firefox не поддерживает режим «картинка в картинке» для документов |
| Командная строка на страницах `about:` и на сайте дополнений | Недоступна |
| Открытие страниц `about:` из ярлыков или командной строки | Недоступно |
| Командная строка на локальных страницах `file://` | Недоступна |
| Значки сайтов | У сайтов, которые вы ещё не посещали, сначала может отображаться значок-заглушка |

В Firefox сочетание `⌘ ⇧ K` уже занято, поэтому версия для Firefox по умолчанию использует `⌃ ⇧ K` в macOS и `Alt + K` в Windows и Linux. `Alt + Q` не меняется.

## Safari {#safari}

Система расширений Safari сильно отличается от Chromium, и версии Lumno для Safari пока нет. Для похожего общесистемного поиска на Mac попробуйте [Raycast](https://www.raycast.com/) или [Alfred](https://www.alfredapp.com/).

## Языки интерфейса {#languages}

Расширение доступно на английском, японском, упрощённом и традиционном китайском; если браузер на русском, оно отображается на английском. По умолчанию оно следует языку браузера, а сменить язык можно в настройках.
