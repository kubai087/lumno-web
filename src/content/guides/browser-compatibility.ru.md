Lumno создан для браузеров на Chromium, а также доступен в версии для Firefox. В таблице ниже указано, какие функции доступны в каждом браузере.

## Поддерживаемые браузеры {#support}

| Браузер | Командная строка | Новая вкладка | Где установить |
| --- | --- | --- | --- |
| Google Chrome | Да | Да | Интернет-магазин Chrome |
| Microsoft Edge | Да | Да | Надстройки Edge |
| Brave, [Arc](https://arc.net/), Vivaldi, Opera | Да | Да | Интернет-магазин Chrome |
| Dia | Да | Пока нет | Интернет-магазин Chrome |
| Firefox, [Zen](https://zen-browser.app/) и другие | Частично | Да | Дополнения Firefox |
| Safari | Нет | Нет | — |

Браузеры на телефонах и планшетах пока не поддерживаются. Если вы открыли этот сайт на телефоне, где выполнен вход в аккаунт Google, можно уже сейчас нажать «Установить»: Lumno установится сам, когда вы откроете Chrome на компьютере с тем же аккаунтом и включённой синхронизацией.

## Dia {#dia}

Dia не позволяет расширениям заменять новую вкладку, поэтому новая вкладка Lumno в этом браузере недоступна. Командная строка работает как обычно.

Чтобы открывать командную строку сочетанием `⌘ T`, сначала освободите его в Dia: собственные сочетания клавиш Dia имеют приоритет.

1. В Dia откройте Settings → Shortcuts и замените сочетание `⌘ T` для «New Tab» на другое.
2. Откройте `dia://extensions/shortcuts` и назначьте действию Lumno «Open command bar» сочетание `⌘ T`.

![Страница Shortcuts в настройках Dia: «New Tab» больше не на ⌘T](dia-newtab "Шаг 1: назначьте «New Tab» другое сочетание в Settings → Shortcuts")

![Страница сочетаний клавиш для расширений в Dia: «Open command bar» Lumno на ⌘T](dia-shortcuts "Шаг 2: назначьте «Open command bar» сочетание ⌘T на dia://extensions/shortcuts")

Если сочетание клавиш не срабатывает, откройте страницу сочетаний клавиш для расширений и измените область действия рядом с Lumno с «In Dia» на «Global».

## Firefox {#firefox}

Версия для Firefox опубликована в [каталоге дополнений Firefox](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/). Она работает в Firefox 140 и более поздних версиях, а ещё её можно установить в браузеры на основе Firefox, например Zen, LibreWolf и Floorp.

API расширений в Firefox отличаются от Chromium, поэтому некоторые функции недоступны:

| Функция | В Firefox |
| --- | --- |
| Автоматическая «картинка в картинке» | Недоступна: Firefox не позволяет расширениям переводить веб-видео в режим «картинка в картинке» |
| Веб-вырезка | Недоступна: Firefox не поддерживает режим «картинка в картинке» для документов |
| Командная строка на страницах `about:` и на сайте дополнений | Недоступна |
| Открытие страниц `about:` из ярлыков или командной строки | Недоступно |
| Командная строка на локальных страницах `file://` | Недоступна |
| Значки сайтов | Для сайтов, которые вы ещё не посещали, сначала может отображаться значок-заглушка |
| Liquid glass на новой вкладке | Только эффект стекла, без преломления по краям |

В Firefox сочетание `⌘ ⇧ K` уже занято, поэтому версия для Firefox по умолчанию использует `⌃ ⇧ K | Alt + K`. Сочетание `⌥ Q` не меняется. Чтобы изменить сочетания, откройте `about:addons`, нажмите кнопку с шестерёнкой в правом верхнем углу и выберите «Управление горячими клавишами расширений».

## Safari {#safari}

Система расширений Safari сильно отличается от Chromium, и версии Lumno для Safari пока нет. Для похожего общесистемного поиска на Mac попробуйте [Raycast](https://www.raycast.com/) или [Alfred](https://www.alfredapp.com/).

## Языки интерфейса {#languages}

Расширение доступно на английском, японском, упрощённом и традиционном китайском; если браузер настроен на русский язык, интерфейс отображается на английском. По умолчанию используется язык браузера, его можно изменить в настройках.
