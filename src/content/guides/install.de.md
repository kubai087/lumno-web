Lumno ist kostenlos, erfordert keine Registrierung und ist direkt nach der Installation einsatzbereit.

## Aus einem Store installieren {#store}

| Browser | Installieren über |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge-Add-ons](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

Öffne die Store-Seite, klicke auf „Hinzufügen“ bzw. „Abrufen“ und bestätige im angezeigten Dialogfenster. In Edge kannst du Lumno auch aus dem Chrome Web Store installieren.

## Nach der Installation {#after-install}

Dein Browser öffnet die Willkommensseite von Lumno, die dir die wichtigsten Funktionen vorstellt.

![Lumnos Willkommensseite: links Slogan und Funktionen, rechts der Lumno-Schriftzug über einer Wiese](onboarding "Die Willkommensseite nach der Installation")

Wenn du zum ersten Mal einen neuen Tab öffnest, fragt Chrome möglicherweise, ob du die von der Erweiterung geänderte Seite beibehalten möchtest. Behalte die Änderung bei. Wenn du sie rückgängig machst, deaktiviert Chrome Lumno vollständig, einschließlich der Befehlsleiste. Wenn du weiterhin eine andere Erweiterung für den neuen Tab verwenden möchtest, lies [Mit einer anderen Erweiterung für den neuen Tab verwenden](../newtab-other-extensions/).

## Die Befehlsleiste ausprobieren {#try}

Öffne eine beliebige Seite und drücke `⌘ ⇧ K` (unter Windows und Linux `Strg + Umschalt + K`), um die Befehlsleiste zu öffnen. Gib ein paar Buchstaben ein, um deine offenen Tabs und Lesezeichen zu durchsuchen, und schließe sie mit `Esc`.

Wenn nichts passiert, findest du unter [Tastenkürzel](../keyboard-shortcuts/) Hinweise zur Fehlerbehebung.

## In lokalen Dateien verwenden {#file-access}

Um die Befehlsleiste auch in PDF- oder HTML-Dateien auf deinem Computer zu öffnen, rufe `chrome://extensions` auf, öffne die Details von Lumno, aktiviere „Zugriff auf Datei-URLs zulassen“ und lade die Datei anschließend neu.
