Lumno is free, requires no sign-up, and is ready to use as soon as you install it.

## Install from a store {#store}

| Browser | Install from |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox, [Zen](https://zen-browser.app/), LibreWolf, Floorp | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

Open the store page, click "Add to Chrome", "Get" or "Add to Firefox", then confirm in the dialog that appears. Edge users can also install Lumno from the Chrome Web Store.

## After you install {#after-install}

Your browser opens Lumno's welcome page, which introduces the main features.

![Lumno's welcome page: the tagline and feature notes on the left, the Lumno wordmark over a meadow on the right](onboarding "The welcome page that opens after you install")

The first time you open a new tab, Chrome may ask whether to keep the new tab page changed by the extension. Choose to keep it. If you choose to change it back, Chrome turns off Lumno entirely, including the command bar. To keep using another new tab extension, see [Use another new tab extension](../newtab-other-extensions/).

## Try the command bar {#try}

Open any page and press `⌘ ⇧ K` to open the command bar. Type a few letters to search your open tabs and bookmarks, then press `Esc` to close it. In Firefox, the default shortcut is `⌃ ⇧ K | Alt + K`.

If nothing happens, see the troubleshooting steps in [Keyboard shortcuts](../keyboard-shortcuts/).

## Use it in local files {#file-access}

To open the command bar in PDF or HTML files on your computer, go to `chrome://extensions`, open Lumno's details page, turn on "Allow access to file URLs", then reload the file. Firefox doesn't let extensions access local files, so the Firefox version can't open the command bar there.
