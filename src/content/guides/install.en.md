Lumno is free, needs no sign-up, and works as soon as it's installed.

## Install from a store {#store}

| Browser | Where to get it |
| --- | --- |
| Chrome, Dia, Brave, Arc, Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

Open the store page, click "Add to Chrome" or "Get", and confirm. Edge users can also install from the Chrome Web Store.

## After installing {#after-install}

Your browser opens Lumno's welcome page for a quick tour of the main features.

![Lumno's welcome page: the tagline and feature notes on the left, the Lumno wordmark over a meadow on the right](onboarding "The welcome page you see after installing")

The first time you open a new tab, Chrome may ask whether to keep the new tab page the extension changed. Keep it to use Lumno's new tab. If you'd rather have your old one back, that's fine too: the command bar keeps working.

## Try the command bar {#try}

Open any page and press `⌘ ⇧ K` (`Ctrl + Shift + K` on Windows and Linux). Type a few letters to find your open tabs and bookmarks, then press `Esc` to close it.

Nothing happens? See the checks in [Keyboard shortcuts](../keyboard-shortcuts/).

## Use it in local files {#file-access}

To open the command bar in PDF or HTML files on your computer, go to `chrome://extensions`, open Lumno's details, turn on "Allow access to file URLs", then reload the file.
