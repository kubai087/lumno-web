Lumno es gratuito, no requiere registro y se puede usar en cuanto lo instalas.

## Instalar desde una tienda {#store}

| Navegador | Instalar desde |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Complementos de Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox, [Zen](https://zen-browser.app/), LibreWolf, Floorp | [Complementos de Firefox](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

Abre la página de la tienda, haz clic en "Añadir a Chrome", "Obtener" o "Añadir a Firefox" y confirma en el cuadro de diálogo que aparece. En Edge también puedes instalar Lumno desde Chrome Web Store.

## Después de instalarlo {#after-install}

El navegador abre la página de bienvenida de Lumno, que presenta las funciones principales.

![La página de bienvenida de Lumno: el eslogan y las funciones a la izquierda, el logotipo de Lumno sobre un prado a la derecha](onboarding "La página de bienvenida que se abre tras la instalación")

La primera vez que abras una nueva pestaña, Chrome puede preguntarte si quieres conservar la página modificada por la extensión. Conserva el cambio. Si eliges deshacerlo, Chrome desactiva Lumno por completo, incluida la barra de comandos. Si quieres seguir usando otra extensión de nueva pestaña, consulta [Usar otra extensión de nueva pestaña](../newtab-other-extensions/).

## Probar la barra de comandos {#try}

Abre cualquier página y pulsa `⌘ ⇧ K` para abrir la barra de comandos. Escribe unas letras para buscar en tus pestañas abiertas y marcadores, y pulsa `Esc` para cerrarla. En la versión para Firefox, el atajo predeterminado es `⌃ ⇧ K | Alt + K`.

Si no ocurre nada, consulta las comprobaciones de [Atajos de teclado](../keyboard-shortcuts/).

## La ventana de la barra de herramientas {#toolbar-popup}

Haz clic en el icono de Lumno en la barra de herramientas del navegador para abrir una pequeña ventana. Si no ves el icono, haz clic en el botón de extensiones con forma de pieza de puzle y fija Lumno en la barra de herramientas.

- Arriba aparecen el título y la dirección de la página actual. Si alguno está cortado, pasa el puntero por encima para leerlo completo.
- Acciones de la página: Add shortcut añade la página a los accesos directos de la nueva pestaña, y también puedes usar Copy link u Open command bar. Con el [recorte web](../web-clip/) activado en los ajustes de Lumno, puedes recortar la página desde aquí; en una página con vídeo, puedes iniciar la imagen en imagen y configurar la [imagen en imagen automática](../auto-pip/).
- Abre Quick settings para cambiar el tema y activar o desactivar Match page colors y Show open tabs by default.
- Abajo se muestran la versión de Lumno y el estado de la sincronización WebDAV, con enlaces a Settings, Set shortcuts, Feedback y What's new.

## Usar Lumno en archivos locales {#file-access}

Para abrir la barra de comandos en archivos PDF o HTML de tu ordenador, ve a `chrome://extensions`, abre los detalles de Lumno, permite el acceso a las URL de archivo y vuelve a cargar el archivo. Firefox no permite que las extensiones accedan a archivos locales, así que la versión para Firefox no puede abrir la barra de comandos en estas páginas.
