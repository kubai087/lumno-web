Lumno es gratis, no pide registro y funciona nada más instalarlo.

## Instalar desde una tienda {#store}

| Navegador | Dónde conseguirlo |
| --- | --- |
| Chrome, Dia, Brave, Arc, Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Complementos de Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

Abre la página de la tienda, haz clic en "Añadir a Chrome" u "Obtener" y confirma. En Edge también puedes instalarlo desde Chrome Web Store.

## Después de instalarlo {#after-install}

El navegador abre la página de bienvenida de Lumno con un recorrido rápido por las funciones principales.

![La página de bienvenida de Lumno: el eslogan y las funciones a la izquierda, el logotipo de Lumno sobre un prado a la derecha](onboarding "La página de bienvenida que ves al instalarlo")

La primera vez que abras una nueva pestaña, Chrome puede preguntarte si quieres conservar la página que ha cambiado la extensión. Consérvala para usar la nueva pestaña de Lumno. Si prefieres recuperar la de antes, no pasa nada: la barra de comandos sigue funcionando.

## Prueba la barra de comandos {#try}

Abre cualquier página y pulsa `⌘ ⇧ K` (`Ctrl + Mayús + K` en Windows y Linux). Escribe unas letras para encontrar tus pestañas abiertas y marcadores, y pulsa `Esc` para cerrarla.

¿No pasa nada? Revisa las comprobaciones de [Atajos de teclado](../keyboard-shortcuts/).

## Úsalo en archivos locales {#file-access}

Para abrir la barra de comandos en archivos PDF o HTML de tu ordenador, ve a `chrome://extensions`, abre los detalles de Lumno, activa el acceso a las URL de archivo y vuelve a cargar el archivo.
