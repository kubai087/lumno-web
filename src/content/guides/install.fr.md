Lumno est gratuit, ne demande aucune inscription et peut être utilisé dès l'installation.

## Installer depuis une boutique {#store}

| Navigateur | Installer depuis |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Modules complémentaires Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox, [Zen](https://zen-browser.app/), LibreWolf, Floorp | [Modules complémentaires Firefox](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

Ouvrez la page de la boutique, cliquez sur « Ajouter à Chrome », « Obtenir » ou « Ajouter à Firefox », puis confirmez dans la boîte de dialogue qui s'affiche. Dans Edge, vous pouvez également installer Lumno depuis le Chrome Web Store.

## Après l'installation {#after-install}

Votre navigateur ouvre la page d'accueil de Lumno, qui présente les principales fonctions.

![La page d'accueil de Lumno : le slogan et les fonctions à gauche, le logo Lumno sur une prairie à droite](onboarding "La page d'accueil affichée après l'installation")

Lorsque vous ouvrez un nouvel onglet pour la première fois, Chrome peut vous demander si vous souhaitez conserver la page modifiée par l'extension. Conservez la modification. Si vous choisissez de l'annuler, Chrome désactive entièrement Lumno, y compris la barre de commande. Si vous souhaitez continuer à utiliser une autre extension de nouvel onglet, consultez [Utiliser une autre extension de nouvel onglet](../newtab-other-extensions/).

## Essayer la barre de commande {#try}

Ouvrez n'importe quelle page et appuyez sur `⌘ ⇧ K` pour ouvrir la barre de commande. Saisissez quelques lettres pour rechercher vos onglets ouverts et vos favoris, puis appuyez sur `Esc` pour la fermer. Dans la version Firefox, le raccourci par défaut est `⌃ ⇧ K | Alt + K`.

Si rien ne se passe, consultez les vérifications décrites dans [Raccourcis clavier](../keyboard-shortcuts/).

## La fenêtre de la barre d'outils {#toolbar-popup}

Cliquez sur l'icône Lumno dans la barre d'outils de votre navigateur pour ouvrir une petite fenêtre. Si l'icône n'apparaît pas, cliquez sur le bouton Extensions en forme de pièce de puzzle et épinglez Lumno à la barre d'outils.

- En haut s'affichent le titre et l'adresse de la page actuelle. S'ils sont tronqués, survolez-les pour les lire en entier.
- Actions sur la page : Add shortcut ajoute la page aux raccourcis du nouvel onglet ; vous pouvez aussi utiliser Copy link ou Open command bar. Si la [capture web](../web-clip/) est activée dans les réglages de Lumno, vous pouvez capturer la page d'ici ; sur une page avec une vidéo, vous pouvez lancer l'image dans l'image et régler l'[image dans l'image automatique](../auto-pip/).
- Ouvrez Quick settings pour changer de thème et activer ou non Match page colors et Show open tabs by default.
- En bas s'affichent la version de Lumno et l'état de la synchronisation WebDAV, avec des liens vers Settings, Set shortcuts, Feedback et What's new.

## Utiliser Lumno dans des fichiers locaux {#file-access}

Pour ouvrir la barre de commande dans des fichiers PDF ou HTML de votre ordinateur, accédez à `chrome://extensions`, ouvrez les détails de Lumno, activez « Autoriser l'accès aux URL de fichier », puis actualisez le fichier. Firefox n'autorise pas les extensions à accéder aux fichiers locaux : la version Firefox ne peut donc pas ouvrir la barre de commande sur ces pages.
