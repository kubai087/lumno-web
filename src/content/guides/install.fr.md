Lumno est gratuit, ne demande aucune inscription et fonctionne dès l'installation.

## Installer depuis une boutique {#store}

| Navigateur | Où l'obtenir |
| --- | --- |
| Chrome, Dia, Brave, Arc, Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Modules complémentaires Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

Ouvrez la page de la boutique, cliquez sur « Ajouter à Chrome » ou « Obtenir », puis confirmez. Dans Edge, vous pouvez aussi installer depuis le Chrome Web Store.

## Après l'installation {#after-install}

Votre navigateur ouvre la page d'accueil de Lumno pour un petit tour des fonctions principales.

![La page d'accueil de Lumno : le slogan et les fonctions à gauche, le logo Lumno sur une prairie à droite](onboarding "La page d'accueil affichée après l'installation")

À l'ouverture du premier nouvel onglet, Chrome peut vous demander s'il faut garder la page modifiée par l'extension. Gardez-la pour utiliser le nouvel onglet de Lumno. Si vous préférez retrouver l'ancien, pas de souci : la barre de commande continue de fonctionner.

## Essayer la barre de commande {#try}

Ouvrez n'importe quelle page et appuyez sur `⌘ ⇧ K` (`Ctrl + Maj + K` sous Windows et Linux). Tapez quelques lettres pour retrouver vos onglets ouverts et vos favoris, puis appuyez sur `Esc` pour fermer.

Rien ne se passe ? Consultez les vérifications de la page [Raccourcis clavier](../keyboard-shortcuts/).

## Dans les fichiers locaux {#file-access}

Pour ouvrir la barre de commande dans des fichiers PDF ou HTML de votre ordinateur, allez dans `chrome://extensions`, ouvrez les détails de Lumno, activez « Autoriser l'accès aux URL de fichier », puis rechargez le fichier.
