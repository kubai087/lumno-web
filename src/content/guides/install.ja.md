Lumno は無料で、登録は不要です。ストアからインストールすると、すぐに使用できます。

## ストアからインストールする {#store}

| ブラウザ | 入手先 |
| --- | --- |
| Chrome、Dia、Brave、[Arc](https://arc.net/)、Vivaldi、Opera | [Chrome ウェブストア](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge アドオン](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox、[Zen](https://zen-browser.app/)、LibreWolf、Floorp | [Firefox アドオン](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

ストアのページで「Chrome に追加」「インストール」または「Firefox へ追加」をクリックし、表示されたダイアログで確認します。Edge でも Chrome ウェブストアからインストールできます。

## インストールしたあと {#after-install}

ブラウザに Lumno のようこそページが開き、主な機能が紹介されます。

![Lumno のようこそページ。左にキャッチコピーと機能の説明、右に Lumno のロゴと草原のイラスト](onboarding "インストール後に開くようこそページ")

はじめて新しいタブを開くと、拡張機能による新しいタブの変更を維持するかどうかを Chrome が確認することがあります。変更を維持してください。元に戻すことを選ぶと、Chrome は Lumno 全体を無効にするため、コマンドバーも使用できなくなります。ほかの新しいタブ拡張機能を使い続けたい場合は、[ほかの新しいタブ拡張機能と併用する](../newtab-other-extensions/)を参照してください。

## コマンドバーを試す {#try}

任意のページを開き、`⌘ ⇧ K` を押すと、コマンドバーが開きます。数文字入力して、開いているタブやブックマークを検索します。`Esc` キーを押すと閉じます。Firefox 版の初期設定のショートカットは `⌃ ⇧ K | Alt + K` です。

ショートカットキーが反応しない場合は、[キーボードショートカット](../keyboard-shortcuts/)の確認方法を参照してください。

## ツールバーのポップアップ {#toolbar-popup}

ブラウザのツールバーにある Lumno アイコンをクリックすると、小さなポップアップが開きます。アイコンが見当たらない場合は、パズルのピースの形をした拡張機能ボタンをクリックし、Lumno をツールバーに固定してください。

- 上部には、現在のページのタイトルとアドレスが表示されます。途中で切れている場合は、マウスポインタを重ねると全体が表示されます。
- ページの操作：「ショートカット追加」で現在のページを新しいタブのショートカットに追加できるほか、「リンクをコピー」「検索バーを開く」も使えます。Lumno の設定で [Webクリップ](../web-clip/) をオンにすると、ここからページをクリップできます。動画のあるページでは、ピクチャー・イン・ピクチャーを開始したり、[自動ピクチャー・イン・ピクチャー](../auto-pip/)を設定したりできます。
- 「クイック設定」を開くと、テーマ、「ページの色に合わせる」、「開いているタブを既定で表示」を切り替えられます。
- 下部には Lumno のバージョンと WebDAV 同期の状態が表示され、設定、キー設定、フィードバック、更新履歴へ移動できます。

## ローカルファイルで使用する {#file-access}

パソコン上の PDF や HTML ファイルでコマンドバーを開くには、`chrome://extensions` を開いて Lumno の詳細ページに移動し、「ファイルの URL へのアクセスを許可する」をオンにしてから、ファイルを再読み込みします。Firefox では拡張機能がローカルファイルにアクセスできないため、Firefox 版ではこうしたページでコマンドバーを開けません。
