Lumno は無料で、登録も不要。ストアからインストールすれば、すぐに使えます。

## ストアからインストール {#store}

| ブラウザ | 入手先 |
| --- | --- |
| Chrome、Dia、Brave、Arc、Vivaldi、Opera | [Chrome ウェブストア](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge アドオン](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

ストアのページで「Chrome に追加」または「インストール」をクリックし、確認画面で許可すれば完了です。Edge でも Chrome ウェブストアからインストールできます。

## インストールのあと {#after-install}

ブラウザが Lumno のようこそページを開き、主な機能をひととおり案内します。

![Lumno のようこそページ。左にキャッチコピーと機能の説明、右に Lumno のロゴと草原のイラスト](onboarding "インストール後に開くようこそページ")

はじめて新しいタブを開くと、拡張機能によって変更された新しいタブを残すかどうか Chrome が確認することがあります。残せば Lumno の新しいタブが使えます。元の新しいタブに戻しても、コマンドバーはそのまま使えます。

## コマンドバーを試す {#try}

どこかのページを開いて `⌘ ⇧ K`（Windows と Linux では `Ctrl + Shift + K`）を押すと、コマンドバーが開きます。数文字入力して、開いているタブやブックマークを探してみましょう。`Esc` で閉じます。

反応しないときは、[キーボードショートカット](../keyboard-shortcuts/)の確認方法をご覧ください。

## ローカルファイルで使う {#file-access}

パソコン上の PDF や HTML ファイルでもコマンドバーを開くには、`chrome://extensions` で Lumno の詳細を開き、「ファイルの URL へのアクセスを許可する」をオンにして、ファイルを再読み込みしてください。
