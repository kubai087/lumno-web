Lumno는 무료이며 가입할 필요가 없습니다. 스토어에서 설치하면 바로 사용할 수 있습니다.

## 스토어에서 설치하기 {#store}

| 브라우저 | 설치 위치 |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Chrome 웹 스토어](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge 추가 기능](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox, [Zen](https://zen-browser.app/), LibreWolf, Floorp | [Firefox 부가 기능](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

스토어 페이지를 열고 "Chrome에 추가", "다운로드" 또는 "Firefox에 추가"를 클릭한 다음, 표시되는 대화상자에서 확인하세요. Edge에서도 Chrome 웹 스토어에서 Lumno를 설치할 수 있습니다.

## 설치 후 {#after-install}

브라우저에 Lumno 환영 페이지가 열리고 주요 기능이 소개됩니다.

![Lumno 환영 페이지: 왼쪽에 소개 문구와 기능 설명, 오른쪽에 들판 위의 Lumno 로고](onboarding "설치 후 열리는 환영 페이지")

처음 새 탭을 열면 Chrome에서 확장 프로그램이 변경한 새 탭 페이지를 유지할지 물어볼 수 있습니다. 유지를 선택하세요. 변경 사항을 되돌리면 Chrome이 명령 바를 포함한 Lumno 전체를 사용 중지합니다. 다른 새 탭 확장 프로그램을 계속 사용하려면 [다른 새 탭 확장 프로그램과 함께 사용하기](../newtab-other-extensions/)를 참고하세요.

## 명령 바 사용해 보기 {#try}

아무 페이지나 열고 `⌘ ⇧ K`를 누르면 명령 바가 열립니다. 몇 글자를 입력해 열린 탭과 북마크를 검색하고, `Esc`를 눌러 닫으세요. Firefox 버전의 기본 단축키는 `⌃ ⇧ K | Alt + K`입니다.

단축키가 작동하지 않으면 [단축키](../keyboard-shortcuts/)의 확인 방법을 참고하세요.

## 툴바 팝업 {#toolbar-popup}

브라우저 툴바의 Lumno 아이콘을 클릭하면 작은 팝업이 열립니다. 아이콘이 보이지 않으면 퍼즐 모양의 확장 프로그램 버튼을 클릭하고 Lumno를 툴바에 고정하세요.

- 위쪽에는 현재 페이지의 제목과 주소가 표시됩니다. 잘려 보이면 마우스 포인터를 올려 전체 내용을 확인할 수 있습니다.
- 페이지 작업: Add shortcut은 현재 페이지를 새 탭 바로가기에 추가하며, Copy link와 Open command bar도 사용할 수 있습니다. Lumno 설정에서 [웹 클립](../web-clip/)을 켜면 여기서 페이지를 클립할 수 있고, 동영상이 있는 페이지에서는 PIP를 시작하거나 [자동 PIP](../auto-pip/)를 설정할 수 있습니다.
- Quick settings를 펼치면 테마, Match page colors, Show open tabs by default를 바꿀 수 있습니다.
- 아래쪽에는 Lumno 버전과 WebDAV 동기화 상태가 표시되며, Settings, Set shortcuts, Feedback, What's new로 이동할 수 있습니다.

## 로컬 파일에서 사용하기 {#file-access}

컴퓨터에 있는 PDF 또는 HTML 파일에서 명령 바를 열려면 `chrome://extensions`에서 Lumno 세부정보를 열고 파일 URL에 대한 액세스를 허용한 다음, 파일을 새로고침하세요. Firefox는 확장 프로그램이 로컬 파일에 접근하는 것을 허용하지 않으므로, Firefox 버전에서는 이런 페이지에서 명령 바를 열 수 없습니다.
