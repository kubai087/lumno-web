Lumno는 무료이고, 가입 없이 설치하자마자 바로 쓸 수 있어요.

## 스토어에서 설치하기 {#store}

| 브라우저 | 설치하는 곳 |
| --- | --- |
| Chrome, Dia, Brave, Arc, Vivaldi, Opera | [Chrome 웹 스토어](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge 추가 기능](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

스토어 페이지를 열고 "Chrome에 추가" 또는 "다운로드"를 누른 뒤 확인하세요. Edge에서도 Chrome 웹 스토어에서 설치할 수 있어요.

## 설치한 다음에는 {#after-install}

브라우저가 Lumno의 환영 페이지를 열고 주요 기능을 간단히 안내해 줘요.

![Lumno 환영 페이지: 왼쪽에 소개 문구와 기능 설명, 오른쪽에 들판 위의 Lumno 로고](onboarding "설치 후 보게 되는 환영 페이지")

처음 새 탭을 열면 Chrome이 확장 프로그램이 바꾼 새 탭 페이지를 유지할지 물어볼 수 있어요. Lumno 새 탭을 쓰려면 유지하세요. 원래 새 탭으로 돌아가도 괜찮아요. 명령 바는 그대로 동작합니다.

## 명령 바 써 보기 {#try}

아무 페이지나 열고 `⌘ ⇧ K`(Windows와 Linux는 `Ctrl + Shift + K`)를 누르세요. 몇 글자를 입력해 열린 탭과 북마크를 찾아보고, `Esc`로 닫으면 됩니다.

아무 반응이 없나요? [단축키](../keyboard-shortcuts/)의 확인 사항을 살펴보세요.

## 로컬 파일에서 쓰기 {#file-access}

컴퓨터에 있는 PDF나 HTML 파일에서도 명령 바를 열려면 `chrome://extensions`에서 Lumno의 세부정보를 열고 파일 URL 액세스를 허용한 다음, 파일을 새로 고치세요.
