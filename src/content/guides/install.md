Lumno 免费，不用注册，从商店装好就能用。

## 从商店安装 {#store}

| 浏览器 | 去哪里装 |
| --- | --- |
| Chrome、Dia、Brave、Arc、Vivaldi、Opera | [Chrome 应用商店](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

打开商店页面，点「添加至 Chrome」或「获取」，在弹窗里确认就好。Edge 用户也可以直接从 Chrome 应用商店装。

## 装好之后 {#after-install}

浏览器会打开 Lumno 的欢迎页，带你快速认识一遍主要功能。

![Lumno 欢迎页，左侧是“让浏览器的常用网站一搜即达”的标语和功能说明，右侧是 Lumno 字标和田野插画](onboarding "装好后看到的欢迎页")

第一次打开新标签页时，Chrome 可能会问你是否保留扩展修改的新标签页。选保留，就能用上 Lumno 的新标签页；更喜欢原来的也没关系，改回去后命令栏照样能用。

## 试试命令栏 {#try}

随便打开一个网页，按下 `⌘ ⇧ K`（Windows 和 Linux 上是 `Ctrl + Shift + K`），命令栏就出来了。输几个字，搜搜看你开着的标签页和书签，按 `Esc` 关掉。

没反应？看看[快捷键](../keyboard-shortcuts/)里的排查办法。

## 在本地文件里用 {#file-access}

想在电脑上的 PDF、HTML 文件里也唤出命令栏，要先打开 `chrome://extensions`，进入 Lumno 的详情页，开启「允许访问文件网址」，然后刷新那个文件页。
