O Lumno é gratuito, não pede cadastro e funciona assim que é instalado.

## Instalar pela loja {#store}

| Navegador | Onde baixar |
| --- | --- |
| Chrome, Dia, Brave, Arc, Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Complementos do Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

Abra a página da loja, clique em "Usar no Chrome" ou "Obter" e confirme. No Edge, você também pode instalar pela Chrome Web Store.

## Depois de instalar {#after-install}

O navegador abre a página de boas-vindas do Lumno, com um tour rápido pelos principais recursos.

![A página de boas-vindas do Lumno: o slogan e os recursos à esquerda, o logotipo do Lumno sobre um campo florido à direita](onboarding "A página de boas-vindas que aparece depois de instalar")

Na primeira vez que você abrir uma nova guia, o Chrome pode perguntar se você quer manter a página alterada pela extensão. Mantenha para usar a nova guia do Lumno. Se preferir a antiga, tudo bem: a barra de comandos continua funcionando.

## Experimente a barra de comandos {#try}

Abra qualquer página e aperte `⌘ ⇧ K` (`Ctrl + Shift + K` no Windows e no Linux). Digite algumas letras para encontrar suas guias abertas e favoritos, e aperte `Esc` para fechar.

Nada acontece? Confira as verificações em [Atalhos de teclado](../keyboard-shortcuts/).

## Use em arquivos locais {#file-access}

Para abrir a barra de comandos em arquivos PDF ou HTML do seu computador, vá em `chrome://extensions`, abra os detalhes do Lumno, ative o acesso a URLs de arquivo e recarregue o arquivo.
