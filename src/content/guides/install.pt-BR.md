O Lumno é gratuito, não exige cadastro e pode ser usado assim que é instalado.

## Instalar pela loja {#store}

| Navegador | Instalar pela |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Chrome Web Store](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Complementos do Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox, [Zen](https://zen-browser.app/), LibreWolf, Floorp | [Complementos do Firefox](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

Abra a página da loja, clique em "Usar no Chrome", "Obter" ou "Adicionar ao Firefox" e confirme na caixa de diálogo exibida. No Edge, você também pode instalar o Lumno pela Chrome Web Store.

## Depois de instalar {#after-install}

O navegador abre a página de boas-vindas do Lumno, que apresenta os principais recursos.

![A página de boas-vindas do Lumno: o slogan e os recursos à esquerda, o logotipo do Lumno sobre um campo à direita](onboarding "A página de boas-vindas aberta após a instalação")

Na primeira vez que você abrir uma nova guia, o Chrome poderá perguntar se você quer manter a página alterada pela extensão. Mantenha a alteração. Se você optar por desfazê-la, o Chrome desativará o Lumno por completo, incluindo a barra de comandos. Se quiser continuar usando outra extensão de nova guia, consulte [Usar outra extensão de nova guia](../newtab-other-extensions/).

## Experimentar a barra de comandos {#try}

Abra qualquer página e pressione `⌘ ⇧ K` para abrir a barra de comandos. Digite algumas letras para pesquisar suas guias abertas e seus favoritos e pressione `Esc` para fechá-la. Na versão para Firefox, o atalho padrão é `⌃ ⇧ K | Alt + K`.

Se nada acontecer, consulte as verificações em [Atalhos de teclado](../keyboard-shortcuts/).

## Usar em arquivos locais {#file-access}

Para abrir a barra de comandos em arquivos PDF ou HTML do seu computador, acesse `chrome://extensions`, abra os detalhes do Lumno, permita o acesso a URLs de arquivo e recarregue o arquivo. O Firefox não permite que extensões acessem arquivos locais, então a versão para Firefox não consegue abrir a barra de comandos nessas páginas.
