Lumno бесплатный, не требует регистрации и готов к работе сразу после установки.

## Установка из магазина {#store}

| Браузер | Где установить |
| --- | --- |
| Chrome, Dia, Brave, [Arc](https://arc.net/), Vivaldi, Opera | [Интернет-магазин Chrome](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Надстройки Microsoft Edge](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox, [Zen](https://zen-browser.app/), LibreWolf, Floorp | [Дополнения Firefox](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

Откройте страницу расширения в магазине, нажмите «Установить», «Получить» или «Добавить в Firefox» и подтвердите действие в появившемся окне. В Edge расширение также можно установить из Интернет-магазина Chrome.

## После установки {#after-install}

Браузер откроет приветственную страницу Lumno с обзором основных функций.

![Приветственная страница Lumno: слева слоган и описание функций, справа логотип Lumno над цветущим лугом](onboarding "Приветственная страница, которая открывается после установки")

Когда вы впервые откроете новую вкладку, Chrome может спросить, сохранить ли изменения, внесённые расширением. Сохраните их. Если отменить изменения, Chrome полностью отключит Lumno, включая командную строку. Если вы хотите и дальше пользоваться другим расширением для новой вкладки, см. раздел [Использование с другим расширением для новой вкладки](../newtab-other-extensions/).

## Как открыть командную строку {#try}

Откройте любую страницу и нажмите `⌘ ⇧ K`, чтобы открыть командную строку. Введите несколько букв для поиска по открытым вкладкам и закладкам, а затем нажмите `Esc`, чтобы закрыть её. В версии для Firefox по умолчанию используется `⌃ ⇧ K | Alt + K`.

Если ничего не происходит, выполните проверки, описанные в разделе [Сочетания клавиш](../keyboard-shortcuts/).

## Всплывающее окно на панели инструментов {#toolbar-popup}

Нажмите значок Lumno на панели инструментов браузера, чтобы открыть небольшое всплывающее окно. Если значка не видно, нажмите кнопку расширений в виде кусочка пазла и закрепите Lumno на панели инструментов.

- Вверху показаны заголовок и адрес текущей страницы. Если они обрезаны, наведите на них указатель, чтобы прочитать полностью.
- Действия со страницей: Add shortcut добавляет страницу в ярлыки новой вкладки, также доступны Copy link и Open command bar. Если в настройках Lumno включена [веб-вырезка](../web-clip/), страницу можно вырезать прямо отсюда; на странице с видео можно включить режим «картинка в картинке» и настроить [автоматическую «картинку в картинке»](../auto-pip/).
- Откройте Quick settings, чтобы сменить тему и включить или выключить Match page colors и Show open tabs by default.
- Внизу показаны версия Lumno и состояние синхронизации WebDAV, а также ссылки на Settings, Set shortcuts, Feedback и What's new.

## Использование в локальных файлах {#file-access}

Чтобы открывать командную строку в PDF- и HTML-файлах на компьютере, перейдите на страницу `chrome://extensions`, откройте сведения о Lumno, включите «Разрешить открывать файлы по ссылкам» и перезагрузите файл. Firefox не даёт расширениям доступа к локальным файлам, поэтому в версии для Firefox командную строку на таких страницах открыть нельзя.
