Lumno 免費，不用註冊，從商店裝好就能用。

## 從商店安裝 {#store}

| 瀏覽器 | 去哪裡裝 |
| --- | --- |
| Chrome、Dia、Brave、Arc、Vivaldi、Opera | [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge 附加元件](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |

開啟商店頁面，按「加到 Chrome」或「取得」，在彈出視窗裡確認就好。Edge 使用者也可以直接從 Chrome 線上應用程式商店安裝。

## 裝好之後 {#after-install}

瀏覽器會開啟 Lumno 的歡迎頁，帶你快速認識主要功能。

![Lumno 歡迎頁，左側是標語和功能說明，右側是 Lumno 字標和田野插畫](onboarding "裝好後看到的歡迎頁")

第一次開啟新分頁時，Chrome 可能會詢問是否保留擴充功能修改的新分頁。選擇保留，就能用上 Lumno 的新分頁；比較喜歡原本的也沒關係，改回去後命令列一樣能用。

## 試試命令列 {#try}

隨便開一個網頁，按下 `⌘ ⇧ K`（Windows 和 Linux 上是 `Ctrl + Shift + K`），命令列就出來了。打幾個字，搜搜看你開著的分頁和書籤，按 `Esc` 關閉。

沒反應？看看[快速鍵](../keyboard-shortcuts/)裡的排查方式。

## 在本機檔案裡使用 {#file-access}

想在電腦上的 PDF、HTML 檔案裡也叫出命令列，要先開啟 `chrome://extensions`，進入 Lumno 的詳細資料頁，開啟「允許存取檔案網址」，然後重新整理那個檔案頁面。
