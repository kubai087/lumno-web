Lumno 完全免費，不必註冊，從擴充功能商店安裝後即可使用。

## 從商店安裝 {#store}

| 瀏覽器 | 安裝管道 |
| --- | --- |
| Chrome、Dia、Brave、[Arc](https://arc.net/)、Vivaldi、Opera | [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/nggfkkbmogmadfoikakkfegkoilfcfao) |
| Microsoft Edge | [Microsoft Edge 附加元件](https://microsoftedge.microsoft.com/addons/detail/pfbklkaefmfamjpibfiapaiihlddhchc) |
| Firefox、[Zen](https://zen-browser.app/)、LibreWolf、Floorp | [Firefox 附加元件](https://addons.mozilla.org/firefox/addon/lumno-command-bar-new-tab/) |

開啟商店頁面，按一下「加到 Chrome」「取得」或「新增至 Firefox」，然後在彈出的對話框中確認即可。Edge 使用者也可以直接從 Chrome 線上應用程式商店安裝。

## 安裝之後 {#after-install}

瀏覽器會自動開啟 Lumno 的歡迎頁，介紹主要功能。

![Lumno 歡迎頁，左側是標語和功能說明，右側是 Lumno 字標和田野插畫](onboarding "安裝後開啟的歡迎頁")

第一次開啟新分頁時，Chrome 可能會詢問是否保留擴充功能對新分頁的修改，請選擇保留。如果選擇還原原本的設定，Chrome 會停用整個 Lumno，命令列也會一起失效。如果想繼續使用其他新分頁擴充功能，請參閱[搭配其他新分頁擴充功能](../newtab-other-extensions/)。

## 開始使用命令列 {#try}

開啟任何網頁，按下 `⌘ ⇧ K`，即可叫出命令列。輸入幾個字，可以搜尋已開啟的分頁和書籤；按 `Esc` 關閉。Firefox 版的預設快速鍵是 `⌃ ⇧ K | Alt + K`。

如果按下快速鍵沒有反應，請參閱[快速鍵](../keyboard-shortcuts/)中的排解方式。

## 工具列彈出視窗 {#toolbar-popup}

按一下瀏覽器工具列中的 Lumno 圖示，會開啟一個小視窗。如果工具列中沒有 Lumno 圖示，可以先按一下拼圖形狀的擴充功能按鈕，把 Lumno 固定到工具列。

- 視窗上方顯示目前網頁的標題和網址。內容被截斷時，將滑鼠停在上面即可看到完整內容。
- 頁面操作：「新增捷徑」會把目前網頁加入新分頁的捷徑；還可以「複製連結」或「開啟命令列」。在 Lumno 設定中開啟[網頁剪裁](../web-clip/)後，也可以從這裡剪裁網頁；網頁中有影片時，可以開啟子母畫面，並設定[自動子母畫面](../auto-pip/)。
- 展開「快速設定」，可以切換主題、「跟隨網頁配色」和「預設顯示已開啟的分頁」。
- 底部顯示版本號和 WebDAV 同步狀態，還可以前往設定、設定快速鍵、回饋和更新日誌。

## 在本機檔案中使用 {#file-access}

如果想在電腦上的 PDF、HTML 檔案中叫出命令列，需要先開啟 `chrome://extensions`，進入 Lumno 的詳細資料頁，開啟「允許存取檔案網址」，然後重新整理該檔案頁面。Firefox 不允許擴充功能存取本機檔案，因此 Firefox 版無法在這類頁面中叫出命令列。
