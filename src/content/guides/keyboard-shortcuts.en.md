Most of Lumno happens on the keyboard. Here are the default shortcuts, how to change them, and the handy keys inside the command bar.

## Default shortcuts {#defaults}

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Open the command bar | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| Open the recent tab switcher | `⌥ Q` | `Alt + Q` |
| Open the command bar with the current page URL | Set it yourself | Set it yourself |
| Copy the current page URL | Set it yourself | Set it yourself |

The last two may show "Not set" right after installing. Give them a shortcut the way described below.

## Change a shortcut {#change}

Browsers manage extension shortcuts on their own page:

1. Type `chrome://extensions/shortcuts` in the address bar (`edge://extensions/shortcuts` in Edge).
2. Find Lumno and click the pencil next to the action you want to change.
3. Press the new key combination.

![The browser's extension shortcuts page, with Lumno's "Open command bar" set to ⇧⌘K and "Open recent tab switcher" set to ⌥Q](shortcuts "Changing shortcuts on the extensions page")

Coming from Arc? Set "Open command bar" to `⌘ T` and it feels just like home.

If the shortcut does nothing in Dia, change the scope next to it from "In Dia" to "Global".

## Keys in the command bar {#command-bar-keys}

| Key | What it does |
| --- | --- |
| `↑` `↓` | Move through results |
| `↩` | Open a result, or switch to an open tab |
| `⌥ ↩` | Open in the current tab instead of a new one |
| `⇧ ↩` | For an open tab, open another copy in a new tab |
| `Tab` | After a site shortcut, start site search; in an empty box, search open tabs only |
| `Tab` `Tab` | In an empty box, open the search scope panel |
| `Esc` | Leave site search, or close the command bar |

## Keys in the switcher {#switcher-keys}

| Key | What it does |
| --- | --- |
| Hold `⌥`, tap `Q` | Move through recent tabs |
| `Tab` or arrow keys | Move the selection |
| Let go of `⌥`, or press `↩` | Switch to the selected tab |
