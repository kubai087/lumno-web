You can do most things in Lumno from the keyboard. This page lists the default shortcuts, how to change them, and the keys you can use in the command bar and the switcher.

## Default shortcuts {#defaults}

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Open the command bar | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| Open the recent tab switcher | `⌥ Q` | `Alt + Q` |
| Open the command bar with the current page URL | Not set by default | Not set by default |
| Copy the current page URL | Not set by default | Not set by default |

The last two may show "Not set" after you install Lumno. To assign shortcuts to them, follow the steps below.

## Change a shortcut {#change}

Browsers manage extension shortcuts on a separate page:

1. Type `chrome://extensions/shortcuts` in the address bar (`edge://extensions/shortcuts` in Edge).
2. Find Lumno, then click the pencil icon next to the action you want to change.
3. Press the new key combination.

![The browser's extension shortcuts page, with Lumno's "Open command bar" set to ⇧⌘K and "Open recent tab switcher" set to ⌥Q](shortcuts "Changing shortcuts on the extensions page")

If you're used to Arc, set "Open command bar" to `⌘ T`.

If the shortcut doesn't work in Dia, change the scope next to it from "In Dia" to "Global".

## Keys in the command bar {#command-bar-keys}

| Key | Action |
| --- | --- |
| `↑` `↓` | Select a result |
| `↩` | Open a result, or switch to an open tab |
| `⌥ ↩` | Open in the current tab instead of a new one |
| `⇧ ↩` | If the result is an open tab, open another copy in a new tab |
| `Tab` | After a site shortcut, start site search; in an empty search box, search open tabs only |
| `Tab` `Tab` | In an empty search box, open the search scope panel |
| `Esc` | Leave site search, or close the command bar |

## Keys in the switcher {#switcher-keys}

| Key | Action |
| --- | --- |
| Hold `⌥` and press `Q` repeatedly | Move through recent tabs |
| `Tab` or arrow keys | Move the selection |
| Release `⌥`, or press `↩` | Switch to the selected tab |
