La mayoría de las funciones de Lumno se pueden usar con el teclado. En esta página encontrarás los atajos predeterminados, cómo cambiarlos y las teclas que puedes usar en la barra de comandos y en el selector de pestañas.

## Atajos predeterminados {#defaults}

| Acción | macOS | Windows / Linux |
| --- | --- | --- |
| Abrir la barra de comandos | `⌘ ⇧ K` | `Ctrl + Mayús + K` |
| Abrir el selector de pestañas recientes | `⌥ Q` | `Alt + Q` |
| Abrir la barra de comandos con la URL de la página actual | Sin atajo predeterminado | Sin atajo predeterminado |
| Copiar la URL de la página actual | Sin atajo predeterminado | Sin atajo predeterminado |

Las dos últimas acciones pueden aparecer como "Sin definir" después de la instalación. Para asignarles un atajo, sigue los pasos que se indican a continuación.

## Cambiar un atajo {#change}

Los navegadores gestionan los atajos de las extensiones en una página específica:

1. Escribe `chrome://extensions/shortcuts` en la barra de direcciones (`edge://extensions/shortcuts` en Edge).
2. Busca Lumno y haz clic en el icono del lápiz junto a la acción que quieras cambiar.
3. Pulsa la nueva combinación de teclas.

![La página de atajos de extensiones del navegador, con "Open command bar" de Lumno en ⇧⌘K y "Open recent tab switcher" en ⌥Q](shortcuts "Cambiar atajos en la página de extensiones")

Si estás acostumbrado a Arc, puedes asignar `⌘ T` a "Open command bar".

Si el atajo no funciona en Dia, cambia el ámbito que aparece junto a él de "In Dia" a "Global".

## Teclas de la barra de comandos {#command-bar-keys}

| Tecla | Acción |
| --- | --- |
| `↑` `↓` | Seleccionar un resultado |
| `↩` | Abrir un resultado o cambiar a una pestaña abierta |
| `⌥ ↩` | Abrir en la pestaña actual en lugar de en una nueva |
| `⇧ ↩` | Si el resultado es una pestaña abierta, abrirla de nuevo en una pestaña nueva |
| `Tab` | Después de un atajo de sitio, iniciar la búsqueda en el sitio; con el cuadro vacío, buscar solo en las pestañas abiertas |
| `Tab` `Tab` | Con el cuadro vacío, abrir el panel de ámbitos de búsqueda |
| `Esc` | Salir de la búsqueda en el sitio o cerrar la barra de comandos |

## Teclas del selector de pestañas {#switcher-keys}

| Tecla | Acción |
| --- | --- |
| Mantener pulsada `⌥` y pulsar `Q` varias veces | Recorrer las pestañas recientes |
| `Tab` o teclas de flecha | Mover la selección |
| Soltar `⌥` o pulsar `↩` | Cambiar a la pestaña seleccionada |
