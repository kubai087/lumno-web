Lumno の操作はほとんどキーボードで完結します。初期設定のショートカット、変更方法、コマンドバーで使える便利なキーをまとめました。

## 初期設定のショートカット {#defaults}

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| コマンドバーを開く | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 最近のタブ切り替えを開く | `⌥ Q` | `Alt + Q` |
| 現在のページ URL を入力して開く | 自分で設定 | 自分で設定 |
| 現在のページ URL をコピー | 自分で設定 | 自分で設定 |

下の 2 つは、インストール直後は「未設定」になっていることがあります。次の手順で割り当ててください。

## ショートカットを変更する {#change}

拡張機能のショートカットは、ブラウザのショートカット設定ページで変更します。

1. アドレスバーに `chrome://extensions/shortcuts`（Edge では `edge://extensions/shortcuts`）と入力します。
2. Lumno の変更したい項目の右にある鉛筆アイコンをクリックします。
3. 新しいキーの組み合わせを押します。

![ブラウザの拡張機能のショートカット設定ページ。Lumno の「Lumnoを開く」が ⇧⌘K、「最近のタブ切り替えを開く」が ⌥Q](shortcuts "拡張機能のショートカット設定ページで変更")

Arc に慣れているなら、「Lumnoを開く」を `⌘ T` にすると、いつもの手触りになります。

Dia でショートカットが反応しないときは、右側の範囲を「Dia 内」から「グローバル」に変えてください。

## コマンドバーのキー {#command-bar-keys}

| キー | 動作 |
| --- | --- |
| `↑` `↓` | 結果を選ぶ |
| `↩` | 結果を開く、または開いているタブに切り替える |
| `⌥ ↩` | 新しいタブではなく、現在のタブで開く |
| `⇧ ↩` | 開いているタブの結果を、新しいタブでもうひとつ開く |
| `Tab` | 略称のあとならサイト内検索、空の検索ボックスなら開いているタブだけを検索 |
| `Tab` `Tab` | 空の検索ボックスで検索範囲パネルを開く |
| `Esc` | サイト内検索をやめる、またはコマンドバーを閉じる |

## 切り替え画面のキー {#switcher-keys}

| キー | 動作 |
| --- | --- |
| `⌥` を押したまま `Q` | 最近のタブを順に移動 |
| `Tab` または矢印キー | 選択を移動 |
| `⌥` を離す、または `↩` | 選んだタブに切り替え |
