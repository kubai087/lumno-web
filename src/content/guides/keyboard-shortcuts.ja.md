Lumno のほとんどの操作はキーボードで行えます。このページでは、初期設定のショートカット、変更方法、コマンドバー・新しいタブ・切り替え画面・Webクリップで使用できるキーを紹介します。クリックでも同じ操作ができる場合は、キーと並べて記載しています。

## 初期設定のショートカット {#defaults}

| 操作 | ショートカット |
| --- | --- |
| コマンドバーを開く | `⌘ ⇧ K` |
| 最近のタブ切り替えを開く | `⌥ Q` |
| 現在のページの URL を入力した状態でコマンドバーを開く | 初期設定なし |
| 現在のページの URL をコピー | 初期設定なし |

下の 2 つは、インストール直後に「未設定」と表示される場合があります。次の手順でショートカットを割り当ててください。Firefox 版では、コマンドバーを開く初期設定のショートカットが異なります。詳しくは、[ブラウザ互換性](../browser-compatibility/#firefox)を参照してください。

## ショートカットを変更する {#change}

拡張機能のショートカットは、ブラウザのショートカット設定ページで変更します。

1. アドレスバーに `chrome://extensions/shortcuts`（Edge では `edge://extensions/shortcuts`）と入力します。
2. Lumno を見つけ、変更したい項目の右にある鉛筆アイコンをクリックします。
3. 新しいキーの組み合わせを押します。

![ブラウザの拡張機能のショートカット設定ページ。Lumno の「Lumnoを開く」が ⇧⌘K、「最近のタブ切り替えを開く」が ⌥Q](shortcuts "拡張機能のショートカット設定ページで変更")

[Arc](https://arc.net/) や [Zen](https://zen-browser.app/) の操作に慣れている場合は、「Lumnoを開く」を `⌘ T` に変更できます。

Dia でショートカットキーが反応しない場合は、項目の右側にある範囲を「Dia 内」から「グローバル」に変更してください。

## コマンドバーで使用できるキー {#command-bar-keys}

### 結果を選択する

| キー | 動作 |
| --- | --- |
| `↑` `↓` | 選択中の結果を上下に移動する |
| `⌘` を長押しして離し、`0`–`9` を押す | 結果の横に番号が表示され、数字を押すとその結果を開く |

設定の「ラボ機能」で「Command 単押しで数字ジャンプ表示」をオンにすると、`⌘` を 1 回押すだけで番号が表示され、`⌘` を押したまま数字を押すと開きます。この場合、`⌘` はバックグラウンドで開く操作には使われなくなります。中クリックは引き続き使えます。

macOS では、「ラボ機能」で「Mac キーボードナビゲーション」をオンにすると、`⌃ N | ⌃ N` と `⌃ P | ⌃ P` で次と前の結果を選択できます。

### 結果を開く

| キーまたはクリック | 動作 |
| --- | --- |
| `↩` または結果をクリック | 結果を開く、または開いているタブに切り替える |
| `⌥ ↩` または `⌥` を押しながらクリック | 新しいタブではなく、現在のタブで開く |
| `⇧ ↩` または `⇧` を押しながらクリック | 結果が開いているタブの場合、新しいタブでもう 1 つ開く |
| `⌘ ↩`、`⌘` を押しながらクリック、または中クリック | バックグラウンドのタブで開く。コマンドバーは開いたままなので、続けて次の結果を開ける |

`⌥`、`⇧`、`⌘` を押している間は、結果の右側に表示される操作のヒントがそれに合わせて変わります。

### 入力と検索モード

| キー | 動作 |
| --- | --- |
| `Tab` | 候補を補完する。略称の入力後はサイト内検索を開始する。検索ボックスが空のときは、開いているタブだけを検索する |
| `Tab` `Tab` | 検索ボックスが空のときに 2 回押すと、検索範囲パネルを開く。検索範囲を選択済みの場合は 1 回押すだけで開く |
| `⌥ ↑` `⌥ ↓` | 以前に入力した内容を前後に切り替える |
| `⌘ Z` `⌘ ⇧ Z` | 検索範囲パネルが開いているとき、検索ソースの並び順の変更を取り消す、またはやり直す |
| `⌫` | 検索ボックスが空のとき、サイト内検索、検索範囲、開いているタブの検索を終了する |
| `Esc` | サイト内検索、検索範囲、開いているタブの検索を終了する |
| `Esc` またはコマンドバーの外側をクリック | コマンドバーを閉じる |

## 新しいタブで使用できるキー {#newtab-keys}

新しいタブの検索ボックスでは、コマンドバーと同じキーを使用できます。そのほかの操作は次のとおりです。

| キーまたはクリック | 動作 |
| --- | --- |
| そのまま入力する | 検索ボックスをクリックしなくても、入力した文字が検索ボックスに入る |
| 検索結果、ショートカット、ブックマーク、サイトカードをクリック | 初期設定では現在のタブで開く。設定の「一般 → 新しいタブ設定 → 新しいタブで開く」でオンにすると新しいタブで開く |
| `⌘` を押しながらクリック、または中クリック | バックグラウンドのタブで開く |
| `⌥ ←` `⌥ →` | `Tab` キーでショートカットを選択したあと、1 つ前または後ろへ移動する |
| `⌘ Z` | ショートカットやブックマークに対する直前の操作（削除、移動、フォルダの作成、グループの削除など）を取り消す |
| `⌘ ⇧ Z` | 取り消した操作をやり直す |
| `Esc` | ショートカットやブックマークのドラッグをキャンセルする |

## 切り替え画面で使用できるキー {#switcher-keys}

| キーまたはクリック | 動作 |
| --- | --- |
| `⌥` を押したまま `Q` を繰り返し押す | 最近のタブを順に移動する |
| `Tab`、`→`、`↓` | 次のタブを選択する |
| `⇧ Tab`、`←`、`↑` | 前のタブを選択する |
| `⌥` を離す、`↩` を押す、またはタブをクリック | 選択したタブに切り替える |
| ページのプレビューの角にある閉じるボタンをクリック | そのタブを閉じる。切り替え画面は開いたまま |
| `Esc` または切り替え画面の外側をクリック | 切り替え画面を閉じ、現在のタブに留まる |

切り替え画面のショートカットを変更した場合は、設定したショートカットの修飾キーを押したままにします。

## Webクリップで使用できるキー {#web-clip-keys}

クリップする内容を選んでいるとき：

| キーまたは操作 | 動作 |
| --- | --- |
| `[` または `↑` | 外側の要素を選択する |
| `]` または `↓` | 内側の要素を選択する |
| マウスホイールをスクロール | 外側と内側の要素を切り替える |
| `↩` または枠で囲まれた内容をクリック | フローティングウインドウで開く |
| `Esc` | 選択をキャンセルする |

フローティングウインドウ内のリンクをクリックすると、新しいタブで開きます。`⌘` を押しながらクリックすると、バックグラウンドで開きます。詳しくは、[Webクリップ](../web-clip/)を参照してください。
