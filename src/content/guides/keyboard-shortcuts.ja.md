Lumno のほとんどの操作はキーボードで行えます。このページでは、初期設定のショートカット、変更方法、コマンドバーと切り替え画面で使用できるキーを紹介します。

## 初期設定のショートカット {#defaults}

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| コマンドバーを開く | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 最近のタブ切り替えを開く | `⌥ Q` | `Alt + Q` |
| 現在のページの URL を入力した状態でコマンドバーを開く | 初期設定なし | 初期設定なし |
| 現在のページの URL をコピー | 初期設定なし | 初期設定なし |

下の 2 つは、インストール直後に「未設定」と表示される場合があります。次の手順でショートカットを割り当ててください。

## ショートカットを変更する {#change}

拡張機能のショートカットは、ブラウザのショートカット設定ページで変更します。

1. アドレスバーに `chrome://extensions/shortcuts`（Edge では `edge://extensions/shortcuts`）と入力します。
2. Lumno を見つけ、変更したい項目の右にある鉛筆アイコンをクリックします。
3. 新しいキーの組み合わせを押します。

![ブラウザの拡張機能のショートカット設定ページ。Lumno の「Lumnoを開く」が ⇧⌘K、「最近のタブ切り替えを開く」が ⌥Q](shortcuts "拡張機能のショートカット設定ページで変更")

[Arc](https://arc.net/) や [Zen](https://zen-browser.app/) の操作に慣れている場合は、「Lumnoを開く」を `⌘ T` に変更できます。

Dia でショートカットキーが反応しない場合は、項目の右側にある範囲を「Dia 内」から「グローバル」に変更してください。

## コマンドバーで使用できるキー {#command-bar-keys}

| キー | 動作 |
| --- | --- |
| `↑` `↓` | 結果を選択する |
| `↩` | 結果を開く、または開いているタブに切り替える |
| `⌥ ↩` | 新しいタブではなく、現在のタブで開く |
| `⇧ ↩` | 結果が開いているタブの場合、新しいタブでもう 1 つ開く |
| `Tab` | 略称の入力後はサイト内検索を開始する。検索ボックスが空のときは、開いているタブだけを検索する |
| `Tab` `Tab` | 検索ボックスが空のときに 2 回押すと、検索範囲パネルを開く |
| `Esc` | サイト内検索を終了する、またはコマンドバーを閉じる |

## 切り替え画面で使用できるキー {#switcher-keys}

| キー | 動作 |
| --- | --- |
| `⌥` を押したまま `Q` を繰り返し押す | 最近のタブを順に移動する |
| `Tab` または矢印キー | 選択を移動する |
| `⌥` を離す、または `↩` を押す | 選択したタブに切り替える |
