Lumno는 대부분 키보드로 써요. 기본 단축키, 바꾸는 방법, 명령 바 안에서 쓰기 좋은 키를 정리했습니다.

## 기본 단축키 {#defaults}

| 동작 | macOS | Windows / Linux |
| --- | --- | --- |
| 명령 바 열기 | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 최근 탭 전환기 열기 | `⌥ Q` | `Alt + Q` |
| 현재 페이지 URL을 넣어 명령 바 열기 | 직접 설정 | 직접 설정 |
| 현재 페이지 URL 복사 | 직접 설정 | 직접 설정 |

아래 두 개는 설치 직후 "설정되지 않음"으로 보일 수 있어요. 아래 방법으로 단축키를 지정하세요.

## 단축키 바꾸기 {#change}

확장 프로그램 단축키는 브라우저가 전용 페이지에서 관리해요.

1. 주소창에 `chrome://extensions/shortcuts`를 입력하세요(Edge는 `edge://extensions/shortcuts`).
2. Lumno를 찾아 바꾸려는 동작 옆의 연필 아이콘을 누르세요.
3. 새 키 조합을 누르세요.

![브라우저의 확장 프로그램 단축키 페이지. Lumno의 "Open command bar"는 ⇧⌘K, "Open recent tab switcher"는 ⌥Q로 설정되어 있다](shortcuts "확장 프로그램 페이지에서 단축키 바꾸기")

Arc에서 오셨나요? "Open command bar"를 `⌘ T`로 바꾸면 집에 온 것처럼 편해요.

Dia에서 단축키가 동작하지 않으면 옆에 있는 범위를 "In Dia"에서 "Global"로 바꾸세요.

## 명령 바 안의 키 {#command-bar-keys}

| 키 | 동작 |
| --- | --- |
| `↑` `↓` | 결과 사이 이동 |
| `↩` | 결과 열기, 또는 열린 탭으로 전환 |
| `⌥ ↩` | 새 탭 대신 현재 탭에서 열기 |
| `⇧ ↩` | 열린 탭을 새 탭에서 하나 더 열기 |
| `Tab` | 사이트 단축어 뒤에서는 사이트 검색 시작, 빈 검색창에서는 열린 탭만 검색 |
| `Tab` `Tab` | 빈 검색창에서 검색 범위 패널 열기 |
| `Esc` | 사이트 검색에서 나가기, 또는 명령 바 닫기 |

## 전환기 안의 키 {#switcher-keys}

| 키 | 동작 |
| --- | --- |
| `⌥`를 누른 채 `Q` | 최근 탭 사이 이동 |
| `Tab` 또는 방향키 | 선택 이동 |
| `⌥`에서 손 떼기, 또는 `↩` | 선택한 탭으로 전환 |
