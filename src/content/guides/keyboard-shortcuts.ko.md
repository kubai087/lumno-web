Lumno의 대부분의 기능은 키보드로 사용할 수 있습니다. 이 페이지에서는 기본 단축키, 단축키 변경 방법, 그리고 명령 바, 새 탭, 전환기, 웹 클립에서 사용할 수 있는 키를 안내합니다. 클릭으로도 같은 동작을 할 수 있다면 키 옆에 함께 적었습니다.

## 기본 단축키 {#defaults}

| 동작 | 단축키 |
| --- | --- |
| 명령 바 열기 | `⌘ ⇧ K` |
| 최근 탭 전환기 열기 | `⌥ Q` |
| 현재 페이지 URL이 입력된 상태로 명령 바 열기 | 기본값 없음 |
| 현재 페이지 URL 복사 | 기본값 없음 |

아래 두 항목은 설치 직후 "설정되지 않음"으로 표시될 수 있습니다. 다음 방법으로 단축키를 지정하세요. Firefox 버전은 명령 바를 여는 기본 단축키가 다릅니다. 자세한 내용은 [브라우저 호환성](../browser-compatibility/#firefox)을 참고하세요.

## 단축키 변경하기 {#change}

확장 프로그램 단축키는 브라우저의 별도 페이지에서 관리합니다.

1. 주소창에 `chrome://extensions/shortcuts`를 입력하세요(Edge에서는 `edge://extensions/shortcuts`).
2. Lumno를 찾아 변경할 동작 옆의 연필 아이콘을 클릭하세요.
3. 새 키 조합을 누르세요.

![브라우저의 확장 프로그램 단축키 페이지. Lumno의 "Open command bar"는 ⇧⌘K, "Open recent tab switcher"는 ⌥Q로 설정되어 있다](shortcuts "확장 프로그램 페이지에서 단축키 변경하기")

[Arc](https://arc.net/)나 [Zen](https://zen-browser.app/) 사용 방식에 익숙하다면 "Open command bar"를 `⌘ T`로 변경할 수 있습니다.

단축키 페이지에서는 `⌃ Tab`을 등록할 수 없습니다. 이 키로 전환기를 열려면 [Ctrl+Tab으로 전환기 열기](../tab-switcher/#ctrl-tab)를 참고하세요.

Dia에서 단축키가 작동하지 않으면 항목 옆의 범위를 "In Dia"에서 "Global"로 변경하세요.

## 명령 바의 키 {#command-bar-keys}

### 결과 선택

| 키 | 동작 |
| --- | --- |
| `↑` `↓` | 선택한 결과를 위아래로 이동 |
| `⌘`를 길게 눌렀다 뗀 다음 `0`–`9` 누르기 | 결과 옆에 번호가 표시되며, 숫자를 누르면 해당 결과가 열림 |

설정의 "Labs"에서 "Single-press Command to show number jump"를 켜면 `⌘`를 한 번만 눌러도 번호가 표시되고, `⌘`를 누른 채 숫자를 누르면 결과가 열립니다. 이 경우 `⌘`는 더 이상 백그라운드에서 열기에 사용되지 않으며, 마우스 가운데 버튼 클릭은 그대로 사용할 수 있습니다.

macOS에서는 "Labs"에서 "Mac keyboard navigation"을 켜고 `⌃ N | ⌃ N`과 `⌃ P | ⌃ P`로 다음 결과와 이전 결과를 선택할 수도 있습니다.

### 결과 열기

| 키 또는 클릭 | 동작 |
| --- | --- |
| `↩` 또는 결과 클릭 | 결과 열기 또는 열린 탭으로 전환 |
| `⌥ ↩` 또는 `⌥`를 누른 채 클릭 | 새 탭 대신 현재 탭에서 열기 |
| `⇧ ↩` 또는 `⇧`를 누른 채 클릭 | 결과가 열린 탭인 경우 새 탭에서 하나 더 열기 |
| `⌘ ↩`, `⌘`를 누른 채 클릭 또는 마우스 가운데 버튼 클릭 | 백그라운드 탭에서 열기. 명령 바가 열린 채로 유지되어 다음 결과를 이어서 열 수 있음 |

`⌥`, `⇧`, `⌘`를 누르고 있으면 결과 오른쪽의 동작 안내가 그에 맞게 바뀝니다.

### 입력과 검색 모드

| 키 | 동작 |
| --- | --- |
| `Tab` | 추천 항목 자동 완성, 사이트 단축어 입력 후에는 사이트 검색 시작, 검색창이 비어 있으면 열린 탭만 검색 |
| `Tab` `Tab` | 검색창이 비어 있을 때 두 번 누르면 검색 범위 패널 열기. 검색 범위를 이미 선택했다면 한 번만 누르면 됨 |
| `⌥ ↑` `⌥ ↓` | 이전 또는 다음 입력 내용으로 전환 |
| `⌘ Z` `⌘ ⇧ Z` | 검색 범위 패널이 열려 있을 때 검색 소스 순서 변경을 실행 취소하거나 다시 실행 |
| `⌫` | 검색창이 비어 있을 때 사이트 검색, 검색 범위, 열린 탭 검색 종료 |
| `Esc` | 사이트 검색, 검색 범위, 열린 탭 검색 종료 |
| `Esc` 또는 명령 바 바깥 클릭 | 명령 바 닫기 |

## 새 탭의 키 {#newtab-keys}

새 탭의 검색창에서는 명령 바와 같은 키를 사용할 수 있습니다. 그 밖의 동작은 다음과 같습니다.

| 키 또는 클릭 | 동작 |
| --- | --- |
| 바로 입력하기 | 검색창을 먼저 클릭하지 않아도 입력한 글자가 검색창에 들어감 |
| 검색 결과, 바로가기, 북마크, 사이트 카드 클릭 | 기본적으로 현재 탭에서 열기. 설정의 General → New Tab Settings → Open in a new tab에서 켜면 새 탭에서 열기 |
| `⌘`를 누른 채 클릭 또는 마우스 가운데 버튼 클릭 | 백그라운드 탭에서 열기 |
| `⌥ ←` `⌥ →` | `Tab` 키로 바로가기를 선택한 다음 한 칸 앞이나 뒤로 이동 |
| `⌘ Z` | 바로가기나 북마크에 대한 마지막 작업(삭제, 이동, 폴더 만들기, 그룹 삭제 등) 실행 취소 |
| `⌘ ⇧ Z` | 방금 실행 취소한 작업 다시 실행 |
| `Esc` | 바로가기나 북마크를 드래그하는 중에 드래그 취소 |

## 전환기의 키 {#switcher-keys}

| 키 또는 클릭 | 동작 |
| --- | --- |
| `⌥`를 누른 채 `Q`를 반복해서 누르기 | 최근 탭 사이 이동 |
| `Tab`, `→` 또는 `↓` | 다음 탭 선택 |
| `⇧ Tab`, `←` 또는 `↑` | 이전 탭 선택 |
| `⌥`에서 손 떼기, `↩` 누르기 또는 탭 클릭 | 선택한 탭으로 전환 |
| 페이지 미리보기 모서리의 닫기 버튼 클릭 | 해당 탭 닫기. 전환기는 열린 채로 유지 |
| `Esc` 또는 전환기 바깥 클릭 | 전환기를 닫고 현재 탭에 머무르기 |

전환기 단축키를 변경했다면 직접 지정한 단축키의 보조 키를 누른 채로 사용하세요.

## 웹 클립의 키 {#web-clip-keys}

잘라 낼 내용을 고르는 동안:

| 키 또는 동작 | 동작 |
| --- | --- |
| `[` 또는 `↑` | 바깥쪽 요소 선택 |
| `]` 또는 `↓` | 안쪽 요소 선택 |
| 마우스 휠 스크롤 | 바깥쪽 요소와 안쪽 요소 사이 전환 |
| `↩` 또는 테두리로 둘러싸인 내용 클릭 | 플로팅 창에서 열기 |
| `Esc` | 선택 취소 |

플로팅 창에서 링크를 클릭하면 새 탭에서 열리고, `⌘`를 누른 채 클릭하면 백그라운드에서 열립니다. 자세한 내용은 [웹 클립](../web-clip/)을 참고하세요.
