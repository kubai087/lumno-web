Lumno의 대부분의 기능은 키보드로 사용할 수 있습니다. 이 페이지에서는 기본 단축키, 단축키 변경 방법, 명령 바와 전환기에서 사용할 수 있는 키를 안내합니다.

## 기본 단축키 {#defaults}

| 동작 | macOS | Windows / Linux |
| --- | --- | --- |
| 명령 바 열기 | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 최근 탭 전환기 열기 | `⌥ Q` | `Alt + Q` |
| 현재 페이지 URL이 입력된 상태로 명령 바 열기 | 기본값 없음 | 기본값 없음 |
| 현재 페이지 URL 복사 | 기본값 없음 | 기본값 없음 |

아래 두 항목은 설치 직후 "설정되지 않음"으로 표시될 수 있습니다. 다음 방법으로 단축키를 지정하세요.

## 단축키 변경하기 {#change}

확장 프로그램 단축키는 브라우저의 별도 페이지에서 관리합니다.

1. 주소창에 `chrome://extensions/shortcuts`를 입력하세요(Edge에서는 `edge://extensions/shortcuts`).
2. Lumno를 찾아 변경할 동작 옆의 연필 아이콘을 클릭하세요.
3. 새 키 조합을 누르세요.

![브라우저의 확장 프로그램 단축키 페이지. Lumno의 "Open command bar"는 ⇧⌘K, "Open recent tab switcher"는 ⌥Q로 설정되어 있다](shortcuts "확장 프로그램 페이지에서 단축키 변경하기")

Arc 사용 방식에 익숙하다면 "Open command bar"를 `⌘ T`로 변경할 수 있습니다.

Dia에서 단축키가 작동하지 않으면 항목 옆의 범위를 "In Dia"에서 "Global"로 변경하세요.

## 명령 바의 키 {#command-bar-keys}

| 키 | 동작 |
| --- | --- |
| `↑` `↓` | 결과 선택 |
| `↩` | 결과 열기 또는 열린 탭으로 전환 |
| `⌥ ↩` | 새 탭 대신 현재 탭에서 열기 |
| `⇧ ↩` | 결과가 열린 탭인 경우 새 탭에서 하나 더 열기 |
| `Tab` | 사이트 단축어 입력 후에는 사이트 검색 시작, 검색창이 비어 있으면 열린 탭만 검색 |
| `Tab` `Tab` | 검색창이 비어 있을 때 검색 범위 패널 열기 |
| `Esc` | 사이트 검색 종료 또는 명령 바 닫기 |

## 전환기의 키 {#switcher-keys}

| 키 | 동작 |
| --- | --- |
| `⌥`를 누른 채 `Q`를 반복해서 누르기 | 최근 탭 사이 이동 |
| `Tab` 또는 방향키 | 선택 이동 |
| `⌥`에서 손 떼기 또는 `↩` 누르기 | 선택한 탭으로 전환 |
