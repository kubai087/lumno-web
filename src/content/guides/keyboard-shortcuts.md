Lumno 的大部分操作都在键盘上完成。这里是默认快捷键、怎么改，以及命令栏里那些顺手的按键。

## 默认快捷键 {#defaults}

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 唤出命令栏 | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 打开最近标签页切换器 | `⌥ Q` | `Alt + Q` |
| 唤出命令栏并预填当前网页链接 | 需自行设置 | 需自行设置 |
| 复制当前网页链接 | 需自行设置 | 需自行设置 |

后两项刚装好时可能显示「未设置」，按下面的方法给它们配一个就行。

## 修改快捷键 {#change}

受浏览器限制，扩展的快捷键要在浏览器的快捷键页面里改：

1. 在地址栏输入 `chrome://extensions/shortcuts`（Edge 里是 `edge://extensions/shortcuts`）。
2. 找到 Lumno，点想修改的那一项右边的铅笔图标。
3. 按下新的组合键。

![浏览器的扩展快捷键页面，Lumno 的“唤起聚焦搜索窗口”为 ⇧⌘K，“打开最近标签页切换器”为 ⌥Q](shortcuts "在扩展快捷键页面修改")

用惯了 Arc？把「唤起聚焦搜索窗口」改成 `⌘ T`，就是熟悉的手感。

在 Dia 里按快捷键没反应的话，把这一项右边的范围从「在 Dia 中」改成「全局」。

## 命令栏里的按键 {#command-bar-keys}

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 选择结果 |
| `↩` | 打开结果，或切换到已打开的标签页 |
| `⌥ ↩` | 在当前标签页打开，不新开 |
| `⇧ ↩` | 结果是已打开的标签页时，在新标签页里再开一份 |
| `Tab` | 输入简称后进入站内搜索；搜索框为空时只搜已打开的标签页 |
| `Tab` `Tab` | 搜索框为空时连按两下，打开搜索范围面板 |
| `Esc` | 退出站内搜索，或关闭命令栏 |

## 切换器里的按键 {#switcher-keys}

| 按键 | 作用 |
| --- | --- |
| 按住 `⌥`，连按 `Q` | 在最近的标签页之间移动 |
| `Tab` 或方向键 | 移动选择 |
| 松开 `⌥` 或按 `↩` | 切换到选中的标签页 |
