Lumno 的大部分操作都可以用键盘完成。下面是默认快捷键、修改方法，以及命令栏、新标签页、切换器和网页剪裁中的按键；能用鼠标完成的操作，也一并写在按键旁边。

## 默认快捷键 {#defaults}

| 操作 | 快捷键 |
| --- | --- |
| 唤出命令栏 | `⌘ ⇧ K` |
| 打开最近标签页切换器 | `⌥ Q` |
| 唤出命令栏并预填当前网页链接 | 需自行设置 |
| 复制当前网页链接 | 需自行设置 |

后两项在安装后可能显示为「未设置」，可以按照下文的方法为它们设置快捷键。Firefox 版唤出命令栏的默认快捷键不同，详见[浏览器兼容性](../browser-compatibility/#firefox)。

## 修改快捷键 {#change}

受浏览器限制，扩展的快捷键需要在浏览器的快捷键页面中修改：

1. 在地址栏中输入 `chrome://extensions/shortcuts`（Edge 中为 `edge://extensions/shortcuts`）。
2. 找到 Lumno，点击要修改的项目右侧的铅笔图标。
3. 按下新的组合键。

![浏览器的扩展快捷键页面，Lumno 的“唤起聚焦搜索窗口”为 ⇧⌘K，“打开最近标签页切换器”为 ⌥Q](shortcuts "在扩展快捷键页面中修改")

如果习惯了 [Arc](https://arc.net/) 或 [Zen](https://zen-browser.app/) 的操作，可以把「唤起聚焦搜索窗口」改为 `⌘ T`。

在 Dia 中按下快捷键没有反应时，请将该项右侧的范围从「在 Dia 中」改为「全局」。

## 命令栏中的按键 {#command-bar-keys}

### 选择结果

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 上下移动选中的结果 |
| 长按 `⌘` 后松开，再按 `0`–`9` | 结果旁会出现编号，按下数字即可打开对应的结果 |

在设置的「实验室功能」中开启「单按 Command 显示数字跳转」后，按一下 `⌘` 就会出现编号，按住 `⌘` 再按数字即可打开。开启后，`⌘` 不再用于在后台打开结果，鼠标中键不受影响。

在 macOS 上，还可以在「实验室功能」中开启「Mac 键盘导航」，用 `⌃ N | ⌃ N` 和 `⌃ P | ⌃ P` 选择下一项和上一项。

### 打开结果

| 按键或点击 | 作用 |
| --- | --- |
| `↩` 或点击结果 | 打开结果，或切换到已打开的标签页 |
| `⌥ ↩` 或按住 `⌥` 点击结果 | 在当前标签页中打开，不新建标签页 |
| `⇧ ↩` 或按住 `⇧` 点击结果 | 结果为已打开的标签页时，在新标签页中再打开一份 |
| `⌘ ↩`、按住 `⌘` 点击结果，或用鼠标中键点击结果 | 在后台标签页中打开；命令栏保持打开，可以接着打开下一个 |

按住 `⌥`、`⇧` 或 `⌘` 时，结果右侧的操作提示会随之变化。

### 输入与搜索模式

| 按键 | 作用 |
| --- | --- |
| `Tab` | 补全候选；输入简称后进入站内搜索；搜索框为空时，只搜索已打开的标签页 |
| `Tab` `Tab` | 搜索框为空时连按两次，打开搜索范围面板；已选择搜索范围时，按一次即可 |
| `⌥ ↑` `⌥ ↓` | 切换到上一条或下一条输入过的内容 |
| `⌫` | 搜索框为空时，退出站内搜索、搜索范围或已打开标签页搜索 |
| `Esc` | 退出站内搜索、搜索范围或已打开标签页搜索 |
| `Esc` 或点击命令栏以外的区域 | 关闭命令栏 |

## 新标签页中的按键 {#newtab-keys}

新标签页搜索框中的按键与命令栏相同。此外：

| 按键或点击 | 作用 |
| --- | --- |
| 直接输入 | 不用先点击搜索框，文字会直接输入到搜索框中 |
| 点击搜索结果、快捷方式、书签或站点卡片 | 默认在当前标签页中打开；在设置的「常规 → 新标签页设置 → 在新标签页打开」中开启后，改为新开标签页 |
| 按住 `⌘` 点击，或用鼠标中键点击 | 在后台标签页中打开 |
| `⌘ Z` | 撤销对快捷方式或书签的上一步操作，例如移除、移动或新建文件夹 |
| `⌘ ⇧ Z` | 重做刚才撤销的操作 |
| `Esc` | 拖动快捷方式或书签时，取消拖动 |

## 切换器中的按键 {#switcher-keys}

| 按键或点击 | 作用 |
| --- | --- |
| 按住 `⌥`，连按 `Q` | 在最近的标签页之间依次移动 |
| `Tab`、`→` 或 `↓` | 选中下一个标签页 |
| `⇧ Tab`、`←` 或 `↑` | 选中上一个标签页 |
| 松开 `⌥`、按 `↩`，或点击标签页 | 切换到选中的标签页 |
| `Esc` 或点击切换器以外的区域 | 关闭切换器，留在当前标签页 |

如果修改过切换器的快捷键，需要按住的是你设置的组合键中的修饰键。

## 网页剪裁中的按键 {#web-clip-keys}

选择要剪下的内容时：

| 按键或操作 | 作用 |
| --- | --- |
| `[` 或 `↑` | 选择外层元素 |
| `]` 或 `↓` | 选择内层元素 |
| 滚动鼠标滚轮 | 在外层和内层元素之间切换 |
| `↩` 或点击框住的内容 | 在悬浮窗口中打开 |
| `Esc` | 取消选择 |

在悬浮窗口中点击链接，会新开一个标签页；按住 `⌘` 点击，则在后台打开。详见[网页剪裁](../web-clip/)。
