Lumno 的大部分操作都可以用键盘完成。下面是默认快捷键、修改方法，以及命令栏和切换器中的按键。

## 默认快捷键 {#defaults}

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 唤出命令栏 | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 打开最近标签页切换器 | `⌥ Q` | `Alt + Q` |
| 唤出命令栏并预填当前网页链接 | 需自行设置 | 需自行设置 |
| 复制当前网页链接 | 需自行设置 | 需自行设置 |

后两项在安装后可能显示为「未设置」，可以按照下文的方法为它们设置快捷键。

## 修改快捷键 {#change}

受浏览器限制，扩展的快捷键需要在浏览器的快捷键页面中修改：

1. 在地址栏中输入 `chrome://extensions/shortcuts`（Edge 中为 `edge://extensions/shortcuts`）。
2. 找到 Lumno，点击要修改的项目右侧的铅笔图标。
3. 按下新的组合键。

![浏览器的扩展快捷键页面，Lumno 的“唤起聚焦搜索窗口”为 ⇧⌘K，“打开最近标签页切换器”为 ⌥Q](shortcuts "在扩展快捷键页面中修改")

如果习惯了 Arc 的操作，可以把「唤起聚焦搜索窗口」改为 `⌘ T`。

在 Dia 中按下快捷键没有反应时，请将该项右侧的范围从「在 Dia 中」改为「全局」。

## 命令栏中的按键 {#command-bar-keys}

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 选择结果 |
| `↩` | 打开结果，或切换到已打开的标签页 |
| `⌥ ↩` | 在当前标签页中打开，不新建标签页 |
| `⇧ ↩` | 结果为已打开的标签页时，在新标签页中再打开一份 |
| `Tab` | 输入简称后进入站内搜索；搜索框为空时，只搜索已打开的标签页 |
| `Tab` `Tab` | 搜索框为空时连按两次，打开搜索范围面板 |
| `Esc` | 退出站内搜索，或关闭命令栏 |

## 切换器中的按键 {#switcher-keys}

| 按键 | 作用 |
| --- | --- |
| 按住 `⌥`，连按 `Q` | 在最近的标签页之间移动 |
| `Tab` 或方向键 | 移动选中项 |
| 松开 `⌥` 或按 `↩` | 切换到选中的标签页 |
