A maioria dos recursos do Lumno pode ser usada pelo teclado. Esta página mostra os atalhos padrão, como alterá-los e as teclas que você pode usar na barra de comandos e no alternador de guias.

## Atalhos padrão {#defaults}

| Ação | macOS | Windows / Linux |
| --- | --- | --- |
| Abrir a barra de comandos | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| Abrir o alternador de guias recentes | `⌥ Q` | `Alt + Q` |
| Abrir a barra de comandos com a URL da página atual | Sem atalho padrão | Sem atalho padrão |
| Copiar a URL da página atual | Sem atalho padrão | Sem atalho padrão |

As duas últimas ações podem aparecer como "Não definido" após a instalação. Para atribuir atalhos a elas, siga as etapas abaixo.

## Alterar um atalho {#change}

Os navegadores gerenciam os atalhos das extensões em uma página própria:

1. Digite `chrome://extensions/shortcuts` na barra de endereço (`edge://extensions/shortcuts` no Edge).
2. Localize o Lumno e clique no ícone de lápis ao lado da ação que deseja alterar.
3. Pressione a nova combinação de teclas.

![A página de atalhos de extensões do navegador, com "Open command bar" do Lumno em ⇧⌘K e "Open recent tab switcher" em ⌥Q](shortcuts "Alterar atalhos na página de extensões")

Se você estiver acostumado com o [Arc](https://arc.net/) ou o [Zen](https://zen-browser.app/), pode atribuir `⌘ T` a "Open command bar".

Se o atalho não funcionar no Dia, altere o escopo ao lado dele de "In Dia" para "Global".

## Teclas da barra de comandos {#command-bar-keys}

| Tecla | Ação |
| --- | --- |
| `↑` `↓` | Selecionar um resultado |
| `↩` | Abrir um resultado ou alternar para uma guia aberta |
| `⌥ ↩` | Abrir na guia atual em vez de em uma nova guia |
| `⇧ ↩` | Se o resultado for uma guia aberta, abri-la novamente em uma nova guia |
| `Tab` | Depois de um atalho de site, iniciar a pesquisa no site; com a caixa vazia, pesquisar apenas nas guias abertas |
| `Tab` `Tab` | Com a caixa vazia, abrir o painel de escopo de pesquisa |
| `Esc` | Sair da pesquisa no site ou fechar a barra de comandos |

## Teclas do alternador de guias {#switcher-keys}

| Tecla | Ação |
| --- | --- |
| Manter `⌥` pressionada e pressionar `Q` várias vezes | Percorrer as guias recentes |
| `Tab` ou teclas de seta | Mover a seleção |
| Soltar `⌥` ou pressionar `↩` | Alternar para a guia selecionada |
