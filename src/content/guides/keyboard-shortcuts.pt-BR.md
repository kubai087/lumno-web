Quase tudo no Lumno acontece pelo teclado. Aqui estão os atalhos padrão, como mudá-los e as teclas úteis dentro da barra de comandos.

## Atalhos padrão {#defaults}

| Ação | macOS | Windows / Linux |
| --- | --- | --- |
| Abrir a barra de comandos | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| Abrir o alternador de guias recentes | `⌥ Q` | `Alt + Q` |
| Abrir a barra com a URL da página atual | Você define | Você define |
| Copiar a URL da página atual | Você define | Você define |

Os dois últimos podem aparecer como "Não definido" logo depois da instalação. Dê um atalho a eles do jeito descrito abaixo.

## Mudar um atalho {#change}

Os navegadores gerenciam os atalhos de extensões numa página própria:

1. Digite `chrome://extensions/shortcuts` na barra de endereços (`edge://extensions/shortcuts` no Edge).
2. Encontre o Lumno e clique no lápis ao lado da ação que você quer mudar.
3. Aperte a nova combinação de teclas.

![A página de atalhos de extensões do navegador, com "Open command bar" do Lumno em ⇧⌘K e "Open recent tab switcher" em ⌥Q](shortcuts "Mudando atalhos na página de extensões")

Veio do Arc? Mude "Open command bar" para `⌘ T` e você vai se sentir em casa.

Se o atalho não fizer nada no Dia, mude o escopo ao lado de "In Dia" para "Global".

## Teclas na barra de comandos {#command-bar-keys}

| Tecla | O que faz |
| --- | --- |
| `↑` `↓` | Percorrer os resultados |
| `↩` | Abrir um resultado ou ir para uma guia aberta |
| `⌥ ↩` | Abrir na guia atual em vez de numa nova |
| `⇧ ↩` | Abrir outra cópia de uma guia aberta numa nova guia |
| `Tab` | Depois de um atalho de site, começar a pesquisa no site; com a caixa vazia, pesquisar só nas guias abertas |
| `Tab` `Tab` | Com a caixa vazia, abrir o painel de escopo de pesquisa |
| `Esc` | Sair da pesquisa no site ou fechar a barra de comandos |

## Teclas no alternador {#switcher-keys}

| Tecla | O que faz |
| --- | --- |
| Segure `⌥` e toque `Q` | Percorrer as guias recentes |
| `Tab` ou setas | Mover a seleção |
| Solte `⌥` ou aperte `↩` | Ir para a guia selecionada |
