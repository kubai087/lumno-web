Большинством функций Lumno можно пользоваться с клавиатуры. На этой странице описаны сочетания клавиш по умолчанию, способ их изменить, а также клавиши, которые работают в командной строке и переключателе вкладок.

## Сочетания клавиш по умолчанию {#defaults}

| Действие | macOS | Windows / Linux |
| --- | --- | --- |
| Открыть командную строку | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| Открыть переключатель недавних вкладок | `⌥ Q` | `Alt + Q` |
| Открыть командную строку с адресом текущей страницы | Не задано по умолчанию | Не задано по умолчанию |
| Скопировать адрес текущей страницы | Не задано по умолчанию | Не задано по умолчанию |

После установки у двух последних действий может быть указано «Не задано». Чтобы назначить им сочетания клавиш, выполните действия, описанные ниже.

## Как изменить сочетание клавиш {#change}

Браузеры управляют сочетаниями клавиш расширений на отдельной странице:

1. Введите в адресной строке `chrome://extensions/shortcuts` (в Edge — `edge://extensions/shortcuts`).
2. Найдите Lumno и нажмите на значок карандаша рядом с действием, которое нужно изменить.
3. Нажмите новое сочетание клавиш.

![Страница сочетаний клавиш для расширений: у Lumno «Open command bar» назначено на ⇧⌘K, а «Open recent tab switcher» — на ⌥Q](shortcuts "Изменение сочетаний клавиш на странице расширений")

Если вы привыкли к Arc, можно назначить действию «Open command bar» сочетание `⌘ T`.

Если в Dia сочетание клавиш не срабатывает, измените область действия рядом с ним с «In Dia» на «Global».

## Клавиши в командной строке {#command-bar-keys}

| Клавиша | Действие |
| --- | --- |
| `↑` `↓` | Выбрать результат |
| `↩` | Открыть результат или перейти к открытой вкладке |
| `⌥ ↩` | Открыть в текущей вкладке, а не в новой |
| `⇧ ↩` | Если результат — открытая вкладка, открыть её ещё раз в новой вкладке |
| `Tab` | После сокращения сайта — начать поиск по сайту; в пустой строке — искать только по открытым вкладкам |
| `Tab` `Tab` | В пустой строке — открыть панель областей поиска |
| `Esc` | Выйти из поиска по сайту или закрыть командную строку |

## Клавиши в переключателе вкладок {#switcher-keys}

| Клавиша | Действие |
| --- | --- |
| Удерживать `⌥` и несколько раз нажать `Q` | Перебирать недавние вкладки |
| `Tab` или клавиши со стрелками | Перемещать выделение |
| Отпустить `⌥` или нажать `↩` | Перейти к выбранной вкладке |
