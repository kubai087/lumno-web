Большинством функций Lumno можно пользоваться с клавиатуры. На этой странице описаны сочетания клавиш по умолчанию, способ их изменить, а также клавиши, которые работают в командной строке, на новой вкладке, в переключателе вкладок и при веб-вырезке. Если то же действие можно выполнить щелчком, он указан рядом с клавишей.

## Сочетания клавиш по умолчанию {#defaults}

| Действие | Сочетание клавиш |
| --- | --- |
| Открыть командную строку | `⌘ ⇧ K` |
| Открыть переключатель недавних вкладок | `⌥ Q` |
| Открыть командную строку с адресом текущей страницы | Не задано по умолчанию |
| Скопировать адрес текущей страницы | Не задано по умолчанию |

После установки у двух последних действий может быть указано «Не задано». Чтобы назначить им сочетания клавиш, выполните действия, описанные ниже. В версии для Firefox командная строка по умолчанию открывается другим сочетанием — подробнее в разделе [Совместимость с браузерами](../browser-compatibility/#firefox).

## Как изменить сочетание клавиш {#change}

Браузеры управляют сочетаниями клавиш расширений на отдельной странице:

1. Введите в адресной строке `chrome://extensions/shortcuts` (в Edge — `edge://extensions/shortcuts`).
2. Найдите Lumno и нажмите на значок карандаша рядом с действием, которое нужно изменить.
3. Нажмите новое сочетание клавиш.

![Страница сочетаний клавиш для расширений: у Lumno «Open command bar» назначено на ⇧⌘K, а «Open recent tab switcher» — на ⌥Q](shortcuts "Изменение сочетаний клавиш на странице расширений")

Если вы привыкли к [Arc](https://arc.net/) или [Zen](https://zen-browser.app/), можно назначить действию «Open command bar» сочетание `⌘ T`.

Страница сочетаний клавиш не принимает `⌃ Tab`. Как открывать им переключатель, описано в разделе [Как открывать переключатель по Ctrl+Tab](../tab-switcher/#ctrl-tab).

Если в Dia сочетание клавиш не срабатывает, измените область действия рядом с ним с «In Dia» на «Global».

## Клавиши в командной строке {#command-bar-keys}

### Выбор результата

| Клавиша | Действие |
| --- | --- |
| `↑` `↓` | Переместить выделение вверх или вниз |
| Удерживать `⌘`, отпустить и нажать `0`–`9` | Рядом с результатами появятся номера; нажмите нужную цифру, чтобы открыть результат |

Если в настройках Lumno в разделе «Labs» включить «Single-press Command to show number jump», номера появятся после одного нажатия `⌘`, а результат открывается нажатием цифры с удерживаемой `⌘`. В этом случае `⌘` больше не открывает результаты в фоне; щелчок средней кнопкой мыши по-прежнему работает.

В macOS можно также включить в разделе «Labs» параметр «Mac keyboard navigation» и выбирать следующий и предыдущий результат сочетаниями `⌃ N | ⌃ N` и `⌃ P | ⌃ P`.

### Открытие результата

| Клавиша или щелчок | Действие |
| --- | --- |
| `↩` или щелчок по результату | Открыть результат или перейти к открытой вкладке |
| `⌥ ↩` или щелчок с удерживаемой `⌥` | Открыть в текущей вкладке, а не в новой |
| `⇧ ↩` или щелчок с удерживаемой `⇧` | Если результат — открытая вкладка, открыть её ещё раз в новой вкладке |
| `⌘ ↩`, щелчок с удерживаемой `⌘` или щелчок средней кнопкой мыши | Открыть в фоновой вкладке; командная строка остаётся открытой, и можно сразу открыть следующий результат |

Пока вы удерживаете `⌥`, `⇧` или `⌘`, подсказка справа от каждого результата меняется соответственно.

### Ввод и режимы поиска

| Клавиша | Действие |
| --- | --- |
| `Tab` | Дополнить подсказку; после сокращения сайта — начать поиск по сайту; в пустой строке — искать только по открытым вкладкам |
| `Tab` `Tab` | В пустой строке — открыть панель областей поиска; если область уже выбрана, достаточно одного нажатия |
| `⌥ ↑` `⌥ ↓` | Вернуться к предыдущему или следующему введённому запросу |
| `⌘ Z` `⌘ ⇧ Z` | При открытой панели областей поиска — отменить или повторить изменение порядка источников поиска |
| `⌫` | В пустой строке — выйти из поиска по сайту, области поиска или поиска по открытым вкладкам |
| `Esc` | Выйти из поиска по сайту, области поиска или поиска по открытым вкладкам |
| `Esc` или щелчок за пределами командной строки | Закрыть командную строку |

## Клавиши на новой вкладке {#newtab-keys}

В строке поиска на новой вкладке работают те же клавиши, что и в командной строке. Кроме того:

| Клавиша или щелчок | Действие |
| --- | --- |
| Просто начните печатать | Текст сразу попадает в строку поиска — щёлкать по ней не нужно |
| Щелчок по результату поиска, ярлыку, закладке или карточке сайта | По умолчанию открыть в текущей вкладке; в новой — если включить это в General → New Tab Settings → Open in a new tab |
| Щелчок с удерживаемой `⌘` или щелчок средней кнопкой мыши | Открыть в фоновой вкладке |
| `⌥ ←` `⌥ →` | Сдвинуть ярлык, выбранный клавишей `Tab`, на одну позицию вперёд или назад |
| `⌘ Z` | Отменить последнее изменение ярлыков или закладок: удаление, перемещение, создание папки, удаление группы и т. п. |
| `⌘ ⇧ Z` | Повторить только что отменённое действие |
| `Esc` | Отменить перетаскивание ярлыка или закладки |

## Клавиши в переключателе вкладок {#switcher-keys}

| Клавиша или щелчок | Действие |
| --- | --- |
| Удерживать `⌥` и несколько раз нажать `Q` | Перебирать недавние вкладки |
| `Tab`, `→` или `↓` | Выбрать следующую вкладку |
| `⇧ Tab`, `←` или `↑` | Выбрать предыдущую вкладку |
| Отпустить `⌥`, нажать `↩` или щёлкнуть по вкладке | Перейти к выбранной вкладке |
| Щелчок по кнопке закрытия в углу предпросмотра | Закрыть эту вкладку; переключатель остаётся открытым |
| `Esc` или щелчок за пределами переключателя | Закрыть переключатель и остаться на текущей вкладке |

Если вы изменили сочетание клавиш переключателя, удерживайте клавишу-модификатор из своего сочетания.

## Клавиши при веб-вырезке {#web-clip-keys}

Пока вы выбираете, что вырезать:

| Клавиша или действие | Действие |
| --- | --- |
| `[` или `↑` | Выбрать внешний элемент |
| `]` или `↓` | Выбрать внутренний элемент |
| Прокрутка колёсика мыши | Переключаться между внешними и внутренними элементами |
| `↩` или щелчок по обведённому содержимому | Открыть в плавающем окне |
| `Esc` | Отменить выбор |

В плавающем окне ссылка по щелчку открывается в новой вкладке; чтобы открыть её в фоне, щёлкните по ней, удерживая `⌘`. Подробнее — в разделе [Веб-вырезка](../web-clip/).
