Почти всё в Lumno делается с клавиатуры. Здесь — сочетания по умолчанию, как их изменить и полезные клавиши в командной строке.

## Сочетания по умолчанию {#defaults}

| Действие | macOS | Windows / Linux |
| --- | --- | --- |
| Открыть командную строку | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| Открыть переключатель недавних вкладок | `⌥ Q` | `Alt + Q` |
| Открыть строку с адресом текущей страницы | Назначьте сами | Назначьте сами |
| Скопировать адрес текущей страницы | Назначьте сами | Назначьте сами |

Сразу после установки у последних двух может стоять «Не задано». Назначьте им сочетания, как описано ниже.

## Как изменить сочетание {#change}

Браузеры управляют сочетаниями клавиш расширений на отдельной странице:

1. Введите в адресной строке `chrome://extensions/shortcuts` (в Edge — `edge://extensions/shortcuts`).
2. Найдите Lumno и нажмите на карандаш рядом с нужным действием.
3. Нажмите новое сочетание клавиш.

![Страница сочетаний клавиш для расширений: у Lumno «Open command bar» назначено на ⇧⌘K, а «Open recent tab switcher» — на ⌥Q](shortcuts "Изменение сочетаний на странице расширений")

Перешли с Arc? Назначьте «Open command bar» на `⌘ T` — и почувствуете себя как дома.

Если в Dia сочетание не срабатывает, переключите область действия рядом с ним с «In Dia» на «Global».

## Клавиши в командной строке {#command-bar-keys}

| Клавиша | Что делает |
| --- | --- |
| `↑` `↓` | Перемещение по результатам |
| `↩` | Открыть результат или перейти к открытой вкладке |
| `⌥ ↩` | Открыть в текущей вкладке, а не в новой |
| `⇧ ↩` | Открыть копию открытой вкладки в новой вкладке |
| `Tab` | После сокращения сайта — начать поиск по сайту; в пустой строке — искать только по открытым вкладкам |
| `Tab` `Tab` | В пустой строке — открыть панель областей поиска |
| `Esc` | Выйти из поиска по сайту или закрыть командную строку |

## Клавиши в переключателе {#switcher-keys}

| Клавиша | Что делает |
| --- | --- |
| Удерживайте `⌥` и нажимайте `Q` | Перебирать недавние вкладки |
| `Tab` или стрелки | Перемещать выделение |
| Отпустите `⌥` или нажмите `↩` | Перейти к выбранной вкладке |
