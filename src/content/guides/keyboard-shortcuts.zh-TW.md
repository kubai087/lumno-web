Lumno 大部分的操作都可以用鍵盤完成。以下是預設快速鍵、修改方式，以及命令列和切換器中的按鍵。

## 預設快速鍵 {#defaults}

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 叫出命令列 | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 開啟最近分頁切換器 | `⌥ Q` | `Alt + Q` |
| 叫出命令列並預填目前網頁連結 | 需自行設定 | 需自行設定 |
| 複製目前網頁連結 | 需自行設定 | 需自行設定 |

後兩項在安裝後可能顯示為「未設定」，可以依照下文的方式為它們設定快速鍵。

## 修改快速鍵 {#change}

受瀏覽器限制，擴充功能的快速鍵需要在瀏覽器的快速鍵頁面中修改：

1. 在網址列中輸入 `chrome://extensions/shortcuts`（Edge 中為 `edge://extensions/shortcuts`）。
2. 找到 Lumno，按一下要修改的項目右側的鉛筆圖示。
3. 按下新的組合鍵。

![瀏覽器的擴充功能快速鍵頁面，Lumno 的「叫出聚焦搜尋視窗」為 ⇧⌘K，「開啟最近分頁切換器」為 ⌥Q](shortcuts "在擴充功能快速鍵頁面中修改")

如果習慣了 [Arc](https://arc.net/) 或 [Zen](https://zen-browser.app/) 的操作，可以把「叫出聚焦搜尋視窗」改為 `⌘ T`。

在 Dia 中按下快速鍵沒有反應時，請將該項右側的範圍從「在 Dia 中」改為「全域」。

## 命令列中的按鍵 {#command-bar-keys}

| 按鍵 | 作用 |
| --- | --- |
| `↑` `↓` | 選擇結果 |
| `↩` | 開啟結果，或切換到已開啟的分頁 |
| `⌥ ↩` | 在目前分頁中開啟，不另開新分頁 |
| `⇧ ↩` | 結果為已開啟的分頁時，在新分頁中再開啟一份 |
| `Tab` | 輸入簡稱後進入站內搜尋；搜尋框為空時，只搜尋已開啟的分頁 |
| `Tab` `Tab` | 搜尋框為空時連按兩下，開啟搜尋範圍面板 |
| `Esc` | 離開站內搜尋，或關閉命令列 |

## 切換器中的按鍵 {#switcher-keys}

| 按鍵 | 作用 |
| --- | --- |
| 按住 `⌥`，連按 `Q` | 在最近的分頁之間移動 |
| `Tab` 或方向鍵 | 移動選取項目 |
| 放開 `⌥` 或按 `↩` | 切換到選取的分頁 |
