Lumno 大部分的操作都在鍵盤上完成。這裡是預設快速鍵、怎麼修改，以及命令列裡那些順手的按鍵。

## 預設快速鍵 {#defaults}

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 叫出命令列 | `⌘ ⇧ K` | `Ctrl + Shift + K` |
| 開啟最近分頁切換器 | `⌥ Q` | `Alt + Q` |
| 叫出命令列並預填目前網頁連結 | 需自行設定 | 需自行設定 |
| 複製目前網頁連結 | 需自行設定 | 需自行設定 |

後兩項剛裝好時可能顯示「未設定」，照下面的方式幫它們設一組就行。

## 修改快速鍵 {#change}

受瀏覽器限制，擴充功能的快速鍵要在瀏覽器的快速鍵頁面裡修改：

1. 在網址列輸入 `chrome://extensions/shortcuts`（Edge 裡是 `edge://extensions/shortcuts`）。
2. 找到 Lumno，按想修改那一項右邊的鉛筆圖示。
3. 按下新的組合鍵。

![瀏覽器的擴充功能快速鍵頁面，Lumno 的「叫出聚焦搜尋視窗」為 ⇧⌘K，「開啟最近分頁切換器」為 ⌥Q](shortcuts "在擴充功能快速鍵頁面修改")

用慣了 Arc？把「叫出聚焦搜尋視窗」改成 `⌘ T`，就是熟悉的手感。

在 Dia 裡按快速鍵沒反應的話，把這一項右邊的範圍從「在 Dia 中」改成「全域」。

## 命令列裡的按鍵 {#command-bar-keys}

| 按鍵 | 作用 |
| --- | --- |
| `↑` `↓` | 選擇結果 |
| `↩` | 開啟結果，或切換到已開啟的分頁 |
| `⌥ ↩` | 在目前分頁開啟，不另開新分頁 |
| `⇧ ↩` | 結果是已開啟的分頁時，在新分頁裡再開一份 |
| `Tab` | 輸入簡稱後進入站內搜尋；搜尋框為空時只搜尋已開啟的分頁 |
| `Tab` `Tab` | 搜尋框為空時連按兩下，開啟搜尋範圍面板 |
| `Esc` | 離開站內搜尋，或關閉命令列 |

## 切換器裡的按鍵 {#switcher-keys}

| 按鍵 | 作用 |
| --- | --- |
| 按住 `⌥`，連按 `Q` | 在最近的分頁之間移動 |
| `Tab` 或方向鍵 | 移動選擇 |
| 放開 `⌥` 或按 `↩` | 切換到選取的分頁 |
