Lumno 大部分的操作都可以用鍵盤完成。以下是預設快速鍵、修改方式，以及命令列、新分頁、切換器和網頁剪裁中的按鍵；可以用滑鼠完成的操作，也一併寫在按鍵旁邊。

## 預設快速鍵 {#defaults}

| 操作 | 快速鍵 |
| --- | --- |
| 叫出命令列 | `⌘ ⇧ K` |
| 開啟最近分頁切換器 | `⌥ Q` |
| 叫出命令列並預填目前網頁連結 | 需自行設定 |
| 複製目前網頁連結 | 需自行設定 |

後兩項在安裝後可能顯示為「未設定」，可以依照下文的方式為它們設定快速鍵。Firefox 版叫出命令列的預設快速鍵不同，詳見[瀏覽器相容性](../browser-compatibility/#firefox)。

## 修改快速鍵 {#change}

受瀏覽器限制，擴充功能的快速鍵需要在瀏覽器的快速鍵頁面中修改：

1. 在網址列中輸入 `chrome://extensions/shortcuts`（Edge 中為 `edge://extensions/shortcuts`）。
2. 找到 Lumno，按一下要修改的項目右側的鉛筆圖示。
3. 按下新的組合鍵。

![瀏覽器的擴充功能快速鍵頁面，Lumno 的「叫出聚焦搜尋視窗」為 ⇧⌘K，「開啟最近分頁切換器」為 ⌥Q](shortcuts "在擴充功能快速鍵頁面中修改")

如果習慣了 [Arc](https://arc.net/) 或 [Zen](https://zen-browser.app/) 的操作，可以把「叫出聚焦搜尋視窗」改為 `⌘ T`。

快速鍵頁面不接受 `⌃ Tab`。如果想用它開啟切換器，請參閱[用 Ctrl+Tab 開啟切換器](../tab-switcher/#ctrl-tab)。

Dia 自己的快速鍵優先於擴充功能。想在 Dia 中使用 `⌘ T`，請先在 Dia 的 Settings → Shortcuts 中把「New Tab」改為其他按鍵，詳見[瀏覽器相容性](../browser-compatibility/#dia)。

在 Dia 中按下快速鍵沒有反應時，請將該項右側的範圍從「In Dia」改為「Global」。

## 命令列中的按鍵 {#command-bar-keys}

### 選擇結果

| 按鍵 | 作用 |
| --- | --- |
| `↑` `↓` | 上下移動選取的結果 |
| 長按 `⌘` 後放開，再按 `0`–`9` | 結果旁會出現編號，按下數字即可開啟對應的結果 |

在設定的「實驗室功能」中開啟「單按 Command 顯示數字跳轉」後，按一下 `⌘` 就會出現編號，按住 `⌘` 再按數字即可開啟。開啟後，`⌘` 不再用於在背景開啟結果，滑鼠中鍵不受影響。

在 macOS 上，還可以在「實驗室功能」中開啟「Mac 鍵盤導覽」，用 `⌃ N | ⌃ N` 和 `⌃ P | ⌃ P` 選擇下一項和上一項。

### 開啟結果

| 按鍵或滑鼠操作 | 作用 |
| --- | --- |
| `↩` 或按一下結果 | 開啟結果，或切換到已開啟的分頁 |
| `⌥ ↩` 或按住 `⌥` 再按一下結果 | 在目前分頁中開啟，不另開新分頁；如果已設為[在目前分頁開啟](../search-tabs-bookmarks-history/#current-tab)，則改為開新分頁 |
| `⇧ ↩` 或按住 `⇧` 再按一下結果 | 結果為已開啟的分頁時，在新分頁中再開啟一份 |
| `⌘ ↩`、按住 `⌘` 再按一下結果，或用滑鼠中鍵按一下結果 | 在背景分頁中開啟；命令列保持開啟，可以接著開啟下一個 |

按住 `⌥`、`⇧` 或 `⌘` 時，結果右側的操作提示會跟著改變。

### 輸入與搜尋模式

| 按鍵 | 作用 |
| --- | --- |
| `Tab` | 補全候選項目；輸入簡稱後進入站內搜尋；搜尋框為空時，只搜尋已開啟的分頁；用方向鍵選到網頁結果後，把它的網址填入搜尋框以便修改 |
| `Tab` `Tab` | 搜尋框為空時連按兩下，開啟搜尋範圍面板；已選擇搜尋範圍時，按一下即可 |
| `⌥ ↑` `⌥ ↓` | 切換到上一筆或下一筆輸入過的內容 |
| `⌘ Z` `⌘ ⇧ Z` | 搜尋範圍面板開啟時，復原或重做對搜尋來源順序的調整 |
| `⌫` | 搜尋框為空時，離開站內搜尋、搜尋範圍或已開啟分頁搜尋 |
| `Esc` | 離開站內搜尋、搜尋範圍或已開啟分頁搜尋 |
| `Esc` 或按一下命令列以外的區域 | 關閉命令列 |

## 新分頁中的按鍵 {#newtab-keys}

新分頁搜尋框中的按鍵與命令列相同。此外：

| 按鍵或滑鼠操作 | 作用 |
| --- | --- |
| 直接輸入 | 不用先按一下搜尋框，文字會直接輸入到搜尋框中 |
| 按一下搜尋結果、捷徑、書籤或網站卡片 | 預設在目前分頁中開啟；在設定的「一般 → 新分頁設定 → 點擊後在新分頁開啟」中勾選對應項目後，改為開新分頁 |
| 按住 `⌥` 再按一下，或按 `⌥ ↩` | 改用另一種方式開啟：原本在目前分頁開啟的會開新分頁，原本開新分頁的則在目前分頁開啟 |
| 按住 `⌘` 再按一下，或用滑鼠中鍵按一下 | 在背景分頁中開啟 |
| `⌥ ←` `⌥ →` | 用 `Tab` 鍵選取捷徑後，將它向前或向後移動一格 |
| `⌘ Z` | 復原對捷徑或書籤的上一步操作，例如移除、移動、新增資料夾或刪除群組 |
| `⌘ ⇧ Z` | 重做剛才復原的操作 |
| `Esc` | 拖曳捷徑或書籤時，取消拖曳 |

## 切換器中的按鍵 {#switcher-keys}

| 按鍵或滑鼠操作 | 作用 |
| --- | --- |
| 按住 `⌥`，連按 `Q` | 在最近的分頁之間依序移動 |
| `Tab`、`→` 或 `↓` | 選取下一個分頁 |
| `⇧ Tab`、`←` 或 `↑` | 選取上一個分頁 |
| 放開 `⌥`、按 `↩`，或按一下分頁 | 切換到選取的分頁 |
| 按一下頁面預覽角落的關閉按鈕 | 關閉該分頁，切換器保持開啟 |
| `Esc` 或按一下切換器以外的區域 | 關閉切換器，留在目前分頁 |

如果修改過切換器的快速鍵，需要按住的是你設定的組合鍵中的輔助鍵。

## 網頁剪裁中的按鍵 {#web-clip-keys}

選擇要剪下的內容時：

| 按鍵或滑鼠操作 | 作用 |
| --- | --- |
| `[` 或 `↑` | 選擇外層元素 |
| `]` 或 `↓` | 選擇內層元素 |
| 捲動滑鼠滾輪 | 在外層和內層元素之間切換 |
| `↩` 或按一下框住的內容 | 在浮動視窗中開啟 |
| `Esc` | 取消選擇 |

在浮動視窗中按一下連結，會開啟新分頁；按住 `⌘` 再按一下，則在背景開啟。詳見[網頁剪裁](../web-clip/)。
