Lumno はブラウザ拡張機能であり、ブラウザそのものではないため、ブラウザの制約により実現できない機能があります。現在把握している制限は次のとおりです。これらの機能が必要な場合は、本ページで紹介しているほかのツールのほうが適しているかもしれません。

## コマンドバーを開けないページ {#restricted-pages}

セキュリティ上の理由から、ブラウザは次のページで拡張機能がスクリプトを実行したり独自の画面を表示したりすることを一切許可していません。Lumno もこの制限を回避できません。

- `chrome://` や `edge://` で始まるブラウザのページ（設定ページ、拡張機能ページなど）
- Chrome ウェブストアと Edge アドオン サイト
- Firefox の `about:` で始まるページと Firefox Add-ons サイト

これらのページでショートカットキーを押すと、コマンドバーを現在のページに表示できないため、Lumno は新しいタブを開き、検索ボックスにカーソルを置きます。そのまま検索を続けられます。これは不具合ではありません。通常の Web ページでは、これまでどおりページ上にコマンドバーが開きます。

ブラウザ本来の新しいタブを開くようにしたい場合は、Lumno の設定の「一般 → キー設定 → 制限ページでの動作」で「ブラウザ設定に従う」を選択します。ほかの拡張機能で新しいタブを置き換えている場合は、Lumno が自動的にこの項目を選択します。

制限されるのは、これらのページでコマンドバーを開くことだけです。ショートカットやコマンドバーから `chrome://inspect/#devices` などのブラウザのページを開くことは、これまでどおりできます。

パソコン上の PDF や HTML ファイル（`file://` で始まるもの）では、拡張機能の詳細ページで「ファイルの URL へのアクセスを許可する」をオンにすると、コマンドバーを使用できます。

## ブラウザの外にあるもの {#outside-browser}

Lumno が検索するのはブラウザ内の情報だけです。アプリ、ファイル、システム設定も 1 つのショートカットで検索したい場合は、[Raycast](https://www.raycast.com/) や [Alfred](https://www.alfredapp.com/)（macOS）を検討してください。

## 対応ブラウザ {#browsers}

- Safari とモバイルデバイスのブラウザには対応していません。
- Dia ではコマンドバーを使用できますが、新しいタブは使用できません。
- Firefox 版では一部の機能を使用できません。詳しくは、[ブラウザ互換性](../browser-compatibility/)を参照してください。

## 新しいタブのウィジェット {#widgets}

Lumno の新しいタブはシンプルさを重視しており、天気、ToDo、メモなどのウィジェットはありません。ウィジェットが充実した新しいタブが必要な場合は、[Momentum](https://momentumdash.com/) や [Tabliss](https://tabliss.io/) を検討してください。

ブラウザの仕様上、新しいタブを置き換えられる拡張機能は同時に 1 つだけです。ほかの拡張機能の新しいタブを使いながら、Lumno のコマンドバーを併用できます。詳しくは、[ほかの新しいタブ拡張機能と併用する](../newtab-other-extensions/)を参照してください。

## クラウド同期 {#data}

Lumno にはサーバーがないため、クラウドアカウントもありません。設定はブラウザの同期機能で同期されます。アイコンや壁紙も同期したい場合は、Nextcloud や NAS など、ご自身で用意した WebDAV サーバーが必要です。詳しくは、[同期](../sync/)を参照してください。

履歴、ブックマーク、開いているタブは Lumno の同期対象に含まれず、これまでどおりブラウザによって同期されます。
