Lumno는 브라우저 확장 프로그램이며 브라우저 자체가 아니므로, 브라우저의 제약 때문에 제공할 수 없는 기능이 있습니다. 현재 알려진 제한 사항은 다음과 같습니다. 이러한 기능이 필요하다면 이 페이지에서 소개하는 다른 도구가 더 적합할 수 있습니다.

## 명령 바를 열 수 없는 페이지 {#restricted-pages}

보안상의 이유로 브라우저는 다음 페이지에서 어떤 확장 프로그램도 스크립트를 실행하거나 자체 화면을 표시하지 못하게 하며, Lumno도 이 제한을 우회할 수 없습니다.

- `chrome://` 또는 `edge://`로 시작하는 브라우저 페이지(설정, 확장 프로그램 페이지 등)
- Chrome 웹 스토어와 Edge 추가 기능 사이트
- Firefox에서 `about:`으로 시작하는 페이지와 Firefox 부가 기능 사이트

이런 페이지에서 단축키를 누르면 명령 바를 현재 페이지 위에 표시할 수 없으므로, Lumno가 대신 새 탭을 열고 검색창에 커서를 둡니다. 그대로 이어서 검색하면 됩니다. 이는 오류가 아닙니다. 일반 웹 페이지에서는 지금처럼 페이지 위에 명령 바가 열립니다.

대신 브라우저 자체의 새 탭을 열려면 Lumno 설정의 General → Shortcut Settings → Restricted page behavior에서 Follow browser setting을 선택하세요. 다른 확장 프로그램이 새 탭을 대신하고 있다면 Lumno가 이 항목을 자동으로 선택합니다.

제한되는 것은 이런 페이지에서 명령 바를 여는 것뿐입니다. 바로가기나 명령 바에서 `chrome://inspect/#devices` 같은 브라우저 페이지를 여는 것은 평소처럼 할 수 있습니다.

`file://`로 시작하는 로컬 PDF 또는 HTML 파일에서는 Lumno 확장 프로그램 세부정보 페이지에서 파일 URL에 대한 액세스를 허용하면 명령 바를 사용할 수 있습니다.

## 브라우저 밖의 항목 {#outside-browser}

Lumno는 브라우저 안의 항목만 검색합니다. 앱, 파일, 시스템 설정까지 단축키 하나로 검색하려면 macOS용 [Raycast](https://www.raycast.com/)나 [Alfred](https://www.alfredapp.com/)를 사용해 보세요.

## 브라우저 지원 {#browsers}

- Safari와 모바일 기기의 브라우저는 지원하지 않습니다.
- Dia에서는 명령 바를 사용할 수 있지만, Lumno 새 탭은 사용할 수 없습니다. 또한 Dia 자체 단축키가 우선하므로 `⌘ T`로 명령 바를 열려면 먼저 Dia의 "New Tab" 단축키를 변경해야 합니다. 자세한 내용은 [브라우저 호환성](../browser-compatibility/#dia)을 참고하세요.
- Firefox 버전에서는 일부 기능을 사용할 수 없습니다. 자세한 내용은 [브라우저 호환성](../browser-compatibility/)을 참고하세요.

## 새 탭 위젯 {#widgets}

Lumno의 새 탭은 단순함을 우선하므로 날씨, 할 일, 메모 같은 위젯을 제공하지 않습니다. 위젯이 많은 새 탭이 필요하다면 [Momentum](https://momentumdash.com/)이나 [Tabliss](https://tabliss.io/)를 사용해 보세요.

브라우저에서는 한 번에 하나의 확장 프로그램만 새 탭을 바꿀 수 있습니다. 다른 확장 프로그램의 새 탭을 계속 사용하면서 Lumno의 명령 바를 함께 사용할 수 있습니다. 자세한 내용은 [다른 새 탭 확장 프로그램과 함께 사용하기](../newtab-other-extensions/)를 참고하세요.

## 클라우드 동기화 {#data}

Lumno에는 서버가 없으므로 클라우드 계정도 없습니다. 설정은 브라우저의 기본 동기화 기능으로 동기화됩니다. 아이콘과 배경화면까지 동기화하려면 Nextcloud나 NAS 같은 WebDAV 서버를 직접 준비해야 합니다. 자세한 내용은 [동기화](../sync/)를 참고하세요.

방문 기록, 북마크, 열린 탭은 Lumno의 동기화 대상이 아니며, 지금처럼 브라우저가 동기화합니다.
