`⇧` キーを押しながら Web ページのリンクをクリックすると、Lumno は今のページの上に小さなウインドウを開いてリンク先を表示します。元のページは縮小してぼかされ、ウインドウの後ろに下がります。読み終えたらウインドウを閉じれば元の位置に戻れます。続けて読みたいときは、新しいタブに移したり、今のページの横に分割ビューで並べたりすることもできます。

## リンクをプレビューする {#how}

1. Web ページで `⇧` キーを押したまま、リンクをクリックします。
2. リンク先が小さなウインドウで開きます。ウインドウ内のリンクをクリックすると、そのままウインドウ内で開きます。
3. 読み終えたら、`Esc` キーを押すか、ウインドウの外側をクリックすると閉じます。

![後ろのページが縮小されて灰色にぼかされ、手前の小さなウインドウにフレックスボックスの記事が開いている。ウインドウの右側にボタンが並んでいる](link-preview "小さなウインドウでリンクをプレビュー")

`⇧` キーを押したままリンクの上にポインタを置くと、Lumno はページの読み込みを先に始めます。そのため、クリックしたときにより早く表示されます。

通常のリンクのほか、次のものもプレビューできます。

- ページ内に URL として表示され、クリックするとその URL を開くテキスト。
- X（Twitter）の投稿：`⇧` キーを押しながら投稿をクリックすると、その投稿をプレビューできます。

## ウインドウのボタン {#window}

ウインドウの右側には、上から順に次のボタンがあります。

- 閉じる：ウインドウを閉じて、元のページに戻ります。
- 新しいタブで開く：ウインドウで表示しているページを新しいタブに移します。ウインドウは閉じます。
- 分割ビューで開く：ウインドウで表示しているページを、今のページの横の分割ビューに移します。ウインドウは閉じます。ブラウザが分割ビューに対応していて（現時点では Chrome 155 以降）、今のページが分割ビューになっていない場合にだけ表示されます。[ブラウザ互換性](../browser-compatibility/#split-view)を参照してください。
- リンクをコピー：ウインドウで表示しているページの URL をコピーします。ウインドウ内でほかのリンクを開いた場合は、今表示しているページの URL がコピーされます。
- 再読み込み：ウインドウ内のページを再読み込みします。
- 戻る：ウインドウ内でほかのリンクを開くと表示され、前のページに戻ります。

ウインドウを開いている間、後ろのページはスクロールしません。ウインドウを閉じると、ページは元の位置のままです。

## プレビューできない場合 {#blocked}

一部のサイトはほかのページの中での表示を許可していません。また、ページの読み込みに失敗することもあります。その場合はウインドウに「このページはプレビューで表示できません」と表示されるので、「新しいタブで開く」をクリックすると通常どおり表示できます。

次の場合はプレビューは開かず、`⇧` キーを押しながらのクリックはブラウザの通常の動作になります（多くの場合、新しいウインドウで開きます）。

- ブラウザの設定ページや拡張機能ストアなど、Lumno が動作できない制限付きページ内のリンク。
- ファイルをダウンロードするリンク、メールのリンク、同じページ内の別の位置に移動するリンク。

## オン・オフを切り替える {#toggle}

この機能は初期設定でオンになっています。`⇧` キーを押しながらのクリックで以前のように新しいウインドウを開きたい場合は、Lumno の設定の「機能」で「リンクプレビュー」をオフにしてください。
