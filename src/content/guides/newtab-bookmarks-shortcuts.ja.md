よく使うサイトを検索ボックスの下に置いて、クリックひとつで開けます。ブックマークが多くても、フォルダを順にたどる必要はありません。

## ショートカット {#shortcuts}

検索ボックスの下に並ぶアイコンがショートカットです。ポインタを合わせると、macOS の Dock のようにアイコンが拡大します。

![検索ボックスの下に並ぶショートカットのアイコン。ポインタを合わせた Figma のアイコンが拡大され、名前が表示されている](nt-shortcuts "よく使うサイトをクリックひとつで開く")

### ショートカットを追加する

1. ショートカットの最後にある「+」をクリックします。
2. 名前と URL を入力します。`chrome://inspect/#devices` などのブラウザのページも指定できます。
3. アイコンを選択します。内蔵アイコンやオンラインのアイコンのほか、ご自身の画像（128×128 px 以上の正方形を推奨）もアップロードできます。
4. 「保存」をクリックします。

### ショートカットを整理する

- ショートカットを右クリックすると、編集または削除できます。誤って削除した場合は、通知に表示されるショートカットキーで元に戻せます。
- ドラッグすると順番を変更できます。ブックマークの上にドラッグすると、ブックマークに変換されます。
- 1 行あたりの数、アイコンの大きさ、間隔、Dock のような拡大表示、「+」の表示は、Lumno の設定の「外観 → ショートカット」で変更できます。

## ブックマーク {#bookmarks}

ブックマーク欄には、ブラウザのブックマークバーの内容が表示されます。フォルダにポインタを合わせると、中のページが表示されます。

![新しいタブのブックマーク欄。参考資料、デザインガイドライン、競合などのフォルダと、ChatGPT と GitHub のブックマーク](nt-bookmarks-folder "多層フォルダ表示")

### ブックマークのレイアウト

ブックマーク欄の右上にある「···」をクリックして、レイアウトを切り替えます。

- 多層フォルダ表示：フォルダがカードとして並び、ポインタを合わせると階層ごとに開きます。
- 多階層リスト表示：フォルダの内容を階層メニューで表示します。
- 上部ブックマークバー：ブラウザのブックマークバーと同様に、ページの上部に 1 列で表示します。

![上部ブックマークバーのレイアウト。ブックマークフォルダが新しいタブの上部に一列で並ぶ](nt-bookmarks-top "上部ブックマークバー")

上部ブックマークバーを選択した場合は、背景を自動調整フロスト、クリアガラス、透明、任意の色から選択できます。

### そのほかの設定

- ブックマークが多い場合は、右上の矢印でページを切り替えるか、設定で表示する行数を変更します。
- フォルダを右クリックすると、色を変更できます。メニュー内の同じフォルダにも同じ色が適用されます。
- ブックマークのアイコンをクリックすると、ブラウザのブックマークマネージャが開きます。
