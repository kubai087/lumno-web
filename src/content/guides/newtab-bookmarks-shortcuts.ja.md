よく使うサイトは検索ボックスの下に、ワンクリックで。ブックマークがどれだけあっても、迷いません。

## ショートカット {#shortcuts}

検索ボックスの下に並ぶアイコンがショートカットです。ポインタを合わせると、macOS の Dock のように拡大します。

![検索ボックスの下に並ぶショートカットのアイコン。ポインタを合わせた Figma のアイコンが拡大され、名前が表示されている](nt-shortcuts "よく使うサイトに、ワンクリックで")

### 追加する

1. ショートカットの最後にある「+」をクリックします。
2. 名前と URL を入力します。`chrome://inspect/#devices` のようなブラウザのページも使えます。
3. アイコンを選びます。内蔵アイコン、オンラインアイコン、または自分の画像（128×128 px 以上の正方形がおすすめ）をアップロード。
4. 保存します。

### 整理する

- ショートカットを右クリックすると、編集や削除ができます。間違えて消したときは、通知に表示されるショートカットで元に戻せます。
- ドラッグで並べ替え。ブックマークの上にドラッグすると、ブックマークになります。
- 1 行の数、アイコンの大きさ、間隔、Dock のような拡大、「+」の表示は、Lumno の設定の「外観 → ショートカット」で変えられます。

## ブックマーク {#bookmarks}

ブックマークの欄には、ブラウザのブックマークバーの中身が表示されます。フォルダにポインタを合わせると、中のページが開きます。

![新しいタブのブックマーク欄。参考資料、デザインガイドライン、競合などのフォルダと、ChatGPT と GitHub のブックマーク](nt-bookmarks-folder "多層フォルダ表示")

### 3 つのレイアウト

ブックマーク欄の右上にある「···」から切り替えます。

- 多層フォルダ表示：フォルダがカードで並び、ポインタを合わせると階層ごとに開きます。
- 多階層リスト表示：フォルダの中身を階層メニューで見られます。
- 上部ブックマークバー：ブラウザのブックマークバーのように、ページ上部に一列で並びます。

![上部ブックマークバーのレイアウト。ブックマークフォルダが新しいタブの上部に一列で並ぶ](nt-bookmarks-top "上部ブックマークバー")

上部ブックマークバーでは背景も変えられます。自動調整フロスト、クリアガラス、透明、好きな色から選べます。

### そのほかの細かな点

- ブックマークが多いときは、右上の矢印でページを送るか、設定で表示する行数を変えられます。
- フォルダを右クリックすると色を変えられます。メニュー内の同じフォルダにも反映されます。
- ブックマークのアイコンをクリックすると、ブラウザのブックマークマネージャが開きます。
