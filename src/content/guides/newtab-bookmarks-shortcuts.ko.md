자주 가는 사이트를 검색창 아래에 두고 클릭 한 번으로 열 수 있습니다. 북마크가 많아도 폴더를 하나씩 찾아볼 필요가 없습니다.

## 바로가기 {#shortcuts}

검색창 아래에 표시되는 아이콘이 바로가기입니다. 마우스 포인터를 올리면 macOS Dock처럼 아이콘이 커집니다.

![검색창 아래 바로가기 아이콘 줄. 포인터 아래의 Figma 아이콘이 커지고 이름이 표시된다](nt-shortcuts "자주 가는 사이트를 클릭 한 번으로 열기")

### 바로가기 추가하기

1. 바로가기 끝에 있는 "+"를 클릭하고 Add site를 선택하세요.
2. 이름과 URL을 입력하세요. `chrome://inspect/#devices` 같은 브라우저 페이지도 지정할 수 있습니다.
3. 아이콘을 선택하세요. 기본 아이콘이나 온라인 아이콘을 선택하거나, 직접 가진 이미지(128×128px 이상의 정사각형 권장)를 올릴 수 있습니다.
4. 저장을 클릭하세요.

### 바로가기 정리하기

- 바로가기를 마우스 오른쪽 버튼으로 클릭하면 수정하거나 삭제할 수 있습니다. 실수로 삭제했다면 알림에 표시되는 단축키로 되돌리세요.
- 끌어서 순서를 바꿀 수 있습니다. 북마크 영역으로 끌어다 놓으면 북마크로 바뀝니다. `Tab` 키로 바로가기를 선택한 다음 `⌥ ←` 또는 `⌥ →`를 눌러 한 칸씩 옮길 수도 있습니다.
- 한 줄에 표시할 개수, 아이콘 크기, 간격, Dock 확대 효과, "+" 버튼 표시 여부는 새 탭 Appearance 설정의 Shortcuts 섹션이나 Lumno 설정의 Appearance → New Tab에서 변경할 수 있습니다. "+"를 클릭하고 Hide를 선택해 바로 숨길 수도 있습니다.
- 바로가기는 최대 200개까지 추가할 수 있습니다.
- 바로가기가 필요 없다면 같은 곳에서 Shortcuts를 끄세요. 검색창 아래의 아이콘 줄이 사라집니다.

## 바로가기 그룹 {#shortcut-groups}

바로가기가 많아지면 업무, AI, 엔터테인먼트처럼 용도별로 그룹을 나눌 수 있습니다. 그룹마다 제목이 붙습니다.

![검색창 아래의 바로가기가 Work, AI, Everyday 세 그룹으로 나뉘어 있고, 마우스를 올린 Work 제목 옆에 "···" 버튼이 표시된 모습](nt-shortcut-groups "용도별로 나눈 바로가기")

1. 바로가기 끝에 있는 "+"를 클릭하고 New group을 선택하세요.
2. 그룹 이름을 입력하고 저장을 클릭하세요. 이름은 비워 둘 수 있으며, 이름이 없는 그룹은 줄을 나누는 역할만 합니다.

- 그룹 제목 위에 마우스를 올리고 오른쪽의 "···"를 클릭하면 그룹 이름을 바꾸거나(Rename), 그룹에 사이트를 추가하거나(Add site), 그룹을 위아래로 옮길 수 있습니다(Move up, Move down). 제목을 더블클릭해도 이름을 바꿀 수 있습니다.
- 그룹 제목을 끌어서 그룹 순서를 바꿀 수 있습니다. 바로가기를 다른 그룹으로 끌어다 놓으면 그 그룹으로 옮겨집니다.
- Delete group을 선택하면 그룹 안의 사이트가 바로 위 그룹으로 합쳐집니다. Delete group and sites를 선택하면 확인한 다음 그룹과 사이트를 함께 삭제합니다. 두 작업 모두 `⌘ Z`로 실행 취소할 수 있습니다.
- 그룹은 최대 20개까지 만들 수 있습니다.

## 바로가기 폴더 {#shortcut-folders}

바로가기가 많아지면 휴대폰 홈 화면처럼 폴더로 묶을 수 있습니다. 바로가기 하나를 다른 바로가기의 한가운데로 드래그하고, "Release to create a folder in the bookmarks bar"가 표시되면 놓으세요. 아이콘 양쪽 가장자리에 놓으면 순서만 바뀝니다.

![검색창 아래 바로가기 중 세 번째가 폴더이며, 열면 "AI" 폴더의 Claude, ChatGPT, Gemini, Perplexity가 표시된다](nt-shortcut-folder "바로가기 폴더를 연 모습")

- 새 폴더는 브라우저 북마크바의 맨 끝에 저장되고, 놓은 자리에 있던 바로가기 위치에 표시됩니다. `⌘ Z`를 누르면 되돌릴 수 있습니다.
- 바로가기를 폴더 위로 드래그하면 그 폴더에 들어갑니다. 북마크 영역의 폴더도 바로가기로 바로 드래그할 수 있습니다.
- 폴더를 클릭하면 안에 있는 사이트가 펼쳐지고, 한 번 더 클릭하면 닫힙니다.
- 폴더 안의 사이트를 마우스 오른쪽 버튼으로 클릭하고 Edit를 선택하면 바로가기처럼 아이콘을 고를 수 있습니다. 이 아이콘은 현재 기기에만 저장됩니다.
- 폴더를 마우스 오른쪽 버튼으로 클릭하면 안의 모든 페이지를 새 탭 그룹에서 열거나, 이름과 색을 바꾸거나, 바로가기에서 제거할 수 있습니다. 북마크바의 폴더는 그대로 남습니다.

## 북마크 {#bookmarks}

북마크 영역에는 브라우저 북마크바의 내용이 표시됩니다. 폴더에 마우스 포인터를 올리면 카드 오른쪽에 폴더 안 사이트 몇 개의 아이콘이 표시됩니다.

![새 탭의 북마크 영역: Reference, Design guidelines, Competitors 같은 폴더와 ChatGPT, GitHub 북마크. 포인터를 올린 Reference 폴더에 안에 있는 사이트의 아이콘이 표시되어 있다](nt-bookmarks "북마크 영역")

- 폴더를 마우스 오른쪽 버튼으로 클릭하면 색을 바꿀 수 있으며, 메뉴에 표시되는 같은 폴더에도 같은 색이 적용됩니다.
- 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Open in new tab group"을 선택하면 안의 모든 페이지를 하나의 탭 그룹으로 한꺼번에 열 수 있습니다.
- 북마크나 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Add to shortcuts"를 선택하면 마지막 바로가기 그룹의 끝에 추가되며, 원래 북마크는 그대로 남습니다. 이미 바로가기에 있다면 메뉴에 "Already in shortcuts"가 표시됩니다.
- 북마크 아이콘을 클릭하면 브라우저의 북마크 관리자가 열립니다.
- 바로가기와 북마크는 기본적으로 현재 탭에서 열립니다. 새 탭에서 열려면 Lumno 설정의 General → New Tab Settings → Open in a new tab에서 항목별로 켜세요. `⌘`를 누른 채 클릭하거나 마우스 가운데 버튼으로 클릭하면 항상 백그라운드에서 열립니다.

## 북마크 레이아웃 {#bookmark-layouts}

북마크 영역 오른쪽 위의 "···"를 클릭하면 세 가지 레이아웃 중 하나를 선택할 수 있습니다.

### 다단계 폴더 보기

기본 레이아웃입니다. 폴더와 북마크가 카드로 표시됩니다. 폴더를 클릭하면 그 자리에서 열리고, 위쪽에 "Bookmarks / Reference"처럼 현재 위치가 표시됩니다. "Bookmarks"를 클릭하면 상위 단계로 돌아갑니다.

![다단계 폴더 보기에서 Reference 폴더를 연 모습. 위쪽에 "Bookmarks / Reference"가 표시되고, 아래에 CSS layout 하위 폴더와 북마크 두 개가 있다](nt-bookmarks-folder "다단계 폴더 보기: 폴더가 그 자리에서 열림")

### 다단계 목록 보기

카드 배치는 그대로이고, 폴더를 클릭하면 메뉴가 열립니다. 메뉴 안의 하위 폴더는 오른쪽으로 이어서 열립니다. 깊은 단계의 폴더도 지금 보고 있는 페이지를 벗어나지 않고 살펴볼 수 있습니다.

![다단계 목록 보기에서 Reference 폴더를 클릭해 메뉴를 열고, 포인터를 올린 CSS layout 하위 폴더가 오른쪽으로 열려 web.dev와 Can I use가 표시된 모습](nt-bookmarks-list "다단계 목록 보기: 메뉴가 단계별로 열림")

### 상단 북마크바

브라우저 북마크바처럼 페이지 맨 위에 한 줄로 표시합니다. 북마크바 안의 폴더도 메뉴로 열립니다.

![상단 북마크바 레이아웃. 북마크 폴더가 새 탭 맨 위에 한 줄로 놓여 있다](nt-bookmarks-top "상단 북마크바")

상단 북마크바를 선택한 경우 북마크바 오른쪽 끝의 "···"를 클릭하면 북마크바의 형태와 배경을 설정할 수 있습니다.

- Bar style: Docked to top은 브라우저 위쪽에 딱 붙어 표시되고, Floating은 위쪽에서 조금 떨어진 둥근 북마크바로 표시됩니다.
- Bar background: Match style, Transparent, Custom color 중에서 선택할 수 있습니다. Match style을 선택하면 새 탭과 같은 [재질](../newtab-wallpaper/#glass)이 적용됩니다.

## 줄 수 변경과 북마크 숨기기 {#bookmark-rows}

북마크를 몇 줄로, 한 줄에 몇 개씩 표시할지는 새 탭 Appearance 설정의 Bookmarks 섹션이나 Lumno 설정의 Appearance → New Tab에서 변경할 수 있습니다.

![Lumno 설정의 Bookmark rows, Bookmarks per row, Show Icons Inside Bookmark Folders, Site Cards 네 가지 항목](nt-layout-settings "Appearance → New Tab의 북마크 설정")

- Bookmark rows: 0~8줄 중에서 선택할 수 있으며 기본값은 2줄입니다. 북마크가 다 들어가지 않으면 북마크 영역 오른쪽 위의 화살표로 페이지를 넘기세요.
- 북마크 숨기기: Bookmark rows를 0으로 끌어 놓으면 새 탭에 북마크가 표시되지 않고, 상단 북마크바도 함께 숨겨집니다. 브라우저의 북마크는 그대로 남아 있으므로 언제든 다시 표시할 수 있습니다.
- Bookmarks per row: 4~8개 중에서 선택할 수 있으며 기본값은 6개입니다. 창 너비가 충분할 때의 최대 개수이며, 창이 좁으면 자동으로 줄어듭니다.
- Show Icons Inside Bookmark Folders: 끄면 폴더에 마우스 포인터를 올려도 안에 있는 사이트의 아이콘이 표시되지 않습니다.

새 탭 아래쪽의 사이트 카드도 여기에서 설정합니다. 자세한 내용은 [자주 가는 사이트와 진행 카드](../newtab-frequent-sites/#card-rows)를 참고하세요.
