把常用網站放在搜尋框下方，按一下即可開啟；書籤再多，也不必逐層翻找。

## 捷徑 {#shortcuts}

搜尋框下方的一排圖示就是捷徑。滑鼠停留時，圖示會像 macOS 的 Dock 一樣放大。

![搜尋框下方的一排捷徑圖示，滑鼠所在的 Figma 圖示被放大並顯示名稱](nt-shortcuts "常用網站，一按就到")

### 新增捷徑

1. 按一下捷徑最後面的「+」，選擇「新增網站」。
2. 填入名稱和網址。也支援 `chrome://inspect/#devices` 這類瀏覽器頁面。
3. 選擇圖示：內建圖示、線上圖示，或上傳自己的圖片（建議使用 128×128 px 以上的正方形圖片）。
4. 按一下儲存。

正在瀏覽的網頁也可以直接加進來：在網頁空白處按右鍵，選擇「新增到 Lumno 新分頁的捷徑」；或者按一下工具列中的 Lumno 圖示，在[彈出視窗](../install/#toolbar-popup)中按一下「新增捷徑」。網頁會加到最後一個捷徑群組的末端。

### 圖示背景

有些網站的圖示是透明的或不是方形的。Lumno 會為這類圖示墊上一塊依圖示主色著色的底板，讓它和其他方形圖示看起來一致。

在捷徑的編輯對話框中，可以關閉「為不規則圖示加上背景」，也可以把「背景顏色」從「從圖示取色」改為「自訂顏色」：按一下調色盤按鈕，即可挑選任意顏色、輸入 HEX / RGB 值，或使用已儲存的顏色。

### 整理捷徑

- 在捷徑上按右鍵，可以編輯或移除。如果誤刪，可以按提示中的快速鍵復原。
- 拖曳可以調整順序；拖到書籤區後，它會變成一個書籤。也可以用 `Tab` 鍵選取捷徑，再按 `⌥ ←` 或 `⌥ →` 將它移動一格。
- 每行顯示的數量、圖示大小（最大 112）、間距、是否啟用 Dock 放大效果、是否顯示「+」，都可以在新分頁外觀設定的「捷徑」一節中調整，也可以在 Lumno 設定的「外觀 → 新分頁」中調整。按一下「+」後選擇「隱藏」，也可以直接隱藏它。
- 最多可以新增 200 個捷徑。
- 如果不需要捷徑，可以在同一處關閉「捷徑」，搜尋框下方就不會再顯示這一排圖示。

## 捷徑群組 {#shortcut-groups}

捷徑多了，可以依用途分成幾個群組，例如「工作」「AI」「日常」，每個群組都有自己的標題。

![搜尋框下方的捷徑分成「工作」「AI」「日常」三個群組，滑鼠所在的「工作」標題旁出現「···」按鈕](nt-shortcut-groups "依用途分組的捷徑")

1. 按一下捷徑最後面的「+」，選擇「新增群組」。
2. 輸入群組名稱，按一下儲存。名稱可以留空，這樣的群組只有分隔作用。

- 將滑鼠移到群組標題上，按一下右側的「···」，可以重新命名群組、在群組中新增網站，或者上移、下移群組。按兩下標題也可以重新命名。
- 拖曳群組標題可以調整群組的順序；把捷徑拖到另一個群組中，即可移過去。
- 選擇「刪除群組」時，其中的網站會併入上一個群組；選擇「刪除群組和網站」，則會在確認後一併刪除。兩種操作都可以按 `⌘ Z` 復原。
- 最多可以建立 20 個群組。

## 捷徑資料夾 {#shortcut-folders}

捷徑多了，可以像手機主畫面一樣疊成資料夾：把一個捷徑拖到另一個捷徑的正中央，看到「放開即建立資料夾，存入書籤列」的提示後放開即可。拖到圖示兩側，則只會調整順序。

![搜尋框下方的捷徑中，第三個是資料夾；點開後列出「AI 助理」資料夾中的 Claude、ChatGPT、Gemini 和 Perplexity](nt-shortcut-folder "開啟捷徑資料夾")

- 新資料夾會存在瀏覽器書籤列的最後面，並顯示在被疊上的那個捷徑的位置。按 `⌘ Z` 可以復原。
- 把捷徑拖到資料夾上，就能放進這個資料夾；書籤區域中的資料夾也可以直接拖進捷徑。
- 按一下資料夾即可展開其中的網站，再按一下就會收起。
- 在資料夾中的網站上按右鍵，選擇「編輯」，可以像捷徑一樣為它選擇圖示。這個圖示只會儲存在目前的裝置上。
- 在資料夾上按右鍵，可以在新分頁群組中開啟其中的所有網頁，也可以重新命名、修改顏色，或將它從捷徑中移除；書籤列中的資料夾會保留。

## 書籤 {#bookmarks}

書籤區顯示的是瀏覽器書籤列中的內容。將滑鼠移到資料夾上，卡片右側會顯示其中幾個網站的圖示。

![新分頁的書籤區，第一行是參考、設計規範、競品等資料夾，第二行是 ChatGPT、GitHub 書籤和更多資料夾；滑鼠所在的「參考」資料夾顯示出其中網站的圖示](nt-bookmarks "書籤區")

- 在資料夾上按右鍵可以更改它的顏色，選單中的同一個資料夾也會隨之變色。
- 在資料夾上按右鍵並選擇「在新分頁群組中開啟」，可以一次開啟其中的所有網頁，並歸入同一個分頁群組。
- 在書籤或資料夾上按右鍵，選擇「新增至捷徑」，它會出現在最後一個捷徑群組的最後面，原本的書籤不會移動。已經在捷徑中的，選單中會顯示「已在捷徑中」。
- 按一下書籤圖示，可以直接開啟瀏覽器的書籤管理員。
- 按一下捷徑和書籤，預設會在目前分頁中開啟。如果想開新分頁，可以在 Lumno 設定的「一般 → 新分頁設定 → 點擊後在新分頁開啟」中勾選對應項目。按住 `⌥` 按一下可以暫時改用另一種方式；按住 `⌘` 按一下或用滑鼠中鍵按一下，一律在背景開啟。

## 書籤版面 {#bookmark-layouts}

按一下書籤區右上角的「···」，即可在三種版面之間切換。

### 多層資料夾檢視

預設版面。資料夾和書籤以卡片形式排列，按一下資料夾會在原處開啟，上方顯示目前位置，例如「書籤 / 參考」；按一下「書籤」即可回到上一層。

![多層資料夾檢視中開啟了「參考」資料夾，上方顯示「書籤 / 參考」，下方是 CSS 版面子資料夾和兩個書籤](nt-bookmarks-folder "多層資料夾檢視：在原處開啟資料夾")

### 多層級列表檢視

卡片的排列方式不變，按一下資料夾會彈出選單，選單中的子資料夾會繼續向右展開。瀏覽層級較深的資料夾時，不必離開目前這一頁。

![多層級列表檢視中按一下「參考」資料夾彈出選單，滑鼠所在的「CSS 版面」子資料夾向右展開，列出 web.dev 和 Can I use](nt-bookmarks-list "多層級列表檢視：逐層展開選單")

### 頂端書籤列

書籤排成一列顯示在頁面頂端，與瀏覽器內建的書籤列類似。按一下其中的資料夾，同樣會以選單形式展開。

![頂端書籤列版面，書籤資料夾排成一列顯示在新分頁頂端](nt-bookmarks-top "頂端書籤列")

選擇頂端書籤列後，再按一下書籤列右端的「···」，還可以設定書籤列的形態和背景：

- 書籤列形態：「貼頂」緊貼瀏覽器頂端；「懸浮」則是一條與頂端稍有距離的圓角書籤列。
- 書籤列背景：跟隨風格、透明，或自訂顏色。選擇「跟隨風格」時，書籤列會使用與新分頁相同的[材質](../newtab-wallpaper/#glass)。

## 顯示行數與隱藏書籤 {#bookmark-rows}

書籤要顯示幾行、每行幾個，都可以在新分頁外觀設定的「書籤」一節中調整，也可以在 Lumno 設定的「外觀 → 新分頁」中調整。

![Lumno 設定中的書籤行數、書籤每行數量、顯示書籤資料夾內圖示和網站卡片四項設定](nt-layout-settings "「外觀 → 新分頁」中的書籤設定")

- 書籤行數：可選擇 0 到 8 行，預設為 2 行。書籤放不下時，可以按一下書籤區右上角的箭頭翻頁。
- 隱藏書籤：將「書籤行數」拖到 0，新分頁就不會再顯示書籤，頂端書籤列也會一併隱藏。瀏覽器中的書籤不受影響，隨時可以調回來。
- 書籤每行數量：可選擇 4 到 8 個，預設為 6 個。這是視窗夠寬時的上限，視窗較窄時會自動減少。
- 顯示書籤資料夾內圖示：關閉後，將滑鼠移到資料夾上時，不會再顯示其中網站的圖示。

底端的網站卡片也在這裡設定，詳見[常用網站和追劇卡片](../newtab-frequent-sites/#card-rows)。
