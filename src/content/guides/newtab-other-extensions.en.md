If you already use another new tab extension, such as Momentum or Tabliss, you can keep it and use only Lumno's command bar. The command bar runs on web pages and works no matter which extension controls the new tab.

## Which extension controls the new tab {#which-extension}

Because of how browser extensions work, whether an extension replaces the new tab is fixed when it's installed and can't be turned off while it runs. That's why Lumno can't offer a setting to stop using its new tab; use the steps below instead.

Only one extension can control the new tab at a time. If several such extensions are installed, Chrome and Edge use the one that was installed or turned on most recently. So to use another extension's new tab, make sure it's turned on after Lumno.

## Use another extension's new tab {#switch}

1. Install Lumno and keep it turned on.
2. Install the new tab extension you want to use. If it's already installed, turn it off and on again at `chrome://extensions`.
3. Open a new tab. If the browser asks whether to keep the change, choose to keep it.

Your new tab now shows the other extension's page, and you can still press `⌘ ⇧ K` on any web page to open Lumno's command bar.

## When the browser asks whether to keep the change {#keep-changes}

The first time an extension takes over the new tab, Chrome asks whether you want to keep the change. If you choose to change it back, Chrome turns off that extension entirely instead of only restoring the new tab. For Lumno, this means the command bar stops working too.

If you turned off Lumno by mistake, turn it back on at `chrome://extensions`. Lumno then becomes the most recently turned on extension and takes over the new tab again. To keep using the other extension's new tab, repeat step 2 above.

## Pressing the shortcut on another extension's new tab {#shortcut}

Another extension's new tab is a restricted page, so Lumno can't show its command bar there. If you press the shortcut on such a page, Lumno follows the "Restricted page behavior" option in its settings. By default, it opens Lumno's new tab so you can search there. If you don't want this, change the option to "Follow browser setting".

## Switch back to Lumno's new tab {#back-to-lumno}

Turn off the other new tab extension at `chrome://extensions`, or turn Lumno off and on again, and the new tab returns to Lumno's start page. Turning an extension off and on doesn't erase Lumno's settings.
