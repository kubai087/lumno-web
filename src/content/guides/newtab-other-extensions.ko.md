Momentum이나 Tabliss 같은 다른 새 탭 확장 프로그램을 이미 사용하고 있다면, 그대로 사용하면서 Lumno의 명령 바만 함께 사용할 수 있습니다. 명령 바는 웹 페이지에서 작동하므로 어떤 확장 프로그램이 새 탭을 바꾸었는지와 관계없이 사용할 수 있습니다.

## 새 탭을 바꾸는 확장 프로그램 {#which-extension}

브라우저 확장 프로그램의 구조상, 확장 프로그램이 새 탭을 바꿀지는 설치할 때 정해지며 실행 중에는 끌 수 없습니다. 따라서 Lumno는 설정에서 "Lumno 새 탭 사용 안 함" 같은 스위치를 직접 제공할 수 없으며, 아래 방법으로 전환해야 합니다.

한 번에 하나의 확장 프로그램만 새 탭을 바꿀 수 있습니다. 이러한 확장 프로그램이 여러 개 설치되어 있으면 Chrome과 Edge는 가장 최근에 설치했거나 다시 켠 확장 프로그램을 사용합니다. 따라서 다른 확장 프로그램을 Lumno보다 나중에 켜면 새 탭에 해당 확장 프로그램의 페이지가 표시됩니다.

## 다른 확장 프로그램의 새 탭 사용하기 {#switch}

1. Lumno를 설치하고 켜 둔 상태로 유지하세요.
2. 사용할 새 탭 확장 프로그램을 설치하세요. 이미 설치되어 있다면 `chrome://extensions`에서 껐다가 다시 켜세요.
3. 새 탭을 여세요. 브라우저에서 변경 사항을 유지할지 물으면 유지를 선택하세요.

이제 새 탭에는 해당 확장 프로그램의 페이지가 표시되며, 다른 웹 페이지에서 `⌘ ⇧ K`를 누르면 Lumno의 명령 바를 계속 사용할 수 있습니다.

## 변경 사항 유지 여부를 물을 때 {#keep-changes}

확장 프로그램이 처음으로 새 탭을 바꾸면 Chrome은 이 변경 사항을 유지할지 묻습니다. 변경 사항을 되돌리면 Chrome은 새 탭만 원래대로 돌리는 것이 아니라 해당 확장 프로그램 전체를 사용 중지합니다. Lumno의 경우 명령 바도 함께 작동하지 않게 됩니다.

실수로 Lumno를 사용 중지했다면 `chrome://extensions`에서 다시 켜세요. 다시 켜면 Lumno가 가장 최근에 켠 확장 프로그램이 되어 새 탭을 다시 바꿉니다. 다른 확장 프로그램의 새 탭을 계속 사용하려면 위의 2단계를 다시 진행하세요.

## 다른 확장 프로그램의 새 탭에서 단축키를 누를 때 {#shortcut}

다른 확장 프로그램의 새 탭은 제한된 페이지이므로 Lumno가 그 위에 명령 바를 표시할 수 없습니다. 이러한 페이지에서 단축키를 누르면 Lumno는 설정의 "Restricted page behavior" 옵션에 따라 처리합니다. 기본적으로 Lumno 새 탭을 열어 그곳에서 검색할 수 있게 합니다. 이 동작이 필요하지 않으면 옵션을 "Follow browser setting"으로 변경하세요.

## Lumno 새 탭으로 돌아가기 {#back-to-lumno}

`chrome://extensions`에서 다른 새 탭 확장 프로그램을 끄거나, Lumno를 껐다가 다시 켜면 새 탭이 Lumno 시작 페이지로 돌아옵니다. 확장 프로그램을 껐다가 다시 켜도 Lumno 설정은 삭제되지 않습니다.
