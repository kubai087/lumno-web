Chaque nouvel onglet peut s'ouvrir sur un tableau. Lumno propose de l'art classique et des paysages à l'encre, peut afficher la photo du jour de Bing, ou vos propres images.

## Ouvrir les réglages Appearance {#open}

Cliquez sur le bouton Appearance en bas à droite du nouvel onglet. Les réglages Appearance glissent depuis la droite ; les fonds d'écran se trouvent dans la section Wallpaper.

![Les réglages Appearance ouverts à droite du nouvel onglet, avec les sources de fonds d'écran et les vignettes des fonds intégrés](nt-appearance "Changer le fond d'écran dans les réglages Appearance")

## D'où viennent les fonds d'écran {#sources}

| Source | Ce que vous obtenez |
| --- | --- |
| Built-in | Les tableaux, paysages à l'encre et illustrations de Lumno, en clair et en sombre |
| Local | Vos propres images JPG, PNG ou WebP, jusqu'à 8 Mo |
| Bing | La photo du jour de Bing, mise à jour chaque jour ou choisie dans la semaine écoulée |
| Curated | Des photos par catégorie : nature, eau, ville, minimal et art, renouvelées chaque jour si vous voulez |

Vous avez trouvé une image en ligne qui vous plaît ? Cliquez sur « Add image link » et collez une adresse commençant par `https://`.

Avec la mise à jour quotidienne activée, un fond d'écran choisi à la main reste pour la journée ; le lendemain, celui du jour revient.

## Un pour le jour, un pour la nuit {#dark-mode}

« Match light and dark mode » est activé par défaut : les deux modes utilisent le même fond d'écran. Désactivez-le pour choisir séparément, un tableau le jour, un paysage au clair de lune la nuit.

Le mode clair ou sombre lui-même se règle en haut du panneau : suivre le système, clair ou sombre, pour toute l'extension ou seulement pour le nouvel onglet.

## Voile et filtres {#effects}

- Mask effect : si le fond d'écran est chargé et le champ de recherche difficile à lire, renforcez le voile ; pour une image plus nette, allégez-le.
- Wallpaper filter : le même tableau, une autre texture. Certains filtres ont des réglages d'intensité ou de taille.

| Filtre | Effet |
| --- | --- |
| Glass blur | Adoucit l'arrière-plan pour faire ressortir le contenu |
| Grain | Un bruit fin, façon pellicule |
| Blocks | Reconstruit l'image en blocs de pixels |
| Halftone | Une trame de points façon impression |
| Dither | Un tramage rétro avec une palette limitée |
| ASCII | Redessine les zones sombres ou claires en caractères |
| CRT | Lignes de balayage, halo et courbure d'écran |

## Sur vos autres ordinateurs {#sync}

Votre choix de fond intégré, Bing ou sélectionné, ainsi que vos liens d'images, se synchronisent avec votre navigateur. Les images locales importées restent sur l'ordinateur concerné ; pour les utiliser ailleurs, activez la synchro WebDAV.
