新しいタブを開くたびに、一枚の絵を。Lumno には名画や水墨画が入っていて、Bing の今日の一枚や、自分の写真も使えます。

## 外観設定を開く {#open}

新しいタブの右下にある「外観」ボタンをクリックすると、右側に外観設定が開きます。壁紙は「壁紙」のセクションにあります。

![新しいタブの右側に外観設定パネルが開き、壁紙のセクションに入手元の選択肢と内蔵壁紙のサムネイルが並ぶ](nt-appearance "外観設定で壁紙を変える")

## 壁紙の入手元 {#sources}

| 入手元 | 内容 |
| --- | --- |
| 内蔵 | Lumno に入っている名画、水墨画、イラスト。ライト用とダーク用があります |
| この端末 | 自分の JPG、PNG、WebP 画像（8 MB まで） |
| Bing | Bing の今日の一枚。毎日自動で更新するか、過去 1 週間から選べます |
| 厳選 | 自然、水辺、都市、ミニマル、アートのカテゴリから。毎日 1 枚ずつ替えることもできます |

ネットで気に入った画像があれば、「画像のリンクを追加」から `https://` で始まるアドレスを貼り付けられます。

毎日の自動更新をオンにしている場合、手動で選んだ壁紙はその日だけ表示され、翌日は毎日の壁紙に戻ります。

## 昼の一枚、夜の一枚 {#dark-mode}

「ライト/ダークで同じ」は初期設定でオンになっていて、両方のモードで同じ壁紙を使います。オフにすれば別々に選べます。昼は名画、夜は月夜の山水、というように。

ライトとダークの切り替え自体はパネルの一番上にあります。システムに合わせる、ライト、ダークから選べ、新しいタブだけに適用することもできます。

## オーバーレイとフィルター {#effects}

- オーバーレイの濃さ：壁紙がにぎやかで検索ボックスが読みにくいときは濃く、画をもっと見せたいときは薄く。
- 壁紙効果：同じ絵に、違う質感を。強さや大きさを調整できる効果もあります。

| 効果 | 見え方 |
| --- | --- |
| すりガラス | 背景をぼかして内容を見やすく |
| 粒子 | フィルムのような細かなノイズ |
| ブロック | 画面をピクセルのブロックで組み直す |
| 網点 | 印刷物のようなドットスクリーン |
| ディザ | 限られた色で表現するレトロなディザリング |
| ASCII | 暗部や明部を文字で描き直す |
| CRT | 走査線、光のにじみ、画面の湾曲 |

## ほかのパソコンでも {#sync}

内蔵・Bing・厳選の壁紙の選択と画像リンクは、ブラウザの同期で引き継がれます。アップロードした画像はその端末にだけ保存されるので、ほかの端末でも使うなら WebDAV 同期をオンにしてください。
