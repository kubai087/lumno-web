新しいタブを開くたびに、好きな絵を表示できます。Lumno には名画や水墨画の壁紙が含まれており、Bing の今日の画像や、ご自身の写真も使用できます。

## 外観設定を開く {#open}

新しいタブの右下にある「外観」ボタンをクリックすると、右側に外観設定が開きます。壁紙は「壁紙」セクションで設定します。

![新しいタブの右側に外観設定パネルが開き、壁紙のセクションに入手元の選択肢と内蔵壁紙のサムネイルが並ぶ](nt-appearance "外観設定で壁紙を変更する")

## 壁紙の入手元 {#sources}

| 入手元 | 内容 |
| --- | --- |
| 内蔵 | Lumno に含まれる名画、水墨画、イラスト。ライト用とダーク用があります |
| この端末 | ご自身の JPG、PNG、WebP 画像（8 MB まで） |
| Bing | Bing の今日の画像。毎日自動で更新するか、過去 1 週間の画像から選択できます |
| 厳選 | 自然、水辺、都市、ミニマル、アートのカテゴリから選択できます。毎日自動で変更することもできます |

ウェブ上の画像を使用するには、「画像のリンクを追加」をクリックし、`https://` で始まる画像のアドレスを貼り付けます。

毎日の自動更新がオンの場合、手動で選択した壁紙はその日だけ表示され、翌日には毎日の壁紙に戻ります。

## ライトモードとダークモードで別の壁紙にする {#dark-mode}

「ライト/ダークで同じ」は初期設定でオンになっており、両方のモードで同じ壁紙が使用されます。オフにすると、モードごとに壁紙を選択できます。たとえば、昼は名画、夜は月夜の山水画にすることができます。

ライトモードとダークモードの切り替えは、パネルの一番上で設定します。システムに合わせるか、常にライトまたはダークにするかを選択でき、新しいタブだけに適用することもできます。

## オーバーレイとフィルター {#effects}

- オーバーレイの濃さ：壁紙の模様が多く、検索ボックスが読みにくい場合は濃くします。画像をよりはっきり見せたい場合は薄くします。
- 壁紙効果：同じ画像に別の質感を加えます。一部の効果では、強さや大きさを調整できます。

| 効果 | 内容 |
| --- | --- |
| すりガラス | 背景をぼかして、内容を見やすくします |
| 粒子 | フィルムのような細かなノイズを加えます |
| ブロック | 画像をピクセルのブロックで構成し直します |
| 網点 | 印刷物のようなドットスクリーンを加えます |
| ディザ | 限られた色数によるレトロなディザリングを加えます |
| ASCII | 暗い部分または明るい部分を文字で描き直します |
| CRT | 走査線、光のにじみ、画面の湾曲を加えます |

## ほかのデバイスで使用する {#sync}

内蔵、Bing、厳選の壁紙の選択と画像のリンクは、ブラウザの同期機能で同期されます。アップロードした画像は追加したパソコンにのみ保存されます。ほかのデバイスでも使用するには、[WebDAV 同期](../sync/#webdav)をオンにしてください。
