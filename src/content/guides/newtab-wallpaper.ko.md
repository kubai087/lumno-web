새 탭을 열 때마다 원하는 그림을 배경으로 표시할 수 있습니다. Lumno에는 고전 명화와 수묵 산수화가 포함되어 있으며, Bing 오늘의 사진이나 직접 가진 사진도 사용할 수 있습니다.

## Appearance 설정 열기 {#open}

새 탭 오른쪽 아래의 Appearance 버튼을 클릭하면 오른쪽에 Appearance 설정이 열립니다. 배경화면은 Wallpaper 항목에서 설정합니다.

![새 탭 오른쪽에 열린 Appearance 설정. 배경화면 출처와 기본 배경화면 썸네일이 보인다](nt-appearance "Appearance 설정에서 배경화면 변경하기")

## 배경화면 출처 {#sources}

| 출처 | 설명 |
| --- | --- |
| Built-in | Lumno에 포함된 명화, 수묵 산수화, 일러스트이며 라이트 버전과 다크 버전이 있습니다 |
| Local | 직접 가진 JPG, PNG, WebP 이미지(최대 8MB) |
| Bing | Bing 오늘의 사진이며, 매일 자동으로 바꾸거나 지난 일주일의 사진 중에서 선택할 수 있습니다 |
| Curated | 자연, 물, 도시, 미니멀, 예술 등 분류별 사진이며, 매일 자동으로 바꿀 수도 있습니다 |

웹에서 찾은 이미지를 사용하려면 "Add image link"를 클릭하고 `https://`로 시작하는 이미지 주소를 붙여 넣으세요.

매일 자동 변경이 켜져 있으면 직접 선택한 배경화면은 그날만 유지되며, 다음 날에는 그날의 배경화면으로 돌아갑니다.

## 라이트 모드와 다크 모드에 다른 배경화면 사용하기 {#dark-mode}

"Match light and dark mode"는 기본적으로 켜져 있으며, 두 모드에서 같은 배경화면을 사용합니다. 이 옵션을 끄면 모드별로 배경화면을 선택할 수 있습니다. 예를 들어 낮에는 명화를, 밤에는 달빛 풍경을 사용할 수 있습니다.

라이트 모드와 다크 모드는 패널 맨 위에서 설정합니다. 시스템 설정을 따르거나 라이트 또는 다크를 선택할 수 있으며, 확장 프로그램 전체 또는 새 탭에만 적용할 수 있습니다.

## 마스크와 필터 {#effects}

- 마스크 효과: 배경화면이 복잡해 검색창이 잘 보이지 않으면 마스크를 진하게 하고, 그림을 더 선명하게 보려면 옅게 하세요.
- 배경화면 필터: 같은 그림에 다른 질감을 더합니다. 일부 필터는 강도나 크기를 조절할 수 있습니다.

| 필터 | 효과 |
| --- | --- |
| Glass blur | 배경을 흐리게 하여 내용을 잘 보이게 합니다 |
| Grain | 필름 같은 고운 노이즈를 더합니다 |
| Blocks | 그림을 픽셀 블록으로 다시 구성합니다 |
| Halftone | 인쇄물 같은 망점을 더합니다 |
| Dither | 제한된 색으로 레트로 디더링을 더합니다 |
| ASCII | 어두운 부분이나 밝은 부분을 문자로 다시 그립니다 |
| CRT | 주사선, 빛 번짐, 화면 곡률을 더합니다 |

## 유리 재질 {#glass}

Appearance 설정의 Style 섹션에서 Material을 Default에서 Acrylic 또는 Liquid glass로 바꿀 수 있습니다. 검색창, 카드, 버튼, 메뉴, Appearance 패널이 유리 같은 질감으로 바뀌어 뒤쪽 배경화면이 비쳐 보이고, 유리의 색조도 배경화면에 맞춰 자동으로 조정됩니다.

![Liquid glass를 적용한 새 탭. 시계, 검색창, 바로가기, 북마크, 사이트 카드 뒤로 인상파 과수원 배경화면이 비쳐 보인다](nt-glass "Liquid glass")

| 재질 | 효과 |
| --- | --- |
| Default | Lumno의 기존 모습 |
| Acrylic | 부드럽게 흐려진 반투명 바탕 |
| Liquid glass | 더 투명한 유리. 검색창과 검색 결과의 가장자리가 렌즈처럼 뒤쪽 배경화면을 굴절시킵니다 |

두 가지 유리 재질은 모두 베타 기능이며, 배경화면과 함께 쓸 때 가장 잘 어울립니다. Firefox에서는 Liquid glass의 굴절 효과 없이 유리 질감만 표시됩니다.

## 다른 기기에서 사용하기 {#sync}

Built-in, Bing, Curated 배경화면 선택과 이미지 링크는 브라우저 동기화로 동기화됩니다. 직접 올린 로컬 이미지는 해당 컴퓨터에만 저장됩니다. 다른 기기에서도 사용하려면 [WebDAV 동기화](../sync/#webdav)를 켜세요.
