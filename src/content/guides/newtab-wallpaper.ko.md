새 탭을 열 때마다 그림 한 점을 만날 수 있어요. Lumno에는 고전 명화와 수묵 산수화가 들어 있고, Bing 오늘의 사진이나 내 사진을 쓸 수도 있어요.

## 배경화면 출처 {#sources}

| 출처 | 내용 |
| --- | --- |
| Built-in | Lumno 자체 명화, 수묵 산수화, 일러스트. 라이트와 다크 모두 있어요 |
| Local | 내 JPG, PNG, WebP 이미지. 최대 8MB |
| Bing | Bing 오늘의 사진. 매일 바뀌거나 지난 일주일 중에서 고를 수 있어요 |
| Curated | 자연, 물, 도시, 미니멀, 예술 등 카테고리별 사진. 원하면 매일 바뀌어요 |

인터넷에서 마음에 드는 그림을 찾았나요? "Add image link"를 누르고 `https://`로 시작하는 주소를 붙여 넣으세요.

매일 바뀌는 설정이 켜져 있으면 직접 고른 배경화면은 그날 하루만 유지되고, 다음 날에는 다시 그날의 배경화면으로 돌아와요.

## 낮에 하나, 밤에 하나 {#dark-mode}

"Match light and dark mode"는 기본으로 켜져 있어서 두 모드에 같은 배경화면을 써요. 끄면 따로 고를 수 있어요. 낮에는 명화, 밤에는 달빛 풍경처럼요.

라이트·다크 모드 자체는 패널 맨 위에 있어요. 시스템 설정을 따르거나 라이트, 다크 중에서 고르고, 확장 프로그램 전체에 적용할지 새 탭에만 적용할지도 정할 수 있어요.

## 마스크와 필터 {#effects}

- 마스크 효과: 배경화면이 복잡해서 검색창이 잘 안 보이면 마스크를 진하게, 그림을 더 또렷하게 보고 싶으면 옅게 하세요.
- 배경화면 필터: 같은 그림을 다른 질감으로 바꿔 줘요. 강도나 크기를 조절할 수 있는 필터도 있어요.

| 필터 | 효과 |
| --- | --- |
| Glass blur | 배경을 부드럽게 흐려 내용을 돋보이게 |
| Grain | 필름 같은 고운 노이즈 |
| Blocks | 픽셀 블록으로 그림을 다시 구성 |
| Halftone | 인쇄물 같은 망점 |
| Dither | 제한된 색으로 표현하는 레트로 디더링 |
| ASCII | 어두운 부분이나 밝은 부분을 문자로 다시 그리기 |
| CRT | 주사선, 글로우, 화면 곡률 |

## 다른 컴퓨터에서도 {#sync}

Built-in, Bing, Curated 배경화면 선택과 이미지 링크는 브라우저와 함께 동기화돼요. 직접 올린 로컬 이미지는 그 컴퓨터에만 남으니, 다른 곳에서도 쓰려면 WebDAV 동기화를 켜세요.
