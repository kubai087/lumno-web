每次打开新标签页，都可以是一幅画。Lumno 内置了名画和山水，也能每天换一张 Bing 壁纸，或者用你自己的照片。

## 打开外观设置 {#open}

点新标签页右下角的「外观」按钮，右边会滑出外观设置，壁纸就在「壁纸」这一节。

![新标签页右侧打开外观设置面板，壁纸一节中显示来源选项和内置壁纸缩略图](nt-appearance "在外观设置里换壁纸")

## 从哪里选 {#sources}

| 来源 | 说明 |
| --- | --- |
| 内置 | Lumno 自带的名画、山水和插画，浅色、深色都有 |
| 本地 | 用你自己的 JPG、PNG 或 WebP 图片，8 MB 以内 |
| Bing | Bing 每日一图，可以每天自动更新，也能从最近一周里挑 |
| 精选 | 自然、海与湖、城市、极简、艺术，按分类挑，也能每天换一张 |

看到喜欢的网图，也可以点「添加图片链接」，粘贴 `https://` 开头的图片地址。

开了每日自动更新后，手动选的壁纸当天有效，第二天会换回每日壁纸。

## 白天一张，夜里一张 {#dark-mode}

「深浅模式一致」默认是开着的，浅色和深色用同一张壁纸。关掉它，就能分开选：白天看名画，夜里换成月夜山水。

深浅色本身在面板最上面设：跟随系统、浅色或深色，也可以只对新标签页生效。

## 遮罩和滤镜 {#effects}

- 遮罩效果：壁纸太花、看不清搜索框时，把遮罩调浓一点；想让画面更透，就调淡。
- 壁纸滤镜：同一幅画，换一种质感。有的滤镜还能调强度和大小。

| 滤镜 | 效果 |
| --- | --- |
| 毛玻璃 | 柔化背景，让内容更清楚 |
| 颗粒 | 像胶片一样的细腻噪点 |
| 积木 | 把画面拼成一块块像素 |
| 网点 | 印刷品般的圆点网屏 |
| 抖色 | 有限色阶的复古抖动 |
| ASCII | 用字符重绘暗部或亮部 |
| CRT | 扫描线、光晕和屏幕曲率 |

## 换台电脑也在 {#sync}

内置、Bing、精选壁纸的选择和图片链接，会跟着浏览器同步。你上传的本地图片只存在这台电脑上，想在别的设备也用，可以开启 WebDAV 同步。
