每次開啟新分頁，都可以是一幅畫。Lumno 內建名畫和山水，也能每天換一張 Bing 桌布，或用你自己的照片。

## 開啟外觀設定 {#open}

按新分頁右下角的「外觀」按鈕，右側會滑出外觀設定，桌布就在「桌布」這一節。

![新分頁右側開啟外觀設定面板，桌布一節顯示來源選項和內建桌布縮圖](nt-appearance "在外觀設定裡換桌布")

## 從哪裡選 {#sources}

| 來源 | 說明 |
| --- | --- |
| 內建 | Lumno 內建的名畫、山水和插畫，淺色、深色都有 |
| 本機 | 用你自己的 JPG、PNG 或 WebP 圖片，8 MB 以內 |
| Bing | Bing 每日一圖，可以每天自動更新，也能從最近一週裡挑 |
| 精選 | 自然、海與湖、城市、極簡、藝術，依分類挑，也能每天換一張 |

看到喜歡的網路圖片，也可以按「新增圖片連結」，貼上 `https://` 開頭的圖片網址。

開啟每日自動更新後，手動選的桌布當天有效，隔天會換回每日桌布。

## 白天一張，晚上一張 {#dark-mode}

「深淺模式一致」預設是開啟的，淺色和深色用同一張桌布。關掉它，就能分開選：白天看名畫，晚上換成月夜山水。

深淺色本身在面板最上方設定：跟隨系統、淺色或深色，也可以只套用到新分頁。

## 遮罩和濾鏡 {#effects}

- 遮罩效果：桌布太花、看不清搜尋框時，把遮罩調濃一點；想讓畫面更透，就調淡。
- 桌布濾鏡：同一幅畫，換一種質感。有些濾鏡還能調整強度和大小。

| 濾鏡 | 效果 |
| --- | --- |
| 毛玻璃 | 柔化背景，讓內容更清楚 |
| 顆粒 | 像底片一樣的細緻雜訊 |
| 積木 | 把畫面拼成一塊塊像素 |
| 網點 | 印刷品般的圓點網屏 |
| 混色 | 有限色階的復古抖動 |
| ASCII | 用字元重繪暗部或亮部 |
| CRT | 掃描線、光暈和螢幕曲率 |

## 換台電腦也在 {#sync}

內建、Bing、精選桌布的選擇和圖片連結，會跟著瀏覽器同步。你上傳的本機圖片只存在這台電腦上，想在其他裝置也用，可以開啟 WebDAV 同步。
