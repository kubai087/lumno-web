讓每次開啟的新分頁都是一幅畫。Lumno 內建名畫和山水桌布，也支援每天自動更換 Bing 桌布，或者使用你自己的照片。

## 開啟外觀設定 {#open}

按一下新分頁右下角的「外觀」按鈕，右側會展開外觀設定面板，桌布選項位於「桌布」一節。

![新分頁右側開啟外觀設定面板，桌布一節顯示來源選項和內建桌布縮圖](nt-appearance "在外觀設定中更換桌布")

## 桌布來源 {#sources}

| 來源 | 說明 |
| --- | --- |
| 內建 | Lumno 內建的名畫、山水和插畫，提供淺色和深色版本 |
| 本機 | 使用你自己的 JPG、PNG 或 WebP 圖片，大小不超過 8 MB |
| Bing | Bing 每日一圖，可以每天自動更新，也可以從最近一週的圖片中選擇 |
| 精選 | 分為自然、海與湖、城市、極簡、藝術等類別，也可以每天自動更換 |

如果看到喜歡的網路圖片，也可以按一下「新增圖片連結」，貼上以 `https://` 開頭的圖片網址。

開啟每日自動更新後，手動選擇的桌布僅當天有效，隔天會恢復為每日桌布。

## 為深色模式另外設定 {#dark-mode}

「深淺模式一致」預設開啟，淺色和深色模式使用同一張桌布。關閉後即可分別選擇，例如白天使用名畫，晚上換成月夜山水。

深淺色模式本身在面板頂端設定，可以選擇跟隨系統、淺色或深色，也可以只套用到新分頁。

## 遮罩和濾鏡 {#effects}

- 遮罩效果：桌布過於繁複、搜尋框不夠清楚時，可以加深遮罩；想讓畫面更通透時，可以調淡遮罩。
- 桌布濾鏡：為同一幅畫換一種質感。部分濾鏡還可以調整強度和大小。

| 濾鏡 | 效果 |
| --- | --- |
| 毛玻璃 | 柔化背景，讓內容更清楚 |
| 顆粒 | 類似底片的細緻雜訊 |
| 積木 | 把畫面拼成一塊塊像素 |
| 網點 | 類似印刷品的圓點網屏 |
| 混色 | 有限色階的復古抖動 |
| ASCII | 用字元重繪暗部或亮部 |
| CRT | 掃描線、光暈和螢幕曲率 |

## 在其他裝置上使用 {#sync}

內建、Bing、精選桌布的選擇以及圖片連結，會隨瀏覽器同步。你上傳的本機圖片只保存在目前的電腦上；如需在其他裝置上使用，可以開啟 [WebDAV 同步](../sync/#webdav)。
