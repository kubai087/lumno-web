Lumno에는 계정도, 사용자 데이터를 저장하는 서버도 없어요. 탭, 북마크, 방문 기록은 내 브라우저 안에서만 처리되고 우리에게 전송되지 않습니다. 여기서는 간단히 요약했고, 전문은 [개인정보처리방침](/ko/privacy/)에서 볼 수 있어요.

## 기기에 남는 것 {#local}

검색, 전환, 새 탭 표시를 위해 Lumno는 기기 안에서 다음을 읽어요.

- 열린 탭, 방문 기록, 북마크, 자주 가는 사이트
- Lumno에 입력한 내용과 고른 결과(자주 쓰는 결과가 위로 오도록)
- 설정, 그리고 직접 올린 아이콘과 배경화면

전환기의 페이지 미리보기도 기기에 남아요. 최대 12개이고, 각각 최대 2시간 동안만 보관돼요.

## 수집하지 않는 것 {#not-collected}

가입도 로그인도 없어요. Lumno는 이름이나 이메일을 수집하지 않고, 사용 횟수, 클릭, 기기 식별자, 오류 데이터도 보내지 않아요.

## 컴퓨터 밖으로 나가는 요청 {#requests}

다음 요청은 확장 프로그램에서 해당 서비스로 바로 가고, 우리를 거치지 않아요.

| 요청 | 받는 곳 | 시점 |
| --- | --- | --- |
| 추천 검색어 | 사용하는 검색 엔진(Google, Bing 등) | Lumno 검색창에 입력할 때 |
| 검색과 AI 질문 | 내가 고른 사이트나 AI | Return을 누를 때 |
| 사이트 아이콘 | Google 파비콘 서비스 또는 Favicon.is | 사이트 아이콘을 보여 줄 때 |
| 배경화면 | Bing, Lorem Picsum, 클리블랜드 미술관 | 온라인 배경화면을 쓸 때 |
| 업데이트 안내 | GitHub | 확장 프로그램이 업데이트된 뒤 |

## 설정 동기화 방식 {#sync}

- 브라우저와 함께: 테마, 바로가기, 배경화면 선택 같은 설정은 브라우저 계정으로 동기화돼요.
- WebDAV(선택): 기본으로 꺼져 있어요. 켜면 전체 설정, 직접 올린 아이콘과 배경화면이 내가 고른 서버에 저장돼요. 방문 기록, 북마크, 탭은 올라가지 않아요.
- 내보내기와 가져오기: 설정을 파일로 저장해 다른 컴퓨터에서 가져올 수 있어요.

설정 방법은 [동기화](../sync/)를 참고하세요.

## 이 웹사이트에 대해 {#website}

이 웹사이트(lumno.kubai.design)는 방문자 수와 유입 경로를 알기 위해 분석 도구를 써요. 확장 프로그램과는 별개이며, 확장 프로그램은 분석 도구를 전혀 불러오지 않아요.
