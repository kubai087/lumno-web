タブが何十個、ブックマークが何百件にもなると、目的のページを探すのに、開くよりも時間がかかることがあります。Lumno では、これらを 1 つの検索ボックスで検索できます。ショートカットキーを押して数文字入力すると、開いているタブ、ブックマーク、履歴がまとめて表示されます。

## 検索ボックスを開く {#open}

どのページでも `⌘ ⇧ K` を押すと、画面の中央に検索ボックスが開きます。閉じるには、`Esc` キーを押すか、検索ボックスの外側をクリックします。

`chrome://` の設定ページや拡張機能ストアなどの制限ページでは、ブラウザが拡張機能の表示を許可していません。これらのページでは、設定の「制限ページでの動作」に従って処理されます。

## 検索結果 {#results}

各結果の右側に表示されるラベルは、その結果の種類を示します。

- 開いている：現在開いているタブです。Enter キーを押すとそのタブに切り替わり、同じページが重複して開くことはありません。
- ブックマーク：ブックマークバーや各フォルダ内のページです。保存先のフォルダも表示されます。
- よく使う・履歴：よくアクセスするサイトと閲覧履歴です。

検索エンジンの検索候補も表示され、Enter キーを押すと検索できます。よく選択する結果ほど、上位に表示されます。

`baidu。com` のように句点（。）で区切ったドメインを入力すると、URL として開きます。「。」で終わる普通の文は、そのまま検索されます。

![空白のページで Lumno を開き、chrome と入力すると、開いている GitHub のタブ、検索候補、ブックマーク、よくアクセスするサイトが並ぶ](search "chrome と入力すると、開いているタブ、ブックマーク、よくアクセスするサイトがまとめて表示される")

そのほかの便利なキー：`⌥ ↩` を押すと現在のタブで開き、`⇧ ↩` を押すと開いているタブを新しいタブでもう 1 つ開きます。すべてのキーについては、[キーボードショートカット](../keyboard-shortcuts/#command-bar-keys)を参照してください。

## キーボード配列を切り替え忘れたとき {#keyboard-layout}

入力した内容がタブ、ブックマーク、履歴のどれにも一致しない場合、Lumno はそれをロシア語、ウクライナ語、ヘブライ語、アラビア語、韓国語（2 ボル式）のキーボードで入力したものとして読み直します。たとえば `vjcrdf` で Москва が見つかります。逆に、ロシア語配列のまま入力した `пшерги` でも GitHub が見つかります。こうした結果は、そのまま一致した結果の下に表示されます。

検索では、全角と半角、アクセント記号などの違いも区別しません。韓国語は初声でも検索でき、`ㅅㅇ` で 서울 が見つかります。検索範囲パネルでも同じ方法で照合します。

中国語のタイトルは、ピンイン、頭文字、またはその組み合わせでも検索できます（`wxds`、`wxdushu`、`weixinds` のいずれでも 微信读书 が見つかります）。z と zh、c と ch、s と sh、n と l、an と ang、en と eng、in と ing を同じとみなすには、Lumno の設定の「検索結果設定」で「ピンインのあいまい音」をオンにします。

## 開いているタブだけを検索する {#open-tabs}

タブが多いときは、検索範囲を絞り込めます。検索ボックスが空のときに `Tab` を 1 回押すと、左側に「開いているタブを検索」と表示され、開いているタブだけが一覧に残ります。キーワードを入力して絞り込み、Enter キーで切り替えます。`Esc` キーを押すと元に戻ります。

![検索ボックスの左に「開いているタブを検索」と表示され、開いているタブだけが並ぶ](opentabs "開いているタブだけを検索")

ブックマーク、履歴、よくアクセスするサイトだけを検索したい場合は、検索ボックスが空のときに `Tab` を 2 回押し、検索範囲パネルから選択します。

## 他のタブを閉じる {#close-other-tabs}

タブが増えすぎたときは、検索ボックス右側のブラシアイコンをクリックし、表示された確認で「閉じる」をクリックすると、現在のウィンドウにある他のタブをまとめて閉じられます。現在のタブ、固定したタブ、タブグループ内のタブは残ります。このボタンはコマンドバーと新しいタブの検索ボックスの両方にあります。

やめる場合は、もう一度ブラシアイコンをクリックするか、`Esc` を押すか、確認の外側をクリックします。
