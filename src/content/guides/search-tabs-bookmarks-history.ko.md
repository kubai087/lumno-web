탭이 수십 개, 북마크가 수백 개가 되면 페이지를 여는 것보다 찾는 데 더 오래 걸릴 수 있습니다. Lumno에서는 이 모든 항목을 검색창 하나에서 검색할 수 있습니다. 단축키를 누르고 몇 글자를 입력하면 열린 탭, 북마크, 방문 기록이 함께 표시됩니다.

## 검색창 열기 {#open}

어떤 페이지에서든 `⌘ ⇧ K`를 누르면 화면 가운데에 검색창이 나타납니다. 닫으려면 `Esc`를 누르거나 검색창 바깥을 클릭하세요.

`chrome://` 설정이나 확장 프로그램 스토어 같은 제한된 페이지에서는 브라우저가 확장 프로그램의 화면 표시를 허용하지 않습니다. 이러한 페이지에서는 Lumno 설정의 "Restricted page behavior" 옵션에 따라 처리됩니다.

## 검색 결과 {#results}

각 결과 옆의 표시는 해당 결과의 출처를 나타냅니다.

- Opened: 현재 열려 있는 탭입니다. `↩` 키를 누르면 같은 페이지를 새로 여는 대신 해당 탭으로 전환합니다.
- Bookmark: 북마크바나 폴더에 있는 페이지이며, 폴더 이름도 함께 표시됩니다.
- Frequent, History: 자주 방문하는 사이트와 방문 기록입니다.

검색 엔진의 추천 검색어도 함께 표시되며, `↩` 키를 누르면 검색합니다. 주소창과 마찬가지로 방향키로 추천 검색어를 선택하면 검색창에 채워지고, `Esc`를 누르면 입력하던 내용으로 돌아갑니다. 자주 선택하는 결과일수록 위에 표시됩니다.

기본적으로 목록의 첫 번째 결과는 자동 완성된 페이지입니다. 검색을 주로 한다면 Lumno 설정의 Search Result Settings에서 First Search Result Priority를 Search First로 바꾸세요. 첫 번째 결과가 검색이 되고, 입력한 내용과 제목이 똑같은 북마크, 방문 기록, 자주 방문하는 사이트가 바로 다음에 표시됩니다.

![빈 페이지에서 연 Lumno: chrome을 입력하자 열린 GitHub 탭, 추천 검색어, 북마크, 자주 가는 사이트가 나타난다](search "chrome을 입력하면 열린 탭, 북마크, 자주 가는 사이트가 함께 표시됨")

이 밖에 `⌥ ↩`를 누르면 현재 탭에서 열고, `⇧ ↩`를 누르면 열린 탭을 새 탭에서 하나 더 엽니다. 모든 키는 [단축키](../keyboard-shortcuts/#command-bar-keys)를 참고하세요.

## 현재 탭에서 열기 {#current-tab}

웹페이지에서 명령 바를 열면 결과는 기본적으로 새 탭에서 열리고, 보던 페이지는 그대로 남습니다. 주소창처럼 현재 탭에서 열려면 Lumno 설정의 General → Command Bar에서 Open in a new tab when clicked를 끄세요. 끄면 다음과 같이 바뀝니다.

- 페이지, 검색, 입력한 주소, 사이트 내 검색이 현재 탭에서 열리고, 결과 오른쪽의 안내가 New Tab에서 Go로 바뀝니다.
- 고정된 탭에서 명령 바를 열면 고정된 페이지가 바뀌지 않도록 결과가 계속 새 탭에서 열립니다.
- 이미 열려 있는 탭으로는 지금처럼 바로 전환됩니다.

어떻게 설정하든 `⌥`를 누른 채 `↩` 키를 누르거나 클릭하면 다른 방식으로 열리고, `⌘`를 누른 채 열면 백그라운드 탭에서 열립니다. 새 탭의 검색창은 따로 설정합니다. [새 탭의 키](../keyboard-shortcuts/#newtab-keys)를 참고하세요.

## 키보드 자판을 바꾸지 않고 입력했을 때 {#keyboard-layout}

입력한 내용이 탭, 북마크, 기록 어디에도 일치하지 않으면 Lumno는 이를 러시아어, 우크라이나어, 히브리어, 아랍어 또는 한국어 두벌식 자판으로 입력한 것으로 다시 읽습니다. 예를 들어 영문 자판 상태로 `tkatjd`를 입력해도 삼성이 조합되어 검색되고, `vjcrdf`로 Москва를 찾을 수 있습니다. 반대로 한글 자판 상태로 입력한 내용도 영문으로 다시 읽어 찾습니다. 이런 결과는 그대로 일치하는 결과보다 아래에 표시됩니다.

검색할 때는 전각·반각 문자나 악센트 기호 같은 표기 차이도 무시합니다. 한국어는 초성으로도 검색할 수 있어 `ㅅㅇ`으로 서울을 찾을 수 있고, 입력 중인 음절도 일치시킵니다. 검색 범위 패널도 같은 방식으로 찾습니다.

중국어 제목은 병음, 첫 글자 또는 둘을 섞어서도 찾을 수 있습니다(`wxds`, `wxdushu`, `weixinds` 모두 微信读书를 찾음). z와 zh, c와 ch, s와 sh, n과 l, an과 ang, en과 eng, in과 ing을 같게 취급하려면 Lumno 설정의 Search Result Settings에서 Fuzzy pinyin을 켜세요.

## 열린 탭만 검색하기 {#open-tabs}

탭이 많을 때는 검색 범위를 좁힐 수 있습니다. 검색창이 비어 있을 때 `Tab`을 한 번 누르면 왼쪽에 "Search open tabs"가 표시되고 열린 탭만 목록에 남습니다. 검색어를 입력해 결과를 좁히고, `↩` 키로 전환하고, `Esc`로 나가세요.

![검색창 왼쪽에 "Search open tabs"가 표시되고, 지금 열린 탭만 목록에 남아 있다](opentabs "열린 탭만 검색")

북마크, 방문 기록, 자주 가는 사이트만 검색하려면 검색창이 비어 있을 때 `Tab`을 두 번 누른 다음 검색 범위 패널에서 선택하세요.

## 다른 탭 닫기 {#close-other-tabs}

탭이 너무 많이 쌓였다면 검색창 오른쪽의 브러시 아이콘을 클릭하고, 나타나는 확인 창에서 Close를 클릭해 현재 창의 다른 탭을 한 번에 닫을 수 있습니다. 현재 탭, 고정 탭, 탭 그룹에 속한 탭은 그대로 남습니다. 이 버튼은 명령 바와 새 탭 검색창에 모두 있습니다.

마음이 바뀌었다면 브러시 아이콘을 다시 클릭하거나, `Esc`를 누르거나, 확인 창 바깥을 클릭하세요.
