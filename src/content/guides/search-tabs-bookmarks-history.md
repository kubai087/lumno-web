标签页开到几十个、书签存了几百个时，找到某个页面往往比打开它还要费时。Lumno 把它们集中到一个搜索框中：按下快捷键，输入几个字，已打开的标签页、收藏的书签和浏览过的页面会一并列出。

## 唤出搜索框 {#open}

在任意网页按下 `⌘ ⇧ K`，搜索框会出现在页面中央。按 `Esc` 或点击搜索框以外的区域即可关闭。

在 `chrome://` 设置页、扩展商店等受限页面上，浏览器不允许扩展显示内容，Lumno 会按照设置中「在受限页行为」选项的设定处理。

## 搜索结果 {#results}

每条结果右侧的标签表示它的来源：

- 已打开：当前打开的标签页。按回车键会直接切换过去，不会重复打开。
- 书签：书签栏和各个文件夹中的网页，同时显示所在的文件夹。
- 常用、历史：最常访问的网站和浏览历史。

列表中还会显示当前搜索引擎的搜索建议，按回车键即可搜索。你选择得越频繁的结果，排序越靠前。

输入 `baidu。com` 这样用中文句号分隔的域名时，Lumno 会把它当作网址直接打开；以「。」结尾的普通句子仍然会搜索。

![在空白网页上唤出 Lumno，输入 chrome 后，列表中依次是已打开的 GitHub 标签页、搜索建议、书签和常用网站](search "输入 chrome 后，已打开的标签页、书签和常用网站一并列出")

常用按键：`⌥ ↩` 在当前标签页中打开，`⇧ ↩` 在新标签页中再打开一份已打开的页面。全部按键见[快捷键](../keyboard-shortcuts/#command-bar-keys)。

## 用拼音搜索中文 {#pinyin}

无需切换输入法。例如输入 `shaoshupai`，即可找到标题中含有「少数派」的标签页和书签。

![输入 shaoshupai 后，找到了标题含“少数派”的已打开标签页和书签](pinyin "用拼音搜索中文标题")

- 全拼、首字母或两者混合都可以：`wxds`、`wxdushu`、`weixinds` 都能找到「微信读书」。
- 词语可以不连续，也可以换顺序：搜索「飞书文档」，也能找到「飞书云文档」和「文档 - 飞书」。
- 多音字的每个读音都能匹配，`lv` 能找到「绿色」；繁体标题可以用简体或拼音搜索。
- 用中文也能找到用拼音或首字母命名的网址，例如「知乎」能找到 zhihu.com，「京东」能找到 jd.com。
- 结果中会标出拼音匹配到的字，较早的历史记录也能用拼音找到。

分不清平翘舌或前后鼻音时，可以在 Lumno 设置的「搜索结果设置」中开启「拼音模糊音」。开启后，z 与 zh、c 与 ch、s 与 sh、n 与 l、an 与 ang、en 与 eng、in 与 ing 都视为相同。

## 忘记切换键盘布局 {#keyboard-layout}

如果输入的内容在本地没有任何结果，Lumno 会把它按俄语、乌克兰语、希伯来语、阿拉伯语或韩语两套式键盘重新读一遍，例如 `vjcrdf` 能找到「Москва」；反过来，在这些键盘下误输入的 `пшерги` 也能找到 GitHub。这类结果排在直接匹配的结果之后。

搜索时还会忽略全角与半角、重音符号等写法差异；韩文可以用初声搜索，例如 `ㅅㅇ` 能找到「서울」。搜索范围面板也使用同样的匹配方式。

## 只搜索已打开的标签页 {#open-tabs}

标签页较多时，可以缩小搜索范围：在搜索框为空时按一次 `Tab`，左侧会显示「搜索已打开标签页」，列表中只保留已打开的页面。继续输入关键词进行筛选，按回车键切换，按 `Esc` 退出。

![搜索框左侧显示“搜索已打开标签页”，下方只列出当前打开的标签页](opentabs "只搜索已打开的标签页")

如果只想搜索书签、历史记录或常用网站，可以在搜索框为空时连按两次 `Tab`，在搜索范围面板中选择。

## 关闭其他标签页 {#close-other-tabs}

标签页越开越多时，点击搜索框右侧的刷子图标，在弹出的提示中点击「关闭」，即可关闭当前窗口中的其他标签页。当前标签页、固定的标签页和标签页组中的标签页都会保留。命令栏和新标签页的搜索框中都有这个按钮。

如果改变主意，再次点击刷子图标、按 `Esc` 或点击提示以外的区域即可取消。
