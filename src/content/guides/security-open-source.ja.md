Lumno のコードはすべて公開されているため、拡張機能が何をしていて、何をしていないのかを誰でも確認できます。

## オープンソース {#open-source}

- コード：[github.com/kubai087/lumno-extension](https://github.com/kubai087/lumno-extension)
- ライセンス：GPL-3.0
- 問題の報告：GitHub で Issue を作成してください

ストアで公開している各バージョンは、同じコードからビルドしています。変更内容は、[更新履歴](/ja/release/)と GitHub Releases で確認できます。

## セキュリティに配慮した設計 {#design}

- Manifest V3：ブラウザは、Manifest V3 の拡張機能がリモートのコードをダウンロードして実行することを許可していません。Lumno のコードはすべて、審査を受けたパッケージに含まれています。
- サーバーなし：アカウントの仕組みも、ユーザーのデータを保存する場所もありません。
- WebDAV のアプリパスワードはデバイス上にのみ保存され、ブラウザの同期機能で同期されることはありません。

## 権限 {#permissions}

Lumno は必要な権限だけを要求し、任意の権限は要求しません。すべてのサイトへのアクセス権限は、ページ上でコマンドバーなどの機能を表示するためにのみ使用します。Lumno がページの内容をまとめて読み取ったり、アップロードしたりすることはありません。

各権限の具体的な用途は、[プライバシーポリシー](/ja/privacy/#permissions)で説明しています。
