## 安全のための設計 {#design}

- Manifest V3：ブラウザは Manifest V3 の拡張機能がリモートのコードをダウンロードして実行することを許可していません。Lumno のコードはすべて、審査済みのパッケージに含まれています。
- サーバーなし：アカウントの仕組みも、あなたのデータを保存する場所もありません。
- 必要な権限だけを要求し、任意の権限は要求しません。
- WebDAV のアプリパスワードは端末内にだけ保存され、ブラウザの同期には乗りません。

## 各権限の用途 {#permissions}

| 権限 | 用途 |
| --- | --- |
| `tabs`、`tabGroups` | タブの検索・切り替え・復元、切り替え画面のプレビュー撮影 |
| `history` | 端末内での履歴の検索 |
| `bookmarks` | ブックマークの検索・表示・管理 |
| `topSites` | 新しいタブによくアクセスするサイトを表示 |
| `storage`、`unlimitedStorage` | 設定、アイコン、壁紙の保存 |
| `alarms` | WebDAV 同期の状態を定期的に確認 |
| `search` | 既定の検索エンジンに検索を渡す |
| `favicon` | サイトのアイコンを表示 |
| `scripting` とすべてのサイトへのアクセス | ページ上でのコマンドバーの表示、ショートカットへの応答、文字選択の操作、ピクチャー・イン・ピクチャー |

すべてのサイトへのアクセス権は、ページ上でコマンドバーなどを表示するためだけに使います。Lumno がページの内容をまとめて読み取ったり、アップロードしたりすることはありません。
