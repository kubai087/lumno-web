ストアで公開している各バージョンは、同じコードからビルドしています。変更内容は、[更新履歴](/ja/release/)と GitHub Releases で確認できます。

## セキュリティに配慮した設計 {#design}

- Manifest V3：ブラウザは、Manifest V3 の拡張機能がリモートのコードをダウンロードして実行することを許可していません。Lumno のコードはすべて、審査を受けたパッケージに含まれています。
- サーバーなし：アカウントの仕組みも、ユーザーのデータを保存する場所もありません。
- 最小限の権限：必要な権限だけを要求し、任意の権限は要求しません。
- WebDAV のアプリパスワードはデバイス上にのみ保存され、ブラウザの同期機能で同期されることはありません。

## 各権限の用途 {#permissions}

| 権限 | 用途 |
| --- | --- |
| `tabs`、`tabGroups` | タブの検索、切り替え、復元、および切り替え画面のプレビューの撮影 |
| `history` | デバイス上での履歴の検索 |
| `bookmarks` | ブックマークの検索、表示、管理 |
| `topSites` | 新しいタブでのよくアクセスするサイトの表示 |
| `storage`、`unlimitedStorage` | 設定、アイコン、壁紙の保存 |
| `alarms` | WebDAV 同期の状態の定期的な確認 |
| `search` | 既定の検索エンジンへの検索の受け渡し |
| `favicon` | サイトのアイコンの表示 |
| `scripting` とすべてのサイトへのアクセス | ページ上でのコマンドバーの表示、ショートカットキーへの応答、選択テキストの操作、ピクチャー・イン・ピクチャー |

すべてのサイトへのアクセス権限は、ページ上でコマンドバーなどの機能を表示するためにのみ使用します。Lumno がページの内容をまとめて読み取ったり、アップロードしたりすることはありません。
