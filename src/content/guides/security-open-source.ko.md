스토어에 배포되는 모든 버전은 같은 코드로 빌드됩니다. 변경 내용은 [업데이트 내역](/ko/release/)과 GitHub Releases에서 확인할 수 있습니다.

## 보안을 고려한 설계 {#design}

- Manifest V3: 브라우저는 Manifest V3 확장 프로그램이 원격 코드를 내려받아 실행하는 것을 허용하지 않습니다. Lumno의 모든 코드는 심사를 거친 패키지 안에 포함되어 있습니다.
- 서버 없음: 계정 시스템도, 사용자 데이터를 저장하는 곳도 없습니다.
- WebDAV 앱 비밀번호는 기기에만 저장되며, 브라우저 동기화로 동기화되지 않습니다.

## 권한 {#permissions}

Lumno는 꼭 필요한 권한만 요청하며, 선택 권한은 요청하지 않습니다. 모든 사이트에 대한 접근 권한은 페이지에 명령 바 등의 기능을 표시하는 데만 사용됩니다. Lumno는 페이지 내용을 대량으로 읽거나 업로드하지 않습니다.

권한별 구체적인 용도는 [개인정보처리방침](/ko/privacy/#permissions)에서 확인할 수 있습니다.
