## 보안을 고려한 설계 {#design}

- Manifest V3: 브라우저는 Manifest V3 확장 프로그램이 원격 코드를 내려받아 실행하는 것을 허용하지 않습니다. Lumno의 모든 코드는 심사를 거친 패키지 안에 포함되어 있습니다.
- 서버 없음: 계정 시스템도, 사용자 데이터를 저장하는 곳도 없습니다.
- 최소 권한: 꼭 필요한 권한만 요청하며, 선택 권한은 요청하지 않습니다.
- WebDAV 앱 비밀번호는 기기에만 저장되며, 브라우저 동기화로 동기화되지 않습니다.

## 권한별 용도 {#permissions}

| 권한 | 용도 |
| --- | --- |
| `tabs`, `tabGroups` | 탭 검색, 전환, 복원 및 전환기 미리보기 캡처 |
| `history` | 기기에서 방문 기록 검색 |
| `bookmarks` | 북마크 검색, 표시, 관리 |
| `topSites` | 새 탭에 자주 방문하는 사이트 표시 |
| `storage`, `unlimitedStorage` | 설정, 아이콘, 배경화면 저장 |
| `alarms` | WebDAV 동기화 상태를 주기적으로 확인 |
| `search` | 기본 검색 엔진으로 검색어 전달 |
| `favicon` | 사이트 아이콘 표시 |
| `scripting` 및 모든 사이트에 대한 접근 | 페이지에 명령 바 표시, 단축키 응답, 텍스트 선택 작업, PIP |

모든 사이트에 대한 접근 권한은 페이지에 명령 바 등의 기능을 표시하는 데만 사용됩니다. Lumno는 페이지 내용을 대량으로 읽거나 업로드하지 않습니다.
