## Безопасность на уровне архитектуры {#design}

- Manifest V3: браузеры не позволяют расширениям Manifest V3 загружать и выполнять удалённый код, поэтому весь код Lumno содержится в проверенном пакете.
- Без серверов: нет ни системы аккаунтов, ни места, где хранились бы ваши данные.
- Минимальные разрешения: Lumno запрашивает только необходимые разрешения и не запрашивает необязательных.
- Пароль приложения WebDAV хранится только на вашем устройстве и никогда не передаётся через синхронизацию браузера.

## Для чего используется каждое разрешение {#permissions}

| Разрешение | Назначение |
| --- | --- |
| `tabs`, `tabGroups` | Поиск, переключение и восстановление вкладок; создание предпросмотров для переключателя |
| `history` | Поиск по истории на вашем устройстве |
| `bookmarks` | Поиск, отображение и управление закладками |
| `topSites` | Показ часто посещаемых сайтов на новой вкладке |
| `storage`, `unlimitedStorage` | Хранение настроек, значков и обоев |
| `alarms` | Периодическая проверка состояния синхронизации через WebDAV |
| `search` | Передача запросов поисковой системе по умолчанию |
| `favicon` | Отображение значков сайтов |
| `scripting` и доступ ко всем сайтам | Показ командной строки на страницах, реакция на сочетания клавиш, действия с выделенным текстом и режим «картинка в картинке» |

Доступ ко всем сайтам используется только для показа командной строки и похожих функций на страницах. Lumno не считывает и не загружает содержимое страниц в массовом порядке.
