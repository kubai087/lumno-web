Каждая строка кода Lumno открыта, поэтому любой может проверить, что расширение делает и чего не делает.

Каждая версия в магазинах собирается из этого же кода, а изменения перечислены в разделе [«Что нового»](/ru/release/) и в GitHub Releases.

## Безопасность по замыслу {#design}

- Manifest V3: браузеры не позволяют расширениям на Manifest V3 загружать и выполнять удалённый код, поэтому весь код Lumno находится в проверенном пакете.
- Никаких серверов: нет ни системы аккаунтов, ни места, где хранились бы ваши данные.
- Только необходимые разрешения, никаких дополнительных.
- Пароль приложения для WebDAV остаётся на устройстве и никогда не передаётся через синхронизацию браузера.

## Зачем нужно каждое разрешение {#permissions}

| Разрешение | Для чего |
| --- | --- |
| `tabs`, `tabGroups` | Поиск, переключение и восстановление вкладок; превью для переключателя |
| `history` | Поиск по истории на вашем устройстве |
| `bookmarks` | Поиск, показ и управление закладками |
| `topSites` | Показ часто посещаемых сайтов на новой вкладке |
| `storage`, `unlimitedStorage` | Хранение настроек, значков и обоев |
| `alarms` | Периодическая проверка состояния синхронизации WebDAV |
| `search` | Передача запросов поисковой системе по умолчанию |
| `favicon` | Показ значков сайтов |
| `scripting` и доступ ко всем сайтам | Показ командной строки на страницах, реакция на сочетания клавиш, действия с текстом и «картинка в картинке» |

Доступ ко всем сайтам используется только для того, чтобы показывать на страницах командную строку и похожие функции. Lumno не читает и не загружает содержимое страниц массово.
