Весь код Lumno открыт, поэтому любой может проверить, что расширение делает и чего не делает.

## Открытый код {#open-source}

- Код: [github.com/kubai087/lumno-extension](https://github.com/kubai087/lumno-extension)
- Лицензия: GPL-3.0
- Сообщить о проблеме: создайте issue на GitHub

Каждая версия в магазинах собирается из этого же кода. Изменения перечислены в разделе [«Что нового»](/ru/release/) и в GitHub Releases.

## Безопасность на уровне архитектуры {#design}

- Manifest V3: браузеры не позволяют расширениям Manifest V3 загружать и выполнять удалённый код, поэтому весь код Lumno содержится в проверенном пакете.
- Без серверов: нет ни системы аккаунтов, ни места, где хранились бы ваши данные.
- Пароль приложения WebDAV хранится только на вашем устройстве и никогда не передаётся через синхронизацию браузера.

## Разрешения {#permissions}

Lumno запрашивает только необходимые разрешения и не запрашивает необязательных. Доступ ко всем сайтам используется только для показа командной строки и похожих функций на страницах. Lumno не считывает и не загружает содержимое страниц в массовом порядке.

Зачем нужно каждое разрешение, описано в [Политике конфиденциальности](/ru/privacy/#permissions).
