To search GitHub, you'd normally open GitHub first and then use its search box. With Lumno, you can skip the home page: type the site's shortcut, press `Tab`, type your search and press Return to go straight to the results. Asking AI works the same way.

## How to use site search {#how}

1. Press `⌘ ⇧ K` (`Ctrl + Shift + K` on Windows) on any page.
2. Type a site shortcut, such as `gh`.
3. Press `Tab`. GitHub appears on the left of the search box.
4. Type your search and press Return.

![The search box shows GitHub on the left; typing command palette offers to search GitHub for command palette](sitesearch "Type gh and press Tab to search GitHub directly")

To return to a normal search, press `Esc`.

## Ask AI {#ai}

Type the AI's shortcut, press `Tab`, write your question and press Return. Lumno opens that AI's web app and sends the question for you.

| AI | Shortcut |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![The search box shows ChatGPT on the left with a question about alternatives to Arc's command bar, ready to open ChatGPT](ai "Type gpt and press Tab to send your question to ChatGPT")

## Choose from the search scope panel {#scope-panel}

Press `Tab` twice while the search box is empty to open the search scope panel. Search engines, sites and AI are grouped by category. Use the arrow keys to choose one, or type to filter.

![The search scope panel, with search engines and site search grouped](modemenu "The search scope panel")

## Add a custom search {#custom}

You can add your company intranet, documentation sites you use often and other sites as custom searches in Lumno's settings, each with a shortcut that's easy to remember.

You can also combine 2 to 10 sources into an aggregate search: type your search once, and the results open in several tabs at the same time, grouped into one tab group.
