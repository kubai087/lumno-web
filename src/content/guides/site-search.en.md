Searching GitHub used to mean opening GitHub, then clicking its search box. In Lumno you skip the home page: type a shortcut, press `Tab`, type what you're looking for, and press Return to land on the results. Asking AI works the same way.

## How it works {#how}

1. Press `⌘ ⇧ K` (`Ctrl + Shift + K` on Windows) on any page.
2. Type a site shortcut, such as `gh`.
3. Press `Tab`. GitHub appears at the left of the box.
4. Type your search and press Return.

![The search box shows GitHub on the left; typing command palette offers to search GitHub for command palette](sitesearch "gh, then Tab, searches GitHub directly")

To go back to a normal search, press `Esc`.

## Ask AI directly {#ai}

Type the AI's shortcut, press `Tab`, write your question and press Return. Lumno opens that AI's web app and sends the question for you.

| AI | Shortcut |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![The search box shows ChatGPT on the left with a question about alternatives to Arc's command bar, ready to open ChatGPT](ai "gpt, then Tab, sends your question to ChatGPT")

## Can't remember a shortcut? Pick from the panel {#scope-panel}

Press `Tab` twice in an empty box to open the search scope panel. Search engines, sites and AI are grouped there. Use the arrow keys, or type to filter.

![The search scope panel, with search engines and site search grouped](modemenu "The search scope panel")

## Add your own sites {#custom}

Your company intranet or the docs you check every day can become a custom search in Lumno's settings, with a shortcut of your choice.

You can also combine 2 to 10 sources into an aggregate search: type once, and the results open in several tabs at the same time, grouped into one tab group.
