これまでは GitHub で検索するときに、まず GitHub を開いてから検索ボックスを使う必要がありました。Lumno ではトップページを開かずに検索できます。サイトの略称を入力して `Tab` を押し、キーワードを入力して Enter キーを押すと、検索結果が直接開きます。AI への質問も同じ手順で行えます。

## サイト内検索の使い方 {#how}

1. どのページでも `⌘ ⇧ K` を押します。
2. サイトの略称（例：`gh`）を入力します。
3. `Tab` を押すと、検索ボックスの左側に GitHub と表示されます。
4. キーワードを入力して、Enter キーを押します。

![検索ボックスの左に GitHub が表示され、command palette と入力すると「GitHub で command palette を検索」が表示される](sitesearch "gh を入力して Tab を押すと、GitHub を直接検索できる")

通常の検索に戻るには、`Esc` キーを押します。

## サイトの略称 {#shortcuts}

Lumno には 47 の検索ショートカットが組み込まれています。その一部を次の表に示します。略称を覚えていない場合は、`github` や `youtube` のようにサイト名を入力しても検索できます。

| サイト | 略称 |
| --- | --- |
| GitHub | `gh` |
| YouTube | `yt` |
| Stack Overflow | `sf` |
| MDN | `mdn` |
| npm | `npm` |
| Hugging Face | `hf` |
| Reddit | `rd` |
| X | `tw` |
| Wikipedia | `wk` |
| Google Scholar | `gs` |
| Google マップ | `maps` |

## AI に質問する {#ai}

AI の略称を入力して `Tab` を押し、質問を入力して Enter キーを押します。Lumno がその AI のウェブ版を開き、質問を送信します。

| AI | 略称 |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![検索ボックスの左に ChatGPT が表示され、Arc のコマンドバーの代わりについての質問を ChatGPT で開ける状態](ai "gpt を入力して Tab を押すと、質問を ChatGPT に直接送信できる")

## ヘルプセンターに質問する {#help-center}

機能の使い方がわからないときは、検索ボックスから質問できます。`lm` と入力して `Tab` を押し、「ショートカットを変更したい」のように質問を入力すると、関連するヘルプページが最大 6 件、一致した段落とともに表示されます。選んで Enter キーを押すと、そのページの該当する位置が開きます。いちばん上の行を選ぶと、ヘルプセンターのサイトで検索します。

質問はブラウザ内で照合され、Lumno がダウンロードするのはヘルプページの索引だけです。

## 検索範囲パネルから選ぶ {#scope-panel}

検索ボックスが空のときに `Tab` を 2 回押すと、検索範囲パネルが開きます。検索エンジン、サイト内検索、AI がカテゴリごとに並んでいます。矢印キーで選択するか、キーワードを入力して絞り込めます。

![検索範囲パネル。検索エンジンとサイト内検索がカテゴリごとに並ぶ](modemenu "検索範囲パネル")

## カスタム検索を追加する {#custom}

社内ポータルやよく使うドキュメントサイトなども、Lumno の設定でカスタム検索として追加し、覚えやすい略称を設定できます。

2〜10 個の検索先をまとめた「まとめ検索」も作成できます。キーワードを 1 回入力するだけで、複数のタブに検索結果が同時に開き、それらのタブは 1 つのタブグループにまとめられます。
