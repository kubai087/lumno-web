GitHub で何かを探すとき、これまではまず GitHub を開いて、検索ボックスをクリックしていました。Lumno ならトップページは飛ばせます。略称を入力して `Tab`、探したい言葉を入れて Enter を押せば、検索結果が直接開きます。AI への質問も同じです。

## 使い方 {#how}

1. どのページでも `⌘ ⇧ K`（Windows では `Ctrl + Shift + K`）を押します。
2. サイトの略称、たとえば `gh` を入力します。
3. `Tab` を押すと、検索ボックスの左に GitHub が表示されます。
4. キーワードを入力して Enter。

![検索ボックスの左に GitHub が表示され、command palette と入力すると「GitHub で command palette を検索」が表示される](sitesearch "gh のあとに Tab で、GitHub を直接検索")

通常の検索に戻るときは `Esc` を押します。

## サイトの略称 {#shortcuts}

Lumno には 46 の検索ショートカットが入っています。その一部を紹介します。略称を覚えていなくても、`github` や `youtube` のようにサイト名で入力できます。

| サイト | 略称 |
| --- | --- |
| GitHub | `gh` |
| YouTube | `yt` |
| Stack Overflow | `sf` |
| MDN | `mdn` |
| npm | `npm` |
| Hugging Face | `hf` |
| Reddit | `rd` |
| X | `tw` |
| Wikipedia | `wk` |
| Google Scholar | `gs` |
| Google マップ | `maps` |

## AI にそのまま質問 {#ai}

AI の略称を入力して `Tab`、質問を書いて Enter。Lumno がその AI のウェブ版を開いて、質問を送ってくれます。

| AI | 略称 |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![検索ボックスの左に ChatGPT が表示され、Arc のコマンドバーの代わりについての質問を ChatGPT で開ける状態](ai "gpt のあとに Tab で、質問を ChatGPT へ")

## 略称を忘れたら、パネルから選ぶ {#scope-panel}

空の検索ボックスで `Tab` を 2 回押すと、検索範囲パネルが開きます。検索エンジン、サイト内検索、AI がまとめて並んでいるので、矢印キーで選ぶか、入力して絞り込めます。

![検索範囲パネル。検索エンジンとサイト内検索がカテゴリごとに並ぶ](modemenu "検索範囲パネル")

## 自分のサイトを追加する {#custom}

社内ポータルや毎日見るドキュメントも、Lumno の設定でカスタム検索として追加し、好きな略称を付けられます。

2 〜 10 個の検索先をまとめた「まとめ検索」も作れます。一度入力するだけで、複数のタブに結果が同時に開き、ひとつのタブグループにまとまります。
