예전에는 GitHub를 검색하려면 GitHub를 열고 다시 검색창을 눌러야 했죠. Lumno에서는 홈페이지를 건너뛰어요. 단축어를 입력하고 `Tab`을 누른 뒤 찾는 내용을 쓰고 Return을 누르면 바로 검색 결과로 갑니다. AI에게 묻는 것도 같은 방식이에요.

## 사용 방법 {#how}

1. 어떤 페이지에서든 `⌘ ⇧ K`(Windows는 `Ctrl + Shift + K`)를 누르세요.
2. `gh` 같은 사이트 단축어를 입력하세요.
3. `Tab`을 누르면 검색창 왼쪽에 GitHub가 나타나요.
4. 검색어를 입력하고 Return을 누르세요.

![검색창 왼쪽에 GitHub가 표시되고, command palette를 입력하자 GitHub에서 command palette를 검색하는 항목이 나타난다](sitesearch "gh 다음 Tab으로 GitHub 바로 검색")

일반 검색으로 돌아가려면 `Esc`를 누르세요.

## 사이트 단축어 {#shortcuts}

Lumno에는 검색 단축어 46개가 들어 있어요. 그중 일부를 소개합니다. 단축어가 기억나지 않으면 `github`, `youtube`처럼 사이트 이름을 입력해도 돼요.

| 사이트 | 단축어 |
| --- | --- |
| GitHub | `gh` |
| YouTube | `yt` |
| Stack Overflow | `sf` |
| MDN | `mdn` |

| Reddit | `rd` |
| X | `tw` |
| Wikipedia | `wk` |

| Google Maps | `maps` |

## AI에게 바로 묻기 {#ai}

AI의 단축어를 입력하고 `Tab`을 누른 뒤 질문을 쓰고 Return을 누르세요. Lumno가 해당 AI의 웹 앱을 열고 질문을 대신 보내 줘요.

| AI | 단축어 |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![검색창 왼쪽에 ChatGPT가 표시되고, Arc 명령 바 대안을 묻는 질문이 입력되어 ChatGPT를 열 준비가 되어 있다](ai "gpt 다음 Tab으로 ChatGPT에 질문 보내기")

## 단축어가 기억나지 않으면 패널에서 고르기 {#scope-panel}

빈 검색창에서 `Tab`을 두 번 누르면 검색 범위 패널이 열려요. 검색 엔진, 사이트, AI가 묶여 있고, 방향키로 고르거나 입력해서 걸러 낼 수 있어요.

![검색 엔진과 사이트 검색이 묶여 있는 검색 범위 패널](modemenu "검색 범위 패널")

## 내 사이트 추가하기 {#custom}

회사 인트라넷이나 매일 보는 문서도 Lumno 설정에서 원하는 단축어를 붙인 맞춤 검색으로 만들 수 있어요.

검색 소스 2~10개를 묶어 통합 검색을 만들 수도 있어요. 한 번 입력하면 여러 탭에서 결과가 동시에 열리고, 하나의 탭 그룹으로 묶입니다.
