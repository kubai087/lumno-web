지금까지는 GitHub에서 검색하려면 먼저 GitHub를 열고 검색창을 사용해야 했습니다. Lumno에서는 홈페이지를 거치지 않고 검색할 수 있습니다. 사이트 단축어를 입력하고 `Tab`을 누른 다음, 검색어를 입력하고 `↩` 키를 누르면 검색 결과가 바로 열립니다. AI에게 질문할 때도 방법은 같습니다.

## 사이트 검색 사용 방법 {#how}

1. 어떤 페이지에서든 `⌘ ⇧ K`를 누르세요.
2. `gh` 같은 사이트 단축어를 입력하세요.
3. `Tab`을 누르면 검색창 왼쪽에 GitHub가 표시됩니다.
4. 검색어를 입력하고 `↩` 키를 누르세요.

![검색창 왼쪽에 GitHub가 표시되고, command palette를 입력하자 GitHub에서 command palette를 검색하는 항목이 나타난다](sitesearch "gh를 입력하고 Tab을 누르면 GitHub에서 바로 검색")

일반 검색으로 돌아가려면 `Esc`를 누르세요.

## AI에게 질문하기 {#ai}

AI의 단축어를 입력하고 `Tab`을 누른 다음, 질문을 입력하고 `↩` 키를 누르세요. Lumno가 해당 AI의 웹 앱을 열고 질문을 대신 보냅니다.

| AI | 단축어 |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![검색창 왼쪽에 ChatGPT가 표시되고, Arc 명령 바 대안을 묻는 질문이 입력되어 ChatGPT를 열 준비가 되어 있다](ai "gpt를 입력하고 Tab을 누르면 ChatGPT에 바로 질문")

## 도움말 센터에 질문하기 {#help-center}

기능 사용법이 궁금하다면 검색창에서 바로 질문할 수 있습니다. `lm` 또는 `lumno`를 입력하고 `Tab`을 누른 다음 질문을 입력하세요. 관련 도움말 페이지가 최대 6개까지, 일치한 문단과 함께 표시됩니다. 하나를 선택하고 `↩` 키를 누르면 해당 페이지의 그 위치가 열립니다. 맨 위 줄을 선택하면 도움말 센터 사이트에서 검색합니다.

Lumno가 영어로 표시되는 경우 영어 도움말에서 찾으므로, "change a shortcut"처럼 영어로 질문하세요. 질문은 브라우저 안에서만 비교되며, Lumno는 도움말 페이지 색인만 내려받습니다.

## 검색 범위 패널에서 선택하기 {#scope-panel}

검색창이 비어 있을 때 `Tab`을 두 번 누르면 검색 범위 패널이 열립니다. 검색 엔진, 사이트 검색, AI가 분류별로 정리되어 있으며, 방향키로 선택하거나 입력해서 목록을 좁힐 수 있습니다.

![검색 엔진과 사이트 검색이 묶여 있는 검색 범위 패널](modemenu "검색 범위 패널")

## 검색 소스 순서 바꾸기 {#order}

자주 쓰는 검색 소스를 앞쪽에 둘 수 있습니다.

- 검색 범위 패널에서 아이콘을 끌면 같은 카테고리 안에서 순서를 바꿀 수 있습니다. 카테고리 제목에 마우스를 올리고 나타나는 위로 이동 또는 아래로 이동 버튼을 클릭하면 카테고리 전체를 옮길 수 있습니다.
- Lumno 설정의 Search sources에서 위쪽의 태그를 끌면 패널 안 카테고리의 순서를, 아래 목록의 항목을 끌면 카테고리 안의 순서를 바꿀 수 있습니다. Visible Result Types의 항목도 끌어서 열린 탭, 북마크, 방문 기록 등 결과의 순서를 바꿀 수 있습니다.

잘못 옮겼다면 `⌘ Z`로 실행 취소하고 `⌘ ⇧ Z`로 다시 실행하세요. 순서는 브라우저 동기화로 동기화됩니다.

## 맞춤 검색 추가하기 {#custom}

회사 인트라넷이나 자주 보는 문서 사이트도 Lumno 설정에서 맞춤 검색으로 추가하고, 기억하기 쉬운 단축어를 지정할 수 있습니다.

검색 소스 2~10개를 묶어 통합 검색을 만들 수도 있습니다. 검색어를 한 번 입력하면 여러 탭에서 검색 결과가 동시에 열리며, 이 탭들은 하나의 탭 그룹으로 묶입니다.
