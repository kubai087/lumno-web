以前想在 GitHub 中搜索仓库，需要先打开 GitHub，再使用它的搜索框。在 Lumno 中可以跳过首页：输入网站简称，按 `Tab`，再输入关键词，按回车键即可直接打开搜索结果。向 AI 提问也是同样的操作。

## 使用方法 {#how}

1. 在任意网页按下 `⌘ ⇧ K`（Windows 上为 `Ctrl + Shift + K`）。
2. 输入网站简称，例如 `gh`。
3. 按 `Tab`，搜索框左侧会显示 GitHub。
4. 输入关键词，按回车键。

![搜索框左侧显示 GitHub，输入 command palette 后，结果为“在 GitHub 中搜索 command palette”](sitesearch "输入 gh 并按 Tab，直接在 GitHub 中搜索")

按 `Esc` 即可退出站内搜索，回到普通搜索。

## 在搜索范围面板中选择 {#scope-panel}

在搜索框为空时连按两次 `Tab`，即可打开搜索范围面板。搜索引擎、站内搜索和 AI 按类别排列，可以用方向键选择，也可以输入拼音或英文进行筛选。

![搜索范围面板，按类别列出搜索引擎和站内搜索](modemenu "搜索范围面板")

## 添加自定义搜索 {#custom}

公司内网、常用的文档站等，也可以在 Lumno 设置中添加为自定义搜索，并设置一个便于记忆的简称。

你还可以把 2 到 10 个搜索源组合成一组「聚合搜索」：输入一次关键词，即可在多个标签页中同时打开搜索结果，这些标签页会自动归入同一个标签页组。
