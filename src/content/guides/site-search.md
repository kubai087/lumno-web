想在 GitHub 里搜个仓库，以前要先打开 GitHub，再点它的搜索框。在 Lumno 里，跳过首页就好：输入简称，按 `Tab`，再输关键词，回车直接看到搜索结果。问 AI 也是一样。

## 怎么用 {#how}

1. 在任意网页按下 `⌘ ⇧ K`（Windows 上是 `Ctrl + Shift + K`）。
2. 输入网站简称，比如 `gh`。
3. 按 `Tab`，搜索框左边会出现 GitHub。
4. 输入关键词，回车。

![搜索框左侧显示 GitHub，输入 command palette 后，结果为“在 GitHub 中搜索 command palette”](sitesearch "gh 加 Tab，直接在 GitHub 里搜")

想回到普通搜索，按 `Esc` 退出就好。

## 记不住简称？打开面板挑 {#scope-panel}

搜索框为空时连按两下 `Tab`，打开搜索范围面板。搜索引擎、站内搜索和 AI 都按类排好，用方向键选，或者直接输入拼音、英文筛选。

![搜索范围面板，按类别列出搜索引擎和站内搜索](modemenu "搜索范围面板")

## 加上你自己的网站 {#custom}

公司内网、常用的文档站，也能在 Lumno 设置里加成自定义搜索，配一个顺手的简称。

还可以把 2 到 10 个搜索源合成一组「聚合搜索」：输入一次关键词，在多个标签页里同时打开结果，还会自动归进同一个标签页组。
