Раньше, чтобы выполнить поиск на GitHub, нужно было сначала открыть GitHub, а затем воспользоваться его строкой поиска. В Lumno главную страницу можно пропустить: введите сокращение сайта, нажмите `Tab`, введите запрос и нажмите Enter, чтобы сразу перейти к результатам. Вопросы к ИИ задаются так же.

## Как пользоваться поиском по сайтам {#how}

1. Нажмите `⌘ ⇧ K` на любой странице.
2. Введите сокращение сайта, например `gh`.
3. Нажмите `Tab`. Слева в строке появится GitHub.
4. Введите запрос и нажмите Enter.

![Слева в строке — GitHub; по запросу command palette предлагается поиск command palette на GitHub](sitesearch "Введите gh и нажмите Tab, чтобы искать прямо на GitHub")

Чтобы вернуться к обычному поиску, нажмите `Esc`.

## Вопросы к ИИ {#ai}

Введите сокращение ИИ, нажмите `Tab`, напишите вопрос и нажмите Enter. Lumno откроет веб-приложение этого ИИ и отправит вопрос за вас.

| ИИ | Сокращение |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

## Выбор на панели областей поиска {#scope-panel}

Когда строка пуста, дважды нажмите `Tab`, чтобы открыть панель областей поиска. Поисковые системы, поиск по сайтам и ИИ сгруппированы по категориям. Выберите нужный вариант клавишами со стрелками или введите текст, чтобы отфильтровать список.

![Панель областей поиска с поисковыми системами и поиском по сайтам, разбитыми на группы](modemenu "Панель областей поиска")

## Добавление собственного поиска {#custom}

Внутренний портал компании или часто используемые сайты документации можно добавить в настройках Lumno как собственный поиск и назначить им удобное сокращение.

Можно также объединить от 2 до 10 источников в общий поиск: запрос вводится один раз, а результаты открываются одновременно в нескольких вкладках, объединённых в одну группу.
