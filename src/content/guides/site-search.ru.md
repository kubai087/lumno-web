Раньше, чтобы поискать на GitHub, нужно было открыть GitHub и щёлкнуть по его строке поиска. В Lumno главная страница не нужна: введите сокращение, нажмите `Tab`, наберите запрос и нажмите Enter — и вы сразу в результатах. С вопросами к ИИ всё так же.

## Как это работает {#how}

1. Нажмите `⌘ ⇧ K` (`Ctrl + Shift + K` в Windows) на любой странице.
2. Введите сокращение сайта, например `gh`.
3. Нажмите `Tab`. Слева в строке появится GitHub.
4. Введите запрос и нажмите Enter.

![Слева в строке — GitHub; по запросу command palette предлагается поиск command palette на GitHub](sitesearch "gh, затем Tab — поиск прямо по GitHub")

Чтобы вернуться к обычному поиску, нажмите `Esc`.

## Спросить ИИ напрямую {#ai}

Введите сокращение ИИ, нажмите `Tab`, напишите вопрос и нажмите Enter. Lumno откроет веб-приложение этого ИИ и отправит вопрос за вас.

| ИИ | Сокращение |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![Слева в строке — ChatGPT, введён вопрос об альтернативах командной строке Arc, всё готово, чтобы открыть ChatGPT](ai "gpt, затем Tab — вопрос уходит в ChatGPT")

## Забыли сокращение? Выберите на панели {#scope-panel}

Дважды нажмите `Tab` в пустой строке, чтобы открыть панель областей поиска. Там сгруппированы поисковые системы, сайты и ИИ. Выбирайте стрелками или вводите текст для фильтрации.

![Панель областей поиска с поисковыми системами и поиском по сайтам, разбитыми на группы](modemenu "Панель областей поиска")

## Добавьте свои сайты {#custom}

Внутренний портал компании или документацию, которую вы открываете каждый день, можно превратить в собственный поиск в настройках Lumno — с любым сокращением.

Можно также объединить от 2 до 10 источников в общий поиск: вводите запрос один раз, и результаты открываются сразу в нескольких вкладках, собранных в одну группу.
