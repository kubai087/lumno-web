以前想在 GitHub 中搜尋專案，需要先開啟 GitHub，再使用它的搜尋框。在 Lumno 中可以跳過首頁：輸入網站簡稱，按 `Tab`，再輸入關鍵字，按下 Enter 即可直接開啟搜尋結果。向 AI 提問也是同樣的操作。

## 使用方式 {#how}

1. 在任何網頁按下 `⌘ ⇧ K`。
2. 輸入網站簡稱，例如 `gh`。
3. 按 `Tab`，搜尋框左側會顯示 GitHub。
4. 輸入關鍵字，按下 Enter。

![搜尋框左側顯示 GitHub，輸入 command palette 後，結果為「在 GitHub 中搜尋 command palette」](sitesearch "輸入 gh 並按 Tab，直接在 GitHub 中搜尋")

按 `Esc` 即可離開站內搜尋，回到一般搜尋。

## 向 AI 提問 {#ai}

輸入 AI 的簡稱，按 `Tab`，寫下問題後按下 Enter。Lumno 會開啟對應 AI 的網頁版，並替你送出問題。

| AI | 簡稱 |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

## 在搜尋範圍面板中選擇 {#scope-panel}

在搜尋框為空時連按兩下 `Tab`，即可開啟搜尋範圍面板。搜尋引擎、站內搜尋和 AI 依類別排列，可以用方向鍵選擇，也可以輸入英文進行篩選。

![搜尋範圍面板，依類別列出搜尋引擎和站內搜尋](modemenu "搜尋範圍面板")

## 新增自訂搜尋 {#custom}

公司內網、常用的文件站等，也可以在 Lumno 設定中新增為自訂搜尋，並設定一個容易記住的簡稱。

你還可以把 2 到 10 個搜尋來源組合成一組「聚合搜尋」：輸入一次關鍵字，即可在多個分頁中同時開啟搜尋結果，這些分頁會自動歸入同一個分頁群組。
