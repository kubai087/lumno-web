想在 GitHub 裡找個專案，以前要先開 GitHub，再點它的搜尋框。在 Lumno 裡，跳過首頁就好：輸入簡稱，按 `Tab`，再打關鍵字，按 Enter 直接看到搜尋結果。問 AI 也一樣。

## 怎麼用 {#how}

1. 在任何網頁按下 `⌘ ⇧ K`（Windows 上是 `Ctrl + Shift + K`）。
2. 輸入網站簡稱，例如 `gh`。
3. 按 `Tab`，搜尋框左邊會出現 GitHub。
4. 輸入關鍵字，按 Enter。

![搜尋框左側顯示 GitHub，輸入 command palette 後，結果為「在 GitHub 中搜尋 command palette」](sitesearch "gh 加 Tab，直接在 GitHub 裡搜")

想回到一般搜尋，按 `Esc` 離開就好。

## 有問題，直接問 AI {#ai}

輸入 AI 的簡稱，按 `Tab`，寫下問題，按 Enter。Lumno 會開啟對應 AI 的網頁版，幫你把問題送出去。

| AI | 簡稱 |
| --- | --- |
| ChatGPT | `gpt` |
| Gemini | `gm` |
| Perplexity | `pplx` |
| DeepSeek | `ds` |
| Kimi | `kimi` |

![搜尋框左側顯示 ChatGPT，問題為「Arc 瀏覽器的命令列有哪些替代方案？」，右側可開啟 ChatGPT 網頁版](ai "gpt 加 Tab，把問題直接丟給 ChatGPT")

## 記不住簡稱？打開面板挑 {#scope-panel}

搜尋框為空時連按兩下 `Tab`，開啟搜尋範圍面板。搜尋引擎、站內搜尋和 AI 都分類排好，用方向鍵選，或直接輸入英文篩選。

![搜尋範圍面板，依類別列出搜尋引擎和站內搜尋](modemenu "搜尋範圍面板")

## 加入你自己的網站 {#custom}

公司內網、常用的文件站，也能在 Lumno 設定裡加成自訂搜尋，配一個順手的簡稱。

還可以把 2 到 10 個搜尋來源合成一組「聚合搜尋」：輸入一次關鍵字，就在多個分頁裡同時開啟結果，還會自動歸進同一個分頁群組。
