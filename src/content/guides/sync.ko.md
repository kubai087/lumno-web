여러 대의 컴퓨터나 브라우저를 사용하는 경우에도 바로가기, 배경화면, 설정을 동기화할 수 있습니다. Lumno에는 자체 서버가 없으므로, 이미 사용 중인 두 가지 방법으로 동기화합니다. 바로 브라우저 동기화와 직접 준비한 WebDAV 서버입니다.

## 브라우저 동기화: 별도 설정 불필요 {#browser-sync}

브라우저에 로그인하고 동기화를 켜 두었다면 Lumno 설정이 자동으로 동기화됩니다. 동기화되는 항목은 테마, 검색 엔진, 바로가기, 고정한 사이트 카드, 차단 목록, 배경화면 선택, 이미지 링크입니다.

직접 올린 아이콘과 로컬 배경화면은 용량이 커서 브라우저 동기화로 동기화할 수 없습니다. 이 항목까지 동기화하려면 WebDAV를 사용하세요.

## WebDAV 동기화: 아이콘과 배경화면까지 동기화 {#webdav}

WebDAV 동기화는 베타 기능이며 기본적으로 꺼져 있습니다. 켜면 전체 설정, 직접 올린 바로가기 아이콘, 맞춤 배경화면이 지정한 서버에 저장됩니다.

1. Lumno 설정을 열고 Account & sync → WebDAV로 이동하세요.
2. "Add WebDAV"를 클릭하고 서버 주소, 동기화 폴더, 사용자 이름, 앱 비밀번호를 입력하세요.
3. 필요하면 "Test connectivity"를 클릭한 다음 "Save and turn on sync"를 클릭하세요.

연결은 기기마다 따로 추가해야 합니다. 사용자 이름과 비밀번호는 해당 컴퓨터에만 저장되며, 브라우저 동기화로 동기화되지 않습니다.

## 서버 선택하기 {#hosts}

Lumno는 직접 운영하는 Nextcloud와 Apache, nginx, rclone, WsgiDAV WebDAV 서버, 그리고 Nutstore(坚果云)에서 테스트되었습니다. 표준 WebDAV를 지원하는 호스팅 서비스나 Synology 같은 NAS도 사용할 수 있을 것으로 보이지만, 아직 검증하지는 않았습니다.

서비스에서 앱 비밀번호를 지원한다면 기본 계정 비밀번호 대신 Lumno 전용 앱 비밀번호를 만들어 사용하세요.

## 다른 컴퓨터 설정하기 {#second-device}

같은 서버, 폴더, 계정으로 연결을 추가하세요. 서버에 이미 데이터가 있으면 어느 버전을 사용할지 묻는 메시지가 표시되며, 일반적으로 "Use server version"을 선택하면 됩니다. 데이터를 바꾸기 전에 Lumno가 해당 컴퓨터의 설정을 모두 백업합니다.

이후에는 두 컴퓨터의 변경 사항이 자동으로 병합됩니다. 두 컴퓨터에서 바로가기처럼 같은 항목을 변경하면 카드에 충돌이 표시됩니다. "Show differences"를 클릭해 양쪽의 변경 내용을 확인한 다음, 유지할 버전을 선택하세요.

## 동기화되지 않는 항목 {#not-synced}

- 방문 기록, 북마크, 열린 탭: 지금처럼 브라우저가 동기화합니다.
- WebDAV 사용자 이름과 비밀번호: 기기마다 따로 저장됩니다.

WebDAV를 끄거나 연결을 삭제해도 서버의 파일은 그대로 남습니다. 필요하면 서버에서 직접 삭제하세요. WebDAV 동기화는 종단 간 암호화를 지원하지 않으므로 서버 관리자가 파일을 볼 수 있습니다.

## 내보내기와 가져오기 {#export}

동기화를 사용하지 않으려면 Lumno 설정에서 구성을 파일로 내보낸 다음 다른 컴퓨터에서 가져올 수 있습니다. 내보낸 파일에는 설정만 포함되며 이미지는 포함되지 않습니다.
