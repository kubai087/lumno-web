Lumno를 자주 사용하는 방식을 단계별 사용 방법과 함께 소개합니다. 자신의 사용 방식에 맞는 항목을 찾아보세요.

## 탭을 수십 개 열어 두었을 때 {#many-tabs}

탭이 많아지면 제목이 짧게 줄어들어 원하는 탭을 찾기 어렵습니다. 이럴 때는 열린 탭만 검색하세요.

1. `⌘ ⇧ K`를 눌러 명령 바를 여세요.
2. 검색창이 비어 있을 때 `Tab`을 한 번 누르면 왼쪽에 "Search open tabs"가 표시됩니다.
3. 페이지 제목의 일부(예: "layout")를 입력하고, 원하는 페이지를 선택한 다음 Return 키를 누르면 해당 탭으로 전환됩니다.

![명령 바가 "Search open tabs" 상태이며, layout을 입력하자 제목에 layout이 들어간 MDN 탭 네 개가 표시되고 각각 오른쪽에 Switch가 있다](uc-tabs "열린 탭만 검색")

일반 검색에서도 열린 탭은 "Opened" 표시와 함께 결과에 나타나며, Return 키를 누르면 같은 페이지를 새로 여는 대신 해당 탭으로 전환합니다. 최근 두세 개의 페이지 사이만 오간다면 `⌥ Q`를 사용하는 것이 더 빠릅니다.

탭이 너무 많아 컴퓨터가 느려진다면 Chrome의 메모리 절약 모드를 함께 사용하거나, [OneTab](https://www.one-tab.com/)으로 탭을 목록 하나에 모아 둘 수 있습니다.

자세한 내용은 [탭, 북마크, 방문 기록 검색](../search-tabs-bookmarks-history/)과 [최근 탭 사이 전환](../tab-switcher/)을 참고하세요.

## Arc에서 옮겨 왔을 때 {#from-arc}

Arc에 새 기능이 더 이상 추가되지 않으면서 많은 사용자가 Dia, Chrome, Edge로 옮겼고, 이때 가장 아쉬워하는 기능은 대개 명령 바입니다. Lumno를 설치한 다음 아래 단계를 따르면 익숙한 사용 방식을 되찾을 수 있습니다.

1. 주소창에서 `chrome://extensions/shortcuts`를 여세요.
2. Lumno를 찾아 "Open command bar"를 `⌘ T`로 변경하세요.
3. 이제 `⌘ T`로 명령 바를 열고, `⌥ Q`로 최근 탭 사이를 전환하세요. `⌥ Q`는 Arc의 `⌃ Tab`에 해당합니다.

![브라우저의 확장 프로그램 단축키 페이지. Lumno의 "Open command bar"는 ⇧⌘K, "Open recent tab switcher"는 ⌥Q로 설정되어 있다](shortcuts "확장 프로그램 페이지에서 Lumno 단축키 변경하기")

자세한 내용은 [Arc에서 옮겨 왔다면](../arc-command-bar/)을 참고하세요.

## 문서와 GitHub를 자주 찾아볼 때 {#developers}

사이트 단축어를 입력하고 `Tab`을 누르면 홈페이지를 거치지 않고 사이트 안을 바로 검색할 수 있습니다. 예를 들어 `gh`를 입력하고 `Tab`을 누른 다음, `command palette`를 입력하고 Return 키를 누르면 GitHub 검색 결과가 열립니다. 자주 사용하는 단축어로는 `mdn`, `npm`, `sf`(Stack Overflow) 등이 있습니다.

![검색창 왼쪽에 GitHub가 표시되고, command palette를 입력하자 GitHub에서 command palette를 검색하는 항목이 나타난다](sitesearch "gh를 입력하고 Tab을 누르면 GitHub에서 바로 검색")

- `chrome://extensions` 같은 브라우저 주소도 입력해서 바로 열 수 있습니다.
- 회사 내부 문서 사이트나 이슈 트래커는 Lumno 설정에서 맞춤 검색으로 추가하고 원하는 단축어를 지정할 수 있습니다. 자세한 내용은 [맞춤 검색 추가하기](../site-search/#custom)를 참고하세요.

## 자료 조사와 글쓰기 중에 자료를 찾을 때 {#research}

어떤 글을 읽은 기억은 있지만, 북마크에 저장했는지 방문만 했는지 기억나지 않을 때가 있습니다. 명령 바에 검색어를 입력하면 북마크와 방문 기록을 함께 검색합니다. 각 결과 옆에는 출처가 표시되며, 북마크에는 저장된 폴더도 함께 표시됩니다.

![css grid를 입력하자 북마크 폴더 CSS reading에 있는 MDN 페이지와 방문 기록에 있는 CSS Grid 가이드가 함께 표시된다](uc-research "북마크와 방문 기록 함께 검색")

이해하기 어려운 문단은 텍스트 선택 빠른 작업(Selection quick actions)으로 처리할 수 있습니다. 텍스트를 선택하면 옆에 Lumno 버튼이 나타나며, 버튼을 클릭해 Answer, Explain, Research 등의 작업을 선택하면 Lumno가 새 탭에서 AI의 답변을 엽니다. 이 기능은 기본적으로 꺼져 있으며, Lumno 설정의 Labs에서 켤 수 있습니다.

![글에서 fr 단위에 관한 문장을 선택하자 옆에 Answer, Explain, Research 작업이 표시된다](uc-selection "텍스트를 선택해 AI에게 설명이나 조사 요청하기")

## AI에게 먼저 질문할 때 {#ai}

`gpt`(ChatGPT), `gm`(Gemini), `pplx`(Perplexity) 같은 AI 단축어를 입력하고 `Tab`을 누른 다음, 질문을 입력하고 Return 키를 누르세요. Lumno가 해당 AI의 웹 앱을 열고 질문을 대신 보내므로, 사이트를 열어 질문을 붙여 넣을 필요가 없습니다.

![검색창 왼쪽에 ChatGPT가 표시되고, Arc 명령 바 대안을 묻는 질문이 입력되어 ChatGPT를 열 준비가 되어 있다](ai "gpt를 입력하고 Tab을 누르면 ChatGPT에 바로 질문")

자세한 내용은 [사이트 검색과 AI에게 질문하기](../site-search/#ai)를 참고하세요.

## 깔끔한 새 탭을 원할 때 {#quiet-new-tab}

Lumno 새 탭에는 필요한 것만 표시할 수 있습니다.

- 배경화면: 좋아하는 명화를 선택하거나, Bing 사진을 매일 자동으로 표시합니다.
- 시계: 검색창 위에 시간을 표시합니다.
- Zen 모드: 집중해야 할 때 새 탭 검색창에 `/zen`을 입력하면 검색창과 배경화면만 남습니다.

![검색창 위에 09:41 시계가 있고 아래에 바로가기가 있는 새 탭](nt-clock "검색창 위에 표시된 시계")

자세한 내용은 [배경화면 바꾸기](../newtab-wallpaper/)와 [시계와 Zen 모드](../newtab-clock-zen/)를 참고하세요.

## 드라마나 연재물을 챙겨 볼 때 {#series}

드라마나 연재 소설을 볼 때 Lumno가 새 탭에서 몇 화, 몇 장까지 봤는지 기록할 수 있습니다.

1. 보고 있는 화나 장의 페이지를 여세요. 이 페이지는 새 탭 아래쪽의 사이트 카드에 표시됩니다. 보이지 않으면 카드 영역 오른쪽 위의 "···"를 클릭하고 "Show Recent"를 선택하세요.
2. 카드에 마우스 포인터를 올리고 핀 아이콘을 클릭해 고정하세요. Lumno가 회차나 장 페이지로 인식하면 진행 상황 기록을 자동으로 시작하며, 카드에 레이더 아이콘이 표시됩니다. 기록이 시작되지 않으면 카드를 마우스 오른쪽 버튼으로 클릭하고 "Track progress"를 선택하세요.
3. 같은 작품의 다음 화나 다음 장으로 넘어가면 카드가 자동으로 업데이트됩니다. 다음에는 카드를 클릭해 이어서 보세요.

![새 탭 아래쪽의 사이트 카드: 고정된 Crunchyroll과 Wandering Inn 카드에 레이더 아이콘이 있고, 그 옆에 GitHub와 Material 카드가 있다](uc-series "레이더 아이콘이 있는 카드는 진행 상황을 기록 중")

자세한 내용은 [자주 가는 사이트와 진행 카드](../newtab-frequent-sites/)를 참고하세요.
