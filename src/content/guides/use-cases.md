以下是 Lumno 的几种常见使用场景，每一种都附有操作步骤，你可以从中找到适合自己的用法。

## 同时打开了几十个标签页 {#many-tabs}

标签页一多，标题会挤在一起，很难找到要去的那一页。这时可以只在已打开的标签页中搜索：

1. 按下 `⌘ ⇧ K` 唤出命令栏。
2. 在搜索框为空时按一次 `Tab`，左侧会显示「搜索已打开标签页」。
3. 输入标题中的几个字，例如「布局」，选中要去的页面，按回车键即可切换过去。

![命令栏处于“搜索已打开标签页”模式，输入“布局”后，列出四个标题含“布局”的 MDN 标签页，右侧均为“切换”](uc-tabs "只在已打开的标签页中搜索")

在普通搜索中，已打开的标签页也会出现在结果里，并标有「已打开」，按回车键同样会切换过去，不会再打开一个重复的页面。如果只是在最近的两三个页面之间来回切换，按 `⌥ Q` 更快。

如果标签页多到拖慢电脑，可以配合使用 Chrome 自带的「节省内存」功能，或者用 [OneTab](https://www.one-tab.com/) 将它们收纳到一个列表中。

详见[搜索标签页、书签和历史记录](../search-tabs-bookmarks-history/)、[切换最近的标签页](../tab-switcher/)。

## 从 Arc 迁移过来 {#from-arc}

[Arc](https://arc.net/) 停止开发新功能后，不少用户转向了 Dia、Chrome 或 Edge。Lumno 参考了 Arc 的命令栏、最近标签页切换、重启后恢复固定标签页和视频自动画中画。安装 Lumno 后，可以按以下步骤设置命令栏：

1. 在地址栏中打开 `chrome://extensions/shortcuts`。
2. 找到 Lumno，把「唤起聚焦搜索窗口」改为 `⌘ T`。
3. 之后按 `⌘ T` 唤出命令栏；按 `⌥ Q` 在最近的标签页之间切换，对应 Arc 的 `⌃ Tab`。

![浏览器的扩展快捷键页面，Lumno 的“唤起聚焦搜索窗口”为 ⇧⌘K，“打开最近标签页切换器”为 ⌥Q](shortcuts "在扩展快捷键页面中修改 Lumno 的快捷键")

详见[从 Arc 迁移](../arc-command-bar/)。

## 经常查阅文档和 GitHub {#developers}

输入网站简称并按 `Tab`，可以跳过网站首页，直接在站内搜索。例如输入 `gh`，按 `Tab`，再输入 `command palette` 并按回车键，即可打开 GitHub 中的搜索结果。常用的简称还有 `mdn`、`npm` 和 `sf`（Stack Overflow）。

![搜索框左侧显示 GitHub，输入 command palette 后，结果为“在 GitHub 中搜索 command palette”](sitesearch "输入 gh 并按 Tab，直接在 GitHub 中搜索")

- `chrome://extensions` 这类浏览器地址，输入后可以直接打开。
- 公司内部的文档站、工单系统，可以在 Lumno 设置中添加为自定义搜索，并设置自己的简称，详见[添加自定义搜索](../site-search/#custom)。

## 研究与写作时查找资料 {#research}

查找资料时，常常记得读过某篇文章，却想不起它是存在书签里，还是只留在历史记录中。在命令栏中输入关键词，书签和历史记录会一起搜索：结果右侧会标明来源，书签还会显示所在的文件夹。

![输入“网格布局”后，结果中同时有书签栏“CSS 资料”文件夹里的 MDN 页面和历史记录中的阮一峰网格布局教程](uc-research "书签和历史记录一起搜索")

阅读时遇到难以理解的段落，可以使用「划词快捷操作」：选中文字后，旁边会出现 Lumno 的按钮，点击后可以选择解释、调研、翻译等操作，Lumno 会在新标签页中把文字交给 AI 处理。Lumno 会先判断文字是否需要帮助，并不会每次划词都弹出。此功能默认关闭，需要先在 Lumno 设置的「实验室功能」中开启，详见[划词快捷操作](../selection-actions/)。

![在一篇文章中选中“它表示容器剩余空间中的一份”，旁边显示解释、调研、翻译等操作](uc-selection "选中文字后，让 AI 解释、调研或翻译")

## 习惯向 AI 提问 {#ai}

输入 AI 的简称并按 `Tab`，例如 `ds`（DeepSeek）、`gpt`（ChatGPT）、`kimi` 或 `dbai`（豆包），写下问题后按回车键。Lumno 会打开对应 AI 的网页版并替你发送问题，无需先打开网站再粘贴问题。

![搜索框左侧显示 DeepSeek，问题为“Arc 浏览器的命令栏有哪些替代方案？”，右侧操作为“打开 DeepSeek 网页版”](ai "输入 ds 并按 Tab，把问题直接发送给 DeepSeek")

详见[站内搜索和 AI 提问](../site-search/#ai)。

## 想要一个安静的新标签页 {#quiet-new-tab}

Lumno 的新标签页可以只显示你需要的内容：

- 壁纸：选择一幅喜欢的名画，或者每天自动更换 Bing 壁纸。
- 时钟和名句：在搜索框上方显示时钟，在下方显示一句诗词。
- Zen 模式：需要专注时，在新标签页的搜索框中输入 `/zen`，页面上只保留搜索框和壁纸。

![完整的新标签页：上方是时钟 09:41、搜索框和一句诗词，下面依次是一排快捷方式、八个书签和最常访问的网站，背景为印象派果园壁纸](nt-clock "时钟和每日名句")

详见[更换壁纸](../newtab-wallpaper/)、[时钟、名句和 Zen 模式](../newtab-clock-zen/)。

## 追剧和追更连载 {#series}

看剧集或连载小说时，Lumno 可以在新标签页上记住你看到了哪一集、哪一章：

1. 打开正在看的那一集或那一章。之后，它会出现在新标签页底部的网站卡片中；如果没有看到，可以点击卡片区域右上角的「···」，切换为「最近访问」。
2. 将鼠标移到这张卡片上，点击图钉图标置顶。Lumno 识别出这是剧集或章节页面后，会自动开始记录进度，卡片上会显示雷达图标。如果没有自动开始，可以右键点击卡片，选择「跟踪观看进度」。
3. 之后在同一部作品中看到下一集或下一章时，卡片会自动更新；下次点击卡片即可接着看。

![新标签页底部的网站卡片中，哔哩哔哩的“凡人修仙传 第128话”和起点的“诡秘之主 第一千二百章”两张置顶卡片带有雷达图标](uc-series "带雷达图标的卡片正在记录进度")

详见[常访网站和追更卡片](../newtab-frequent-sites/)。
