以下是 Lumno 的幾種常見使用情境，每一種都附有操作步驟，你可以從中找到適合自己的用法。

## 同時開了幾十個分頁 {#many-tabs}

分頁一多，標題會擠在一起，很難找到要去的那一頁。這時可以只在已開啟的分頁中搜尋：

1. 按下 `⌘ ⇧ K` 叫出命令列。
2. 在搜尋框為空時按一下 `Tab`，左側會顯示「搜尋已開啟分頁」。
3. 輸入標題中的幾個字，例如「layout」，選取要去的頁面，按下 Enter 即可切換過去。

![命令列處於「搜尋已開啟分頁」模式，輸入 layout 後，列出四個標題含 layout 的 MDN 分頁，右側皆為「切換」](uc-tabs "只在已開啟的分頁中搜尋")

在一般搜尋中，已開啟的分頁也會出現在結果裡，並標有「已開啟」，按下 Enter 同樣會切換過去，不會再開啟一個重複的頁面。如果只是在最近的兩三個頁面之間來回切換，按 `⌥ Q` 更快。

如果分頁多到拖慢電腦，可以搭配 Chrome 內建的「節省記憶體」功能，或者用 [OneTab](https://www.one-tab.com/) 把它們收進一個清單。

詳見[搜尋分頁、書籤和瀏覽紀錄](../search-tabs-bookmarks-history/)、[切換最近的分頁](../tab-switcher/)。

## 從 Arc 轉移過來 {#from-arc}

Arc 停止加入新功能後，不少使用者轉向了 Dia、Chrome 或 Edge。Lumno 參考了 Arc 的命令列、最近分頁切換、重新啟動後還原釘選分頁和影片自動子母畫面。安裝 Lumno 後，可以依照以下步驟設定命令列：

1. 在網址列中開啟 `chrome://extensions/shortcuts`。
2. 找到 Lumno，把「叫出聚焦搜尋視窗」改為 `⌘ T`。
3. 之後按 `⌘ T` 叫出命令列；按 `⌥ Q` 在最近的分頁之間切換，對應 Arc 的 `⌃ Tab`。

![瀏覽器的擴充功能快速鍵頁面，Lumno 的「叫出聚焦搜尋視窗」為 ⇧⌘K，「開啟最近分頁切換器」為 ⌥Q](shortcuts "在擴充功能快速鍵頁面中修改 Lumno 的快速鍵")

詳見[從 Arc 搬家](../arc-command-bar/)。

## 經常查閱文件和 GitHub {#developers}

輸入網站簡稱並按 `Tab`，可以跳過網站首頁，直接在站內搜尋。例如輸入 `gh`，按 `Tab`，再輸入 `command palette` 並按下 Enter，即可開啟 GitHub 中的搜尋結果。常用的簡稱還有 `mdn`、`npm` 和 `sf`（Stack Overflow）。

![搜尋框左側顯示 GitHub，輸入 command palette 後，結果為「在 GitHub 中搜尋 command palette」](sitesearch "輸入 gh 並按 Tab，直接在 GitHub 中搜尋")

- `chrome://extensions` 這類瀏覽器網址，輸入後可以直接開啟。
- 公司內部的文件站、工單系統，可以在 Lumno 設定中新增為自訂搜尋，並設定自己的簡稱，詳見[新增自訂搜尋](../site-search/#custom)。

## 研究與寫作時查找資料 {#research}

查找資料時，常常記得讀過某篇文章，卻想不起它是存在書籤裡，還是只留在瀏覽紀錄中。在命令列中輸入關鍵字，書籤和瀏覽紀錄會一起搜尋：結果右側會標明來源，書籤還會顯示所在的資料夾。

![輸入 css grid 後，結果中同時有瀏覽紀錄中的 CSS Grid 教學，以及書籤列「CSS 資料」資料夾中的 MDN 頁面](uc-research "書籤和瀏覽紀錄一起搜尋")

閱讀時遇到難以理解的段落，可以使用「選字快捷操作」：選取文字後，旁邊會出現 Lumno 的按鈕，按一下即可選擇解釋、研究、翻譯等操作，Lumno 會在新分頁中把文字交給 AI 處理。Lumno 會先判斷文字是否需要協助，不會每次選字都跳出。此功能預設關閉，需要先在 Lumno 設定的「實驗室功能」中開啟，詳見[選字快捷操作](../selection-actions/)。

![在一篇文章中選取「它代表容器剩餘空間中的一份」，旁邊顯示解釋、調研、翻譯等操作](uc-selection "選取文字後，讓 AI 解釋、調研或翻譯")

## 習慣向 AI 提問 {#ai}

輸入 AI 的簡稱並按 `Tab`，例如 `gpt`（ChatGPT）、`gm`（Gemini）或 `ds`（DeepSeek），寫下問題後按下 Enter。Lumno 會開啟對應 AI 的網頁版並替你送出問題，不必先開啟網站再貼上問題。

![搜尋框左側顯示 ChatGPT，問題為「Arc 瀏覽器的命令列有哪些替代方案？」，右側可開啟 ChatGPT 網頁版](ai "輸入 gpt 並按 Tab，把問題直接送給 ChatGPT")

詳見[站內搜尋和問 AI](../site-search/#ai)。

## 想要一個安靜的新分頁 {#quiet-new-tab}

Lumno 的新分頁可以只顯示你需要的內容：

- 桌布：選擇一幅喜歡的名畫，或每天自動更換 Bing 桌布。
- 時鐘和名句：在搜尋框上方顯示時鐘，在下方顯示一句詩詞。
- Zen 模式：需要專心時，在新分頁的搜尋框中輸入 `/zen`，頁面上只保留搜尋框和桌布。

![完整的新分頁：上方是時鐘 09:41、搜尋框和一句詩詞，下面依序是一排捷徑、八個書籤和最常瀏覽的網站，背景是印象派果園桌布](nt-clock "時鐘和每日名句")

詳見[更換桌布](../newtab-wallpaper/)、[時鐘、名句和 Zen 模式](../newtab-clock-zen/)。

## 追劇和追連載 {#series}

看劇集或連載小說時，Lumno 可以在新分頁上記住你看到了哪一集、哪一章：

1. 開啟正在看的那一集或那一章。之後，它會出現在新分頁底端的網站卡片中；如果沒有看到，可以按一下卡片區右上角的「···」，切換為「最近瀏覽」。
2. 將滑鼠移到這張卡片上，按一下圖釘圖示釘選。Lumno 辨識出這是劇集或章節頁面後，會自動開始記錄進度，卡片上會顯示雷達圖示。如果沒有自動開始，可以在卡片上按右鍵，選擇「追蹤觀看進度」。
3. 之後在同一部作品中看到下一集或下一章時，卡片會自動更新；下次按一下卡片即可接著看。

![新分頁底端的網站卡片中，巴哈姆特動畫瘋的「葬送的芙莉蓮 [12]」和起點的「詭秘之主 第一千二百章」兩張釘選卡片帶有雷達圖示](uc-series "帶有雷達圖示的卡片正在記錄進度")

詳見[常用網站和追劇卡片](../newtab-frequent-sites/)。
