Webクリップを使うと、ウェブページの一部（表、コード、グラフなど）を独立したフローティングウインドウに表示できます。このウインドウはほかのウインドウより手前に表示され、タブやアプリを切り替えても消えないため、読みながら内容を見比べることができます。

## Webクリップをオンにする {#enable}

Webクリップは初期設定でオフになっています。Lumno の設定で「Webクリップ」をオンにすると使用できます。

## ページの一部をクリップする {#how}

1. クリップしたいページで `⌘ ⇧ K`（Windows では `Ctrl + Shift + K`）を押してコマンドバーを開き、`/clip` と入力して Return キーを押します。

![コマンドバーに /clip と入力し、「Webクリップを開始」が表示されている](clip-command "コマンドバーに /clip と入力")

2. ポインタを動かすと、クリップできる範囲が破線の枠で示されます。
3. 枠の範囲が大きすぎたり小さすぎたりする場合は、ホイールをスクロールして範囲を切り替えます。`[` または `↑` で外側の要素を、`]` または `↓` で内側の要素を選択することもできます。
4. 枠で囲まれた内容をクリックすると、フローティングウインドウで開きます。キャンセルするには `Esc` を押します。

![記事ページの上部に操作のヒントが表示され、下の CSS プロパティの表が破線の枠で選択されている](clip-picker "破線の枠でクリップする内容を選択")

## フローティングウインドウ {#window}

- ウインドウには、選択した内容のコピーが表示されます。元のページでその部分が変わると、ウインドウの内容も更新されます。
- ウインドウ内のリンクをクリックすると、ブラウザの新しいタブで開きます。`⌘`（Windows では `Ctrl`）を押しながらクリックすると、バックグラウンドで開きます。
- ウインドウの下端にポインタを移動すると、「選び直す」ボタンと「閉じる」ボタンが表示されます。
- ウインドウは、通常のウインドウと同じように移動したりサイズを変更したりできます。

## 制限事項 {#limits}

Webクリップはブラウザの Document Picture-in-Picture を利用しているため、次の制限があります。

- HTTPS サイトの最上位のページでのみ使用できます。埋め込まれたフレーム（iframe）内では使用できません。
- サイトのポリシーでピクチャー・イン・ピクチャーが無効になっている場合は使用できません。
- 動画をピクチャー・イン・ピクチャーで再生している場合は、先にそれを閉じてください。
- 選択範囲が小さすぎるとフローティング表示できません。より大きな範囲を選択してください。
- 同時に開けるフローティングウインドウは 1 つだけです。

Firefox は Document Picture-in-Picture に対応していないため、Firefox 版ではこの機能を利用できません。
