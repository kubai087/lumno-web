웹 클립을 사용하면 웹 페이지의 일부(표, 코드, 차트 등)를 별도의 플로팅 창에 띄울 수 있습니다. 이 창은 다른 창 위에 표시되며 탭이나 앱을 전환해도 사라지지 않으므로, 글을 읽으면서 내용을 대조하기 편리합니다.

## 웹 클립 켜기 {#enable}

웹 클립은 기본적으로 꺼져 있습니다. Lumno 설정에서 "Web Clip"을 켜면 사용할 수 있습니다.

## 페이지 일부 잘라 내기 {#how}

1. 잘라 낼 페이지에서 `⌘ ⇧ K`를 눌러 명령 바를 열고 `/clip`을 입력한 다음 Enter 키를 누르세요.

![명령 바에 /clip을 입력하자 "Start Web Clip" 결과가 표시된 모습](clip-command "명령 바에 /clip 입력")

2. 포인터를 움직이면 잘라 낼 수 있는 영역이 점선 테두리로 표시됩니다.
3. 테두리 범위가 너무 크거나 작으면 마우스 휠을 스크롤해 범위를 바꾸세요. `[` 또는 `↑`를 누르면 바깥쪽 요소를, `]` 또는 `↓`를 누르면 안쪽 요소를 선택합니다.
4. 테두리로 둘러싸인 내용을 클릭하면 플로팅 창에서 열립니다. 취소하려면 `Esc`를 누르세요.

![문서 페이지 상단에 안내 문구가 표시되고, 아래의 CSS 속성 표가 점선 테두리로 선택된 모습](clip-picker "점선 테두리로 잘라 낼 내용 선택")

## 플로팅 창 {#window}

- 창에는 선택한 내용의 사본이 표시됩니다. 원래 페이지의 해당 부분이 바뀌면 창의 내용도 함께 업데이트됩니다.
- 창에서 링크를 클릭하면 브라우저의 새 탭에서 열립니다. `⌘`를 누른 채 클릭하면 백그라운드에서 열립니다.
- 포인터를 창 아래쪽으로 옮기면 "Reselect" 버튼과 "Close" 버튼이 나타납니다.
- 창은 일반 창처럼 옮기거나 크기를 조절할 수 있습니다.

## 제한 사항 {#limits}

웹 클립은 브라우저의 문서 PIP(Document Picture-in-Picture)를 기반으로 하므로 다음과 같은 제한이 있습니다.

- HTTPS 사이트의 최상위 페이지에서만 사용할 수 있으며, 삽입된 프레임(iframe) 안에서는 사용할 수 없습니다.
- 사이트 정책으로 PIP를 막아 둔 사이트에서는 사용할 수 없습니다.
- 동영상이 이미 PIP로 재생 중이라면 먼저 닫아야 합니다.
- 선택한 영역이 너무 작으면 띄울 수 없습니다. 더 큰 영역을 선택하세요.
- 플로팅 창은 한 번에 하나만 열 수 있습니다.

Firefox는 문서 PIP를 지원하지 않으므로 Firefox 버전에서는 이 기능을 사용할 수 없습니다.
