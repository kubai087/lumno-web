网页剪裁可以把网页中的一部分单独放进悬浮窗口，例如一张表格、一段代码或一张图表。悬浮窗口会显示在其他窗口之上，切换标签页或应用时也不会消失，方便一边阅读、一边对照。

## 开启网页剪裁 {#enable}

网页剪裁默认关闭。在 Lumno 设置中开启「网页剪裁」后即可使用。

## 剪下网页内容 {#how}

1. 在要剪裁的网页上按下 `⌘ ⇧ K`（Windows 上为 `Ctrl + Shift + K`）唤出命令栏，输入 `/clip`，然后按回车键。

![命令栏中输入 /clip 后，结果为“开启网页剪裁”](clip-command "在命令栏中输入 /clip")

2. 移动鼠标，Lumno 会用虚线框标出可以剪下的区域。
3. 如果框住的范围太大或太小，可以滚动鼠标滚轮切换范围，也可以按 `[` 或 `↑` 选择外层元素，按 `]` 或 `↓` 选择内层元素。
4. 点击框住的内容，它会在悬浮窗口中打开。按 `Esc` 可以取消。

![文章页面顶部显示操作提示，下方的 CSS 属性表格被虚线框选中](clip-picker "用虚线框选择要剪下的内容")

## 悬浮窗口 {#window}

- 悬浮窗口中显示的是所选内容的副本。原网页中的这部分内容发生变化时，悬浮窗口会同步更新。
- 在悬浮窗口中点击链接，会在浏览器中新开一个标签页；按住 `⌘`（Windows 上为 `Ctrl`）点击，则在后台打开。
- 将鼠标移到悬浮窗口底部，会显示「重新选择」和「关闭」按钮。
- 悬浮窗口可以像普通窗口一样移动和调整大小。

## 使用限制 {#limits}

网页剪裁基于浏览器的文档画中画（Document Picture-in-Picture），因此有以下限制：

- 只能在 HTTPS 网页的顶层页面中使用，不能在嵌入的框架（iframe）中使用。
- 网站通过站点策略禁用了画中画时，无法使用。
- 已有视频在画中画中播放时，需要先关闭视频画中画。
- 所选区域太小时无法悬浮，请换一个更大的内容区域。
- 同一时间只能打开一个悬浮窗口。

Firefox 不支持文档画中画，因此 Firefox 版不提供此功能。
