網頁剪裁可以把網頁中的一部分單獨放進浮動視窗，例如一張表格、一段程式碼或一張圖表。浮動視窗會顯示在其他視窗之上，切換分頁或 App 時也不會消失，方便一邊閱讀、一邊對照。

## 開啟網頁剪裁 {#enable}

網頁剪裁預設為關閉。在 Lumno 設定中開啟「網頁剪裁」後即可使用。

## 剪下網頁內容 {#how}

1. 在要剪裁的網頁上按下 `⌘ ⇧ K`（Windows 上為 `Ctrl + Shift + K`）叫出命令列，輸入 `/clip`，然後按下 Enter。

![命令列中輸入 /clip 後，結果為「開啟網頁剪裁」](clip-command "在命令列中輸入 /clip")

2. 移動滑鼠，Lumno 會用虛線框標出可以剪下的區域。
3. 如果框住的範圍太大或太小，可以捲動滑鼠滾輪切換範圍，也可以按 `[` 或 `↑` 選擇外層元素，按 `]` 或 `↓` 選擇內層元素。
4. 按一下框住的內容，它就會在浮動視窗中開啟。按 `Esc` 可以取消。

![文章頁面頂端顯示操作提示，下方的 CSS 屬性表格被虛線框選取](clip-picker "用虛線框選取要剪下的內容")

## 浮動視窗 {#window}

- 浮動視窗中顯示的是所選內容的副本。原網頁中的這部分內容有變化時，浮動視窗會同步更新。
- 在浮動視窗中按一下連結，會在瀏覽器中開啟新分頁；按住 `⌘`（Windows 上為 `Ctrl`）再按一下，則在背景開啟。
- 將游標移到浮動視窗底部，會顯示「重新選擇」和「關閉」按鈕。
- 浮動視窗可以像一般視窗一樣移動和調整大小。

## 使用限制 {#limits}

網頁剪裁以瀏覽器的文件子母畫面（Document Picture-in-Picture）為基礎，因此有以下限制：

- 只能在 HTTPS 網頁的最上層頁面中使用，無法在嵌入的框架（iframe）中使用。
- 網站透過網站政策停用子母畫面時，無法使用。
- 已有影片在子母畫面中播放時，需要先關閉影片的子母畫面。
- 選取的區域太小時無法浮動，請改選較大的內容區域。
- 同一時間只能開啟一個浮動視窗。

Firefox 不支援文件子母畫面，因此 Firefox 版不提供這項功能。
