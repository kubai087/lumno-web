Lumno는 무료 오픈소스 브라우저 확장 프로그램입니다. 주요 기능은 두 가지입니다. 어떤 페이지에서든 단축키를 누르면 브라우저 전체를 검색할 수 있는 명령 바가 열리고, 새 탭은 깔끔하고 보기 좋은 시작 페이지로 바뀝니다. Chrome, Edge, Dia, Brave 등 Chromium 기반 브라우저에서 사용할 수 있습니다.

## 명령 바 {#command-bar}

어떤 페이지에서든 `⌘ ⇧ K`(Windows에서는 `Ctrl + Shift + K`)를 누르면 화면 가운데에 명령 바가 열립니다.

- 몇 글자만 입력하면 열린 탭, 북마크, 방문 기록에 있는 페이지를 찾을 수 있으며, Return 키를 누르면 해당 페이지로 바로 이동합니다. 자세한 내용은 [탭, 북마크, 방문 기록 검색](../search-tabs-bookmarks-history/)을 참고하세요.
- GitHub, YouTube, Stack Overflow 등을 홈페이지를 열지 않고 바로 검색할 수 있습니다. 사이트 단축어를 입력하고 `Tab`을 누른 다음 검색어를 입력하세요. ChatGPT나 Gemini에 질문할 때도 방법은 같습니다. 자세한 내용은 [사이트 검색과 AI에게 질문하기](../site-search/)를 참고하세요.
- URL이나 `chrome://settings` 같은 브라우저 페이지를 입력해 바로 열 수도 있습니다.

![빈 페이지 위의 Lumno 명령 바: chrome을 입력하자 열린 GitHub 탭, 추천 검색어, 북마크, 자주 가는 사이트가 함께 나타난다](search "검색창 하나로 브라우저 전체 검색")

최근에 본 몇 개의 페이지 사이를 오가려면 `⌥ Q`를 눌러 [최근 탭 전환기](../tab-switcher/)를 여세요.

## 새 탭 {#new-tab}

Lumno를 설치하면 Chrome과 Edge의 새 탭이 Lumno 시작 페이지로 바뀝니다. 명화 배경화면, 자주 가는 사이트, 북마크, 자주 방문한 페이지가 한 화면에 표시됩니다. 표시할 항목은 Appearance 설정에서 조정할 수 있습니다.

## 기타 기능 {#more}

- 텍스트 선택 빠른 작업(Selection quick actions): 문단을 선택하면 AI에게 답변, 번역, 설명, 요약을 요청할 수 있습니다. 기본적으로 꺼져 있으며, 설정의 Labs에서 켤 수 있습니다.
- 웹 클립: 페이지의 일부를 잘라 떠 있는 PIP 창에 표시합니다.
- 자동 PIP: YouTube나 Twitch 탭에서 다른 탭으로 이동해도 영상이 작은 창에서 계속 재생됩니다.
- 고정 탭 복원: 브라우저를 다시 시작하면 고정한 탭이 자동으로 복원됩니다.

각 기능은 Lumno 설정에서 개별적으로 켜거나 끌 수 있습니다.

## Lumno의 특징 {#strengths}

- 무료 오픈소스: GPL-3.0 라이선스로 공개되어 있으며, 모든 코드를 [GitHub](https://github.com/kubai087/lumno-extension)에서 확인할 수 있습니다.
- 계정 불필요: Lumno에는 가입 절차도 서버도 없으며, 브라우징 데이터는 사용자의 브라우저에만 저장됩니다. 자세한 내용은 [개인정보와 데이터](../privacy-data/)를 참고하세요.
- 브라우저 교체 불필요: Chrome, Edge, Dia에서 Arc 스타일의 명령 바를 사용할 수 있습니다.
- 다국어 지원: 확장 프로그램 화면은 영어, 일본어, 중국어 간체·번체로 제공되며, 여러 나라의 주요 사이트가 기본으로 포함되어 있습니다.

설치하기 전에 [Lumno가 할 수 없는 일](../limitations/)도 확인해 보세요.
