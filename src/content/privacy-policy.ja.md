## 2. 情報の取り扱い

Lumno の主要な機能はブラウザ内で動作します。画面上に表示され、あなたが利用する機能を提供するため、本拡張機能は以下の情報を端末上で読み取り、または保存します。**第 4 条に記載する場合を除き、これらの情報が端末の外に出ることはなく、Lumno や開発者に送信されることもありません。**

### 2.1 ブラウザのデータ

- **タブ：** URL、タイトル、グループ、アイコン。タブの検索、切り替え、並べ替え、復元、管理に使用します。タブ切り替え画面を使うと、現在のタブをサムネイルとしてキャプチャします。サムネイルは最大 12 枚、各 2 時間以内に限り、端末内にのみ保存します。
- **履歴：** URL、タイトル、訪問日時。端末内での履歴の検索と並べ替え、およびあなたが求めた場合の項目削除に使用します。
- **ブックマーク：** フォルダ構成、名前、URL。あなたの操作に応じたブックマークの検索、表示、管理に使用します。
- **よくアクセスするサイト：** URL とタイトル。新しいタブに表示するために使用します。固定または非表示にしたサイトカードは設定として保存します。

### 2.2 ページの内容

- **ショートカットとコマンドバー：** Web ページ上で Lumno のキーボードショートカットを検知し、コマンドバーを表示します。
- **選択テキストのクイック操作：** 初期状態ではオフです。オンにすると、選択したテキスト（最大 2,400 文字）を読み取り、あなたが操作を選んだときにのみ使用します。
- **自動ピクチャー・イン・ピクチャー：** 対応する動画サイトで動画要素を見つけ、ピクチャー・イン・ピクチャーを開きます。
- **進捗の追跡（ラボ機能）：** 追跡対象に指定したサイトカードにのみ動作します。ページの前後のリンク、構造化データ、メディア情報を読み取り、そのカードの URL とタイトルを更新します。

### 2.3 検索と設定

- **検索履歴：** 入力した語句と、選んだ結果の URL・タイトル。端末内での並び順の改善に使用します。
- **設定とメディア：** テーマ、言語、レイアウト、ショートカット、検索プロバイダー、非表示リスト、機能のオン・オフ、アップロードしたショートカットアイコン、カスタム壁紙、およびこれらの機能に必要なキャッシュ。

### 2.4 収集しない情報

Lumno は登録やサインインを必要としません。氏名、メールアドレス、電話番号、住所を収集せず、利用回数、クリック、端末識別子、クラッシュデータを送信せず、履歴、ブックマーク、タブの一覧、ページの内容を開発者に送ることもありません。

## 3. 各権限が必要な理由

本拡張機能は、これらの機能に必要な権限のみを要求し、任意の権限（optional permissions）は要求しません。

| 権限 | 用途 |
| --- | --- |
| `tabs`、`tabGroups` | タブの照会、切り替え、作成、更新、グループ化、復元、およびタブ切り替え用サムネイルのキャプチャ。 |
| `history` | 端末内での履歴の検索と並べ替え、およびあなたの求めに応じた項目の削除。 |
| `bookmarks` | ブックマークの検索、表示、管理。 |
| `topSites` | よくアクセスするサイトを新しいタブに表示。 |
| `storage`、`unlimitedStorage` | 設定、キャッシュ、カスタム画像、WebDAV 同期に必要なローカル設定を、ブラウザの既定の容量を超えて保存。 |
| `alarms` | WebDAV の同期状態をバックグラウンドで定期的に確認。 |
| `search` | 送信した検索語をブラウザの既定の検索エンジンに渡す。 |
| `favicon` | ブラウザ経由で Web サイトのアイコンを表示。 |
| `scripting` と `<all_urls>` のサイトアクセス | Web ページ上でのコマンドバー、ショートカット、選択テキストのクイック操作、ピクチャー・イン・ピクチャー、進捗の追跡の提供、選んだ AI・検索サービスへの検索語の入力、Web サイトのアイコンや壁紙画像の取得、設定した WebDAV アドレスへの接続。 |

広範なサイトアクセスは上記の機能にのみ使用します。Lumno がページの内容を一括で読み取り、収集し、アップロードするという意味ではありません。

## 4. 端末の外に送信されるデータ

以下のリクエストは本拡張機能から関係する第三者サービスへ直接送信され、**Lumno のサーバーを経由することはありません。** 受信者は、あらゆるネットワークリクエストに含まれる IP アドレスやブラウザ情報も受け取り、それぞれのプライバシーポリシーに従って取り扱います。

### 4.1 オンライン検索候補

Lumno の検索ボックス（新しいタブまたはコマンドバー）に入力すると、候補を表示するため、入力内容がリアルタイムで現在の検索エンジンの候補エンドポイントに送信されます。対応サービスは Google、Bing、Baidu、Sogou（Tencent の `sor.html5.qq.com` が提供）、DuckDuckGo、Yandex、Quark・Shenma（`sugs.m.sm.cn`）、Yahoo です。設定で検索エンジンを切り替えると、送信先を変更できます。

### 4.2 Web 検索、サイト内検索、AI

- **Web 検索・サイト内検索：** 送信した検索語は、ブラウザの既定の検索エンジンに渡されるか、あなたが選んだ検索サービスや Web サイトを新しいタブで開きます。
- **AI 検索と選択テキストのクイック操作：** あなたが操作を選んだ後にのみ、選んだ AI サービス（ChatGPT、Gemini、DeepSeek、Doubao、Kimi など）を開き、検索語または選択テキストと、その操作のために Lumno が用意したプロンプトを入力します。

これらは、あなた自身がそれらのサイトにアクセスするのと同じです。サイトは送信された内容を受け取り、そのサイトでのログイン状態と結び付ける場合があります。

### 4.3 Web サイトのアイコン

サイトのアイコンを取得するため、Google の favicon サービス（`www.google.com` / `gstatic`）がページの URL を受け取ります。Favicon.is を選んだ場合は、ドメインのみを送信します。これらのリクエストには Cookie やリファラーを含めず、アイコンは端末内にキャッシュします。ショートカットに設定したカスタムアイコンのアドレスは、ブラウザがそのアドレスから直接読み込みます。

### 4.4 オンライン壁紙と日替わりの名言

- **日替わりの名言：** 初期状態ではオフです。オンにすると、選んだカテゴリの名言を Hitokoto（`v1.hitokoto.cn`）から取得し、その日のうちキャッシュします。
- **Bing 壁紙：** `www.bing.com` から取得します。リクエストに含まれるのは地域と画像の識別子のみです。
- **厳選壁紙とアート壁紙：** 写真は Lorem Picsum（`picsum.photos`、出典は Unsplash）、作品はクリーブランド美術館のオープンアクセス・コレクション（`openaccess-cdn.clevelandart.org`）から取得します。リクエストに含まれるのは画像 ID とサイズのみです。
- **画像リンクの壁紙：** 貼り付けたリンクは設定とともに同期されます。各端末はそのアドレスから画像を一度だけ取得し、圧縮して端末内にキャッシュします。

壁紙や名言のダウンロードには Cookie やリファラーを含めません。壁紙選択画面のプレビュー用サムネイルは、通常の Web 画像と同様に読み込まれます。

### 4.5 リリースノートと本サイトのリソース

- **アップデートのお知らせ：** アップデート後、お知らせを表示するため、そのバージョンのリリースタイトルを GitHub（`api.github.com`、予備として `github.com`）に問い合わせます。設定で「更新のお知らせ」をオフにできます。
- **更新履歴ページ：** アップデート後、本サイトの更新履歴を開く場合があります。その URL には遷移元、アップデートの理由、拡張機能のバージョンが含まれ、そのページには第 6 条が適用されます。
- **フィードバックのリンク：** フィードバックやコミュニティのリンクを開くと、本サイトからコミュニティリンクの設定（`community-links.json`）とコミュニティの QR コード画像を取得します。
- **ヘルプセンター検索：** 「Lumno ヘルプセンター」のサイト内検索に入力すると、本サイトから現在の表示言語のヘルプセンター検索インデックス（`search-index.json`）をダウンロードし、端末内で照合して最大 10 分間キャッシュします。入力した内容は本サイトに送信されません。

本サイトは GitHub Pages でホスティングしており、ホスティング事業者である GitHub が IP アドレスを含むリクエストを記録する場合があります。

## 5. 設定の同期

Lumno はクラウド同期を提供していません。設定が端末間で移動するのは、あなたが選んだ次の方法による場合のみです。

- **ブラウザの内蔵同期：** テーマ、検索プロバイダー、ショートカット（タイトルと URL）、固定・非表示にしたサイトカード（URL とタイトル）、非表示リストのルール、壁紙の選択と画像リンク、日替わりの名言の設定、WebDAV サーバーのアドレス・フォルダ・ユーザー名は `chrome.storage.sync` に保存され、ブラウザのアカウントと同期設定に従って、ブラウザ提供元によって端末間で同期されます。アップロードしたアイコン、カスタム壁紙、WebDAV のアプリパスワードがブラウザ同期の対象になることはありません。
- **WebDAV 同期（任意）：** 初期状態ではオフで、あなた自身がサーバーを追加した場合にのみオンになります。オンにすると、すべての設定、アップロードしたショートカットアイコン、カスタム壁紙、上書き前の設定スナップショットが、指定したサーバーとフォルダに HTTPS で保存されます。履歴、ブックマーク、開いているタブ、アイコンのキャッシュがアップロードされることはありません。WebDAV にはエンドツーエンド暗号化がないため、そのサーバーの管理者はこれらのファイルを閲覧できます。
- **書き出しと読み込み：** 設定を JSON ファイルとして書き出し、保管したり別の端末で読み込んだりできます。書き出したファイルに画像は含まれません。

## 6. 本サイトのアクセス解析と Cookie

本サイトの公開ページは VibeLoft のアクセス解析スクリプトを読み込み、デプロイ時の設定により Google アナリティクス（IP 匿名化あり）を有効にする場合があります。これらのサービスは、ページの URL（クエリパラメータを含む）とタイトル、訪問日時、参照元ページ、クリックイベント、ブラウザの言語、端末とブラウザの種類、おおよその位置、IP アドレス、Cookie またはそれに類する仮名の識別子を処理する場合があります。

これらのデータは、本サイトのトラフィック、流入元、パフォーマンスを把握するためにのみ使用し、本拡張機能内のデータと結び付けることはありません。本拡張機能自体がこれらのスクリプトを読み込むことはありません。ブラウザの Cookie、スクリプトブロック、トラッキング防止の機能でアクセス解析を拒否しても、拡張機能の機能には影響しません。

## 8. 保存と保存期間

本拡張機能は、ブラウザの `chrome.storage.local`、`chrome.storage.sync`、セッションストレージ、および拡張機能専用の IndexedDB にデータを保存します。アップロードしたショートカットアイコンは `chrome.storage.local` に、カスタム壁紙、WebDAV の設定、アプリパスワード、復元用のバックアップは IndexedDB に保存します。

| データ | 保存期間 |
| --- | --- |
| 端末内の設定、画像、キャッシュ、検索の並び順のデータ | 拡張機能内で削除するか、ブラウザで拡張機能のデータを消去するか、Lumno をアンインストールするまで。 |
| タブ切り替え用のサムネイル | 各 2 時間まで。 |
| ブラウザ同期の設定 | ブラウザのアカウントと同期設定に従い、ブラウザ提供元が保存・削除します。 |
| WebDAV サーバー上のファイル | 削除するまであなたのサーバーに残ります。同期の一時停止、接続の解除、Lumno のアンインストールでは削除されません。 |
| 書き出した設定ファイル | あなた自身が保管・削除します。 |
| 第三者サービスと本サイトのアクセス解析データ | 各サービスがそれぞれのポリシーに従って保存します。 |

Lumno が管理するシステムには、あなたに関する個人情報は一切保存されていません。

## 10. セキュリティ

次の措置によってあなたのデータを保護しています。

- 閲覧データはブラウザ内でのみ処理し、開発者に送信することはありません。
- WebDAV は HTTPS のアドレスのみを受け付け、証明書の検証を維持し、認証のリダイレクトを拒否します。
- WebDAV のアプリパスワードは、現在の端末にある拡張機能専用のストレージに保存します。ブラウザ同期の対象にならず、Web ページやコンテンツスクリプトに公開されることもありません。
- Web サイトのアイコンや壁紙のダウンロードには Cookie やリファラーを含めません。

Lumno 専用の WebDAV アプリパスワードを発行し、端末、ブラウザアカウント、WebDAV アカウントの安全を保つことをおすすめします。完全に安全な通信・保存の方法はありません。セキュリティ上の問題を見つけた場合は、[i@kubai.design](mailto:i@kubai.design) までお知らせください。

Lumno はユーザーデータを保存するサーバーを運用していないため、あなたのデータが Lumno の管理するシステムに移転されることはありません。ブラウザ提供元、あなたが選んだ検索・AI・WebDAV・画像サービス、GitHub、VibeLoft、Google アナリティクスは、それぞれのプライバシーポリシーと移転の仕組みに基づき、あなたの国や地域の外でデータを処理する場合があります。

## 13. Chrome ウェブストアのユーザーデータに関するポリシー

- データは、拡張機能の単一の、ユーザー向けの目的を提供または改善するためにのみ使用します。
- データは、あなたが開始した操作を完了するために必要な範囲でのみ、第 4 条に記載のサービスに送信します。
- データを第三者に販売・移転したり、パーソナライズ広告に使用したり、信用力の判断や融資の目的に使用したりすることはありません。
