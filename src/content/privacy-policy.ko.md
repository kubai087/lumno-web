## 2. 정보 처리 방식

Lumno의 핵심 기능은 브라우저 안에서 동작합니다. 화면에 보이고 사용자가 직접 쓰는 기능을 제공하기 위해, 확장 프로그램은 다음 정보를 기기에서 읽거나 저장합니다. **제4조에서 설명하는 경우를 제외하면, 이 정보는 기기 밖으로 나가지 않으며 Lumno나 개발자에게 전송되지 않습니다.**

### 2.1 브라우저 데이터

- **탭:** URL, 제목, 그룹, 아이콘. 탭 검색, 전환, 정렬, 복원, 관리에 사용합니다. 탭 전환기를 사용하면 현재 탭을 썸네일로 캡처하며, 최대 12개를 각각 2시간 이내로만 기기에 보관합니다.
- **방문 기록:** URL, 제목, 방문 시각. 기기 내 방문 기록 검색과 순위 지정, 그리고 사용자가 요청한 항목 삭제에 사용합니다.
- **북마크:** 폴더 구조, 이름, URL. 사용자의 요청에 따른 북마크 검색, 표시, 관리에 사용합니다.
- **자주 방문한 사이트:** URL과 제목. 새 탭에 표시하는 데 사용합니다. 고정하거나 숨긴 사이트 카드는 설정으로 저장됩니다.

### 2.2 페이지 콘텐츠

- **단축키와 커맨드 바:** 웹페이지에서 Lumno 단축키를 감지하고 커맨드 바를 표시합니다.
- **선택 텍스트 빠른 작업:** 기본값은 꺼짐입니다. 켜면 사용자가 선택한 텍스트(최대 2,400자)를 읽고, 사용자가 작업을 고를 때만 사용합니다.
- **자동 PIP:** 지원하는 동영상 사이트에서 동영상 요소를 찾아 PIP(화면 속 화면)를 엽니다.
- **진도 추적(실험실 기능):** 추적하도록 표시한 사이트 카드에서만 동작합니다. 페이지의 이전·다음 링크, 구조화 데이터, 미디어 정보를 읽어 해당 카드의 URL과 제목을 업데이트합니다.

### 2.3 검색과 설정

- **검색 기록:** 입력한 내용과 선택한 결과의 URL·제목. 기기 내 순위 개선에 사용합니다.
- **설정과 미디어:** 테마, 언어, 레이아웃, 단축키, 검색 제공자, 차단 목록, 기능 켜기/끄기, 업로드한 바로가기 아이콘, 사용자 지정 배경화면, 그리고 이 기능들에 필요한 캐시.

### 2.4 수집하지 않는 정보

Lumno는 가입이나 로그인이 필요 없습니다. 이름, 이메일 주소, 전화번호, 주소를 수집하지 않고, 사용 횟수, 클릭, 기기 식별자, 오류 데이터를 보고하지 않으며, 방문 기록, 북마크, 탭 목록, 페이지 콘텐츠를 개발자에게 보내지 않습니다.

## 3. 각 권한이 필요한 이유

확장 프로그램은 이 기능들에 필요한 권한만 요청하며, 선택적 권한은 요청하지 않습니다.

| 권한 | 용도 |
| --- | --- |
| `tabs`, `tabGroups` | 탭 조회, 전환, 생성, 업데이트, 그룹화, 복원 및 탭 전환기 썸네일 캡처. |
| `history` | 기기 내 방문 기록 검색과 순위 지정, 사용자 요청 시 항목 삭제. |
| `bookmarks` | 북마크 검색, 표시, 관리. |
| `topSites` | 자주 방문한 사이트를 새 탭에 표시. |
| `storage`, `unlimitedStorage` | 설정, 캐시, 사용자 지정 이미지, WebDAV 동기화에 필요한 로컬 구성을 브라우저 기본 용량을 넘어 저장. |
| `alarms` | 백그라운드에서 WebDAV 동기화 상태를 주기적으로 확인. |
| `search` | 사용자가 제출한 검색어를 브라우저 기본 검색 엔진에 전달. |
| `favicon` | 브라우저를 통해 웹사이트 아이콘 표시. |
| `scripting` 및 `<all_urls>` 사이트 액세스 | 웹페이지에서 커맨드 바, 단축키, 선택 텍스트 빠른 작업, PIP, 진도 추적 제공, 선택한 AI·검색 서비스에 검색어 입력, 웹사이트 아이콘과 배경화면 이미지 가져오기, 설정한 WebDAV 주소 연결. |

광범위한 사이트 액세스는 위 기능에만 사용합니다. Lumno가 페이지 콘텐츠를 대량으로 읽거나 수집하거나 업로드한다는 뜻이 아닙니다.

## 4. 기기 밖으로 전송되는 데이터

아래 요청은 확장 프로그램이 관련 제3자 서비스로 직접 보내며, **Lumno 서버를 거치지 않습니다.** 수신자는 모든 네트워크 요청에 포함되는 IP 주소와 브라우저 정보도 받으며, 이를 자체 개인정보처리방침에 따라 처리합니다.

### 4.1 온라인 검색 추천

Lumno 검색창(새 탭 또는 커맨드 바)에 입력하면, 추천 검색어를 보여 주기 위해 입력 내용이 실시간으로 현재 검색 엔진의 추천 엔드포인트로 전송됩니다. 지원 서비스는 Google, Bing, Baidu, Sogou(Tencent의 `sor.html5.qq.com`에서 제공), DuckDuckGo, Yandex, Quark·Shenma(`sugs.m.sm.cn`), Yahoo입니다. 설정에서 검색 엔진을 바꾸면 요청을 받는 곳을 변경할 수 있습니다.

### 4.2 웹 검색, 사이트 내 검색, AI

- **웹 검색과 사이트 내 검색:** 제출한 검색어는 브라우저 기본 검색 엔진으로 전달되거나, 사용자가 고른 검색 서비스나 웹사이트를 새 탭에서 엽니다.
- **AI 검색과 선택 텍스트 빠른 작업:** 사용자가 작업을 고른 뒤에만, 고른 AI 서비스(ChatGPT, Gemini, DeepSeek, Doubao, Kimi 등)를 열고 검색어나 선택한 텍스트, 그리고 해당 작업을 위해 Lumno가 작성한 프롬프트를 입력합니다.

이는 사용자가 직접 해당 사이트를 방문하는 것과 같습니다. 사이트는 제출된 내용을 받으며, 그 사이트에 로그인된 세션과 연결할 수 있습니다.

### 4.3 웹사이트 아이콘

사이트 아이콘을 가져오기 위해 Google favicon 서비스(`www.google.com` / `gstatic`)가 페이지 URL을 받습니다. Favicon.is를 고르면 도메인만 전송됩니다. 이 요청에는 쿠키나 리퍼러가 포함되지 않으며, 아이콘은 기기에 캐시됩니다. 바로가기에 지정한 사용자 지정 아이콘 주소는 브라우저가 해당 주소에서 직접 불러옵니다.

### 4.4 온라인 배경화면과 오늘의 문장

- **오늘의 문장:** 기본값은 꺼짐입니다. 켜면 선택한 분류의 문장을 Hitokoto(`v1.hitokoto.cn`)에서 가져와 하루 동안 캐시합니다.
- **Bing 배경화면:** `www.bing.com`에서 가져오며, 요청에는 지역과 이미지 식별자만 포함됩니다.
- **큐레이션 및 예술 작품 배경화면:** 사진은 Lorem Picsum(`picsum.photos`, 출처 Unsplash), 작품은 클리블랜드 미술관 오픈 액세스 컬렉션(`openaccess-cdn.clevelandart.org`)에서 가져오며, 요청에는 이미지 ID와 크기만 포함됩니다.
- **이미지 링크 배경화면:** 붙여 넣은 링크는 설정과 함께 동기화되며, 각 기기는 해당 주소에서 이미지를 한 번만 받아 압축한 뒤 기기에 캐시합니다.

배경화면과 문장 다운로드에는 쿠키나 리퍼러가 포함되지 않습니다. 배경화면 선택기의 미리 보기 썸네일은 일반 웹 이미지처럼 불러옵니다.

### 4.5 릴리스 노트와 웹사이트 리소스

- **업데이트 알림:** 업데이트 후 알림을 표시하기 위해 해당 버전의 릴리스 제목을 GitHub(`api.github.com`, 대체 경로로 `github.com`)에 요청합니다. 설정에서 ‘Update Prompts’를 끌 수 있습니다.
- **업데이트 내역 페이지:** 업데이트 후 웹사이트의 업데이트 내역을 열 수 있습니다. 그 URL에는 진입 경로, 업데이트 사유, 확장 프로그램 버전이 포함되며, 해당 페이지에는 제6조가 적용됩니다.
- **피드백 링크:** 피드백이나 커뮤니티 링크를 열면 웹사이트에서 커뮤니티 링크 구성(`community-links.json`)과 커뮤니티 QR 코드 이미지를 가져옵니다.
- **Help Center 검색:** "Lumno Help Center" 사이트 검색에 입력하면 확장 프로그램이 웹사이트에서 현재 인터페이스 언어의 도움말 센터 검색 색인(`search-index.json`)을 내려받아 기기에서 결과를 찾고 최대 10분 동안 캐시합니다. 입력한 내용은 웹사이트로 전송되지 않습니다.

웹사이트는 GitHub Pages에서 호스팅되며, 호스팅 제공자인 GitHub가 IP 주소를 포함한 요청을 기록할 수 있습니다.

## 5. 설정 동기화

Lumno는 클라우드 동기화를 제공하지 않습니다. 설정은 사용자가 고른 다음 방법으로만 기기 사이를 이동합니다.

- **브라우저 내장 동기화:** 테마, 검색 제공자, 바로가기(제목과 URL), 고정하거나 숨긴 사이트 카드(URL과 제목), 차단 목록 규칙, 배경화면 선택과 이미지 링크, 오늘의 문장 설정, WebDAV 서버 주소·폴더·사용자 이름은 `chrome.storage.sync`에 저장되며, 브라우저 계정과 동기화 설정에 따라 브라우저 제공 업체가 기기 간에 동기화합니다. 업로드한 아이콘, 사용자 지정 배경화면, WebDAV 앱 비밀번호는 브라우저 동기화에 포함되지 않습니다.
- **WebDAV 동기화(선택):** 기본값은 꺼짐이며, 사용자가 직접 서버를 추가해야 켜집니다. 켜면 전체 구성, 업로드한 바로가기 아이콘, 사용자 지정 배경화면, 덮어쓰기 전에 만든 구성 스냅숏이 사용자가 지정한 서버와 폴더에 HTTPS로 저장됩니다. 방문 기록, 북마크, 열린 탭, 아이콘 캐시는 업로드되지 않습니다. WebDAV는 종단 간 암호화를 제공하지 않으므로, 해당 서버의 관리자는 이 파일을 읽을 수 있습니다.
- **내보내기와 가져오기:** 설정을 JSON 파일로 내보내 보관하거나 다른 기기에서 가져올 수 있습니다. 내보낸 파일에는 이미지가 포함되지 않습니다.

## 6. 웹사이트 분석과 쿠키

웹사이트의 공개 페이지는 VibeLoft 분석 스크립트를 불러오며, 배포 설정에 따라 Google 애널리틱스(IP 익명화 적용)를 사용할 수 있습니다. 이 서비스들은 페이지 URL(쿼리 매개변수 포함)과 제목, 방문 시각, 참조 페이지, 클릭 이벤트, 브라우저 언어, 기기와 브라우저 종류, 대략적인 위치, IP 주소, 쿠키 또는 이와 유사한 가명 식별자를 처리할 수 있습니다.

이 데이터는 웹사이트의 트래픽, 유입 경로, 성능을 파악하는 데만 사용하며, 확장 프로그램 안의 어떤 데이터와도 연결하지 않습니다. 확장 프로그램 자체는 이 스크립트를 불러오지 않습니다. 브라우저의 쿠키, 스크립트 차단, 추적 방지 기능으로 웹사이트 분석을 막아도 확장 프로그램 기능에는 영향이 없습니다.

## 7. 공유, 이전, 공개

Lumno는 사용자의 개인정보를 판매, 대여, 거래하지 않으며, 맞춤형 광고나 교차 맥락 행동 광고에 사용하지 않고, 데이터 브로커나 광고 플랫폼에 제공하지 않습니다. 사용자가 시작한 작업을 완료하는 경우를 제외하고는 개인정보를 공유, 이전하거나 공개하지 않습니다.

데이터를 받을 수 있는 제3자:

| 수신자 | 받을 수 있는 데이터 | 목적 |
| --- | --- | --- |
| 브라우저 제공 업체(Google, Microsoft 등) | `chrome.storage.sync`의 설정과 브라우저 계정 메타데이터 | 확장 프로그램 설정의 내장 동기화. |
| 사용자의 WebDAV 서비스(Jianguoyun, NAS, 자체 서버 등) | 전체 구성, 아이콘, 배경화면, 스냅숏, 로그인에 쓰는 사용자 이름과 앱 비밀번호 | 사용자 설정에 따른 설정과 이미지 동기화. |
| 검색 추천 서비스(제4.1조) | 입력 내용과 요청 메타데이터 | 추천 검색어 표시. |
| 사용자가 고른 검색·AI·웹 서비스 | 제출한 검색어, 선택한 텍스트, 프롬프트 | 사용자가 시작한 검색과 AI 작업 수행. |
| Google favicon 서비스, Favicon.is | 페이지 URL 또는 도메인 | 웹사이트 아이콘 표시. |
| Hitokoto, Bing, Lorem Picsum, 클리블랜드 미술관 | 분류, 지역, 이미지 ID, 크기 | 사용자가 켠 오늘의 문장과 온라인 배경화면. |
| GitHub | 확장 프로그램 버전, 웹사이트 및 릴리스 요청의 액세스 로그 | 업데이트 알림과 웹사이트 호스팅. |
| [VibeLoft](https://vibeloft.ai/privacy), Google 애널리틱스(사용 시) | 웹사이트 방문 및 기술 정보 | 웹사이트 트래픽, 유입 경로, 성능 분석. |

Lumno가 합병, 양도되거나 새로운 관리자에게 넘어가는 경우, 인수자가 본 방침을 계속 따르도록 하거나 정보 처리 방식이 바뀌기 전에 다시 동의를 구합니다. 법령에 따르거나 권한 있는 기관의 적법한 요청이 있을 때 정보를 공개할 수 있으나, Lumno는 사용자의 개인정보를 보유하지 않으므로 일반적으로 웹사이트 분석 데이터에 한정됩니다.

## 8. 보관과 보관 기간

확장 프로그램은 브라우저의 `chrome.storage.local`, `chrome.storage.sync`, 세션 저장소, 그리고 확장 프로그램 전용 IndexedDB에 데이터를 저장합니다. 업로드한 바로가기 아이콘은 `chrome.storage.local`에, 사용자 지정 배경화면, WebDAV 구성, 앱 비밀번호, 복구용 백업은 IndexedDB에 저장됩니다.

| 데이터 | 보관 기간 |
| --- | --- |
| 로컬 설정, 이미지, 캐시, 검색 순위 데이터 | 확장 프로그램에서 삭제하거나, 브라우저에서 확장 프로그램 데이터를 지우거나, Lumno를 제거할 때까지. |
| 탭 전환기 썸네일 | 각각 최대 2시간. |
| 브라우저 동기화의 설정 | 브라우저 계정과 동기화 설정에 따라 브라우저 제공 업체가 보관하고 삭제합니다. |
| WebDAV 서버의 파일 | 사용자가 삭제할 때까지 서버에 남습니다. 동기화 일시 중지, 연결 해제, Lumno 제거로는 삭제되지 않습니다. |
| 내보낸 설정 파일 | 사용자가 직접 보관하고 삭제합니다. |
| 제3자 서비스와 웹사이트 분석 데이터 | 각 서비스가 자체 정책에 따라 보관합니다. |

Lumno가 관리하는 어떤 시스템에도 사용자의 개인정보는 보관되지 않습니다.

## 9. 사용자의 권리와 선택

사용자는 다음을 할 수 있습니다.

- 가입이나 로그인 없이 Lumno의 모든 기능 사용.
- 설정에서 검색 엔진, AI 서비스, 아이콘 출처 변경. 선택 텍스트 빠른 작업, 오늘의 문장, 온라인 배경화면, 업데이트 알림 등의 기능 끄기.
- WebDAV 동기화 사용 여부 선택, 언제든 연결 일시 중지 또는 해제.
- 브라우저에서 확장 프로그램 동기화를 꺼서 설정을 한 기기에만 유지.
- 확장 프로그램에서 데이터를 삭제하거나, 브라우저에서 확장 프로그램 데이터를 지우거나, 확장 프로그램을 제거해 로컬 데이터 모두 삭제.

Lumno는 사용자의 개인정보를 보유하지 않으므로, 보통 Lumno 쪽에서 열람, 복사, 삭제할 데이터가 없습니다. 열람, 이동, 정정, 삭제, 동의 철회, 처리 제한, 처리 정지 요구 등 관련 법령에 따른 권리를 행사하거나 웹사이트 분석에 관해 문의하려면 제15조의 연락처로 연락해 주세요. 본인 확인 후 15영업일 이내 또는 관련 법령이 정한 기간 내에 답변합니다. 거주 지역의 개인정보 보호 기관에 민원을 제기할 수도 있습니다. 이러한 권리를 행사했다는 이유로 불이익을 받지 않습니다.

Lumno는 사용자를 프로파일링하거나, 법적 효력 또는 이에 준하는 중대한 영향을 미치는 자동화된 결정을 하지 않습니다.

## 10. 보안

다음 조치로 데이터를 보호합니다.

- 방문 데이터는 브라우저 안에서만 처리하며 개발자에게 전송하지 않습니다.
- WebDAV는 HTTPS 주소만 허용하고, 인증서 검증을 유지하며, 인증 리디렉션을 거부합니다.
- WebDAV 앱 비밀번호는 현재 기기의 확장 프로그램 전용 저장소에 보관되며, 브라우저 동기화에 포함되지 않고 웹페이지나 콘텐츠 스크립트에 노출되지 않습니다.
- 웹사이트 아이콘과 배경화면 다운로드에는 쿠키나 리퍼러가 포함되지 않습니다.

Lumno 전용 WebDAV 앱 비밀번호를 따로 만들고, 기기, 브라우저 계정, WebDAV 계정을 안전하게 관리하시길 권장합니다. 완벽하게 안전한 전송·저장 방식은 없습니다. 보안 문제를 발견하면 [i@kubai.design](mailto:i@kubai.design)으로 알려 주세요.

## 11. 아동

Lumno는 일반 사용자를 대상으로 하며 아동을 위해 설계되지 않았고, 아동의 개인정보를 고의로 수집하지 않습니다. 만 14세 미만은 보호자의 동의와 지도 아래 Lumno를 사용해야 합니다. 아동의 정보가 실수로 처리되었다고 생각되면 확인할 수 있도록 연락해 주세요.

## 12. 국외 처리

Lumno는 사용자 데이터를 저장하는 서버를 운영하지 않으므로, 사용자의 데이터가 Lumno가 관리하는 시스템으로 이전되지 않습니다. 브라우저 제공 업체, 사용자가 고른 검색·AI·WebDAV·이미지 서비스, GitHub, VibeLoft, Google 애널리틱스는 각자의 개인정보처리방침과 이전 메커니즘에 따라 사용자의 국가나 지역 밖에서 데이터를 처리할 수 있습니다.

## 13. Chrome 웹 스토어 사용자 데이터 정책

Lumno가 브라우저 API로부터 받은 정보를 사용하는 방식은 **제한적 사용**(Limited Use) 요건을 포함한 [Chrome 웹 스토어 사용자 데이터 정책](https://developer.chrome.com/docs/webstore/program-policies/policies)을 준수합니다.

- 데이터는 확장 프로그램의 단일하고 사용자에게 드러나는 목적을 제공하거나 개선하는 데만 사용합니다.
- 데이터는 사용자가 시작한 작업을 완료하는 데 필요한 경우에만 제4조에 나열된 서비스로 전송합니다.
- 데이터를 제3자에게 판매하거나 이전하지 않고, 맞춤형 광고에 사용하지 않으며, 신용도 판단이나 대출 목적으로 사용하지 않습니다.
- 개발자는 사용자의 방문 데이터나 설정에 접근할 수 없습니다.

## 14. 본 방침의 변경

계정이나 클라우드 기능을 다시 도입하는 등 Lumno가 새로운 데이터 유형, 목적, 수신자를 추가하는 경우, 변경이 적용되기 전에 본 방침과 스토어의 데이터 공개 내용을 업데이트하고 확장 프로그램에서 눈에 띄게 알립니다. 법령상 동의가 필요하면 다시 동의를 구합니다. 사용자의 권리를 줄이지 않는 문구 수정, 링크 업데이트, 설명 보완은 이 페이지의 날짜만 바꿀 수 있습니다. 사용자의 동의 없이 본 방침에 따른 권리를 줄이지 않습니다.
