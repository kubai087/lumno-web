## 2. 先看结论

- **浏览器数据留在本机。** 标签页、浏览历史、书签、常用网站和网页内容只在你的浏览器中读取和处理，不会发送给 Lumno。
- **没有账号，也没有使用统计。** Lumno 没有自己的账号系统和数据服务器，扩展不上报使用次数、行为或设备信息。
- **同步走你选择的通道。** 设置默认通过浏览器自带的同步保存；你也可以连接自己的 WebDAV 服务器，同步完整配置、快捷方式图标和自定义壁纸，或导出配置文件自行保管。
- **你发起的联网操作会交给对应服务。** 搜索建议、网页搜索、AI 或站内搜索、选中文字快捷操作、网站图标、在线壁纸和每日一言，会把完成该操作所需的数据直接发送给你选择或请求的第三方。
- **Lumno 不出售用户数据。** Lumno 不使用浏览活动进行个性化广告、跨场景行为广告、信用评估或放贷。

## 3. 本机数据、存储与浏览器权限

### 本机处理的数据

为提供明确展示在界面中的功能，Lumno 可能在本机读取或保存：

- 已打开标签页的网址、标题、分组与图标，用于搜索、排序、切换、恢复和管理标签页；
- 浏览历史中的网址、标题和访问时间，用于本地搜索、排序和删除用户指定的历史条目；
- 书签的文件夹结构、名称和网址，用于搜索、展示和用户发起的书签管理；
- 常用网站的网址和标题，用于新标签页展示；
- 当前网页中与快捷键、命令浮层、用户所选文字和可选画中画功能有关的内容；
- 搜索输入、用户选择过的本地结果及其网址和标题，用于在设备上优化结果排序；
- 主题、语言、布局、快捷方式、搜索提供商、黑名单、功能开关等设置，以及自定义壁纸、快捷方式图标、缩略图和轻量缓存。

Lumno 不会把上述浏览历史、书签树、标签页列表、网页内容或本地搜索排序记录发送给 Lumno 或开发者。第 4 节列出的联网操作，只会把完成该操作所需的数据发送给对应服务。

### 存储位置

Lumno 使用 `chrome.storage.local`、`chrome.storage.sync`、可用时的会话级扩展存储和扩展来源专用的 IndexedDB。自定义壁纸、快捷方式图标、WebDAV 同步所需的本机配置与恢复备份保存在 IndexedDB；WebDAV 应用密码也只保存在这里，不进入浏览器同步。`chrome.storage.sync` 由浏览器厂商提供，其同步行为见第 4 节。

### 权限为什么需要

| 权限 | 用途 |
| --- | --- |
| `tabs`、`tabGroups` | 查询、切换、创建、更新、分组和恢复标签页。 |
| `history` | 在本机搜索、排序及按你的操作删除历史条目。 |
| `bookmarks`、`topSites` | 搜索与管理书签，并展示常用网站。 |
| `storage`、`unlimitedStorage` | 保存设置、缓存和自定义图片，以及 WebDAV 同步所需的本机配置和恢复备份，不受浏览器同步的容量上限约束。 |
| `alarms` | 定期检查 WebDAV 服务器上的配置，在后台停止后重新触发同步。 |
| `search` | 把你提交的查询交给浏览器默认搜索功能。 |
| `favicon` | 通过浏览器能力显示网站图标。 |
| `scripting`、`<all_urls>` | 在网页中提供命令浮层、快捷键、选中文字操作和可选画中画功能，获取网站图标，从你粘贴的图片链接导入壁纸，并访问你配置的 HTTPS WebDAV 地址。广泛的网站访问权限不代表 Lumno 会批量收集或上传网页内容。 |

## 4. 哪些数据会离开你的设备

### 你主动使用的搜索、AI 与图标请求

- **在线搜索建议：** 输入的查询词会直接发送到当前搜索引擎的建议接口，例如 Google、Bing、Baidu、Sogou、360、DuckDuckGo、Yandex、Quark、Shenma 或 Yahoo。
- **网页搜索与站内搜索：** 你提交的查询词会发送给浏览器默认搜索引擎、你选择的搜索引擎或站内搜索服务。
- **AI 搜索与选中文字快捷操作：** 只有在你选择相应操作后，查询词、你选择的文字以及 Lumno 为该操作添加的提示词才会被填入或发送到你选择的 AI / 搜索服务，例如 ChatGPT、Gemini、DeepSeek 或你配置的其他服务。相关服务按照其自己的隐私政策处理这些内容。
- **网站图标：** 获取第三方图标时，Google / gstatic 图标服务会收到目标页面网址；你选择 Favicon.is 时，只向其发送目标域名。请求不携带 Cookie 或来源页 Referer，取得的图片保存在本机。

### 在线壁纸与每日一言

- **每日一言：** 默认关闭。开启后，Lumno 向一言（`v1.hitokoto.cn`）获取所选分类的公开语句，并按天缓存在本机。
- **Bing 壁纸：** 选择 Bing 来源或每日壁纸后，Lumno 向 `www.bing.com` 获取壁纸信息和图片，请求只包含语言市场和图片标识。
- **精选与艺术壁纸：** 选择精选来源后，Lumno 向 `picsum.photos`（Lorem Picsum，图片来自 Unsplash）获取图片；艺术分类向克利夫兰艺术博物馆开放获取图库（`openaccess-cdn.clevelandart.org`）获取图片。请求只包含图片编号和尺寸。
- **图片链接：** 你粘贴图片链接作为壁纸后，链接地址会随配置同步，每台设备向该链接请求一次图片，压缩后缓存在本机。

这些请求不携带 Cookie、来源页 Referer、浏览记录、书签或搜索词；接收方会看到正常网络请求的 IP 地址。

上述搜索、AI、图标和壁纸请求都由扩展直接发送给对应第三方，不经过 Lumno。你可以通过不使用相应功能、切换提供商或使用扩展中的请求黑名单来减少这些请求。

### 配置同步

Lumno 不提供云端同步，配置只通过以下你选择的方式在设备之间传递：

- **浏览器内置同步：** 主题、搜索提供商、快捷方式、黑名单和新标签页布局等设置保存在 `chrome.storage.sync`，由浏览器厂商按你的浏览器账号和同步设置在设备之间同步，适用浏览器厂商的隐私政策。自定义壁纸和上传的图标不进入浏览器同步。
- **WebDAV 同步（可选）：** 默认关闭，需要你自己添加服务器后才会开启，可同时连接多个服务器。开启后，完整配置（包括你填写的快捷方式标题与网址、搜索模板和黑名单规则）、上传的快捷方式图标和自定义壁纸，以及覆盖前的配置快照，会通过 HTTPS 保存到你指定的服务器和目录。服务器地址、目录和用户名会通过浏览器内置同步传到你的其他设备，方便重新连接；应用密码只保存在当前设备。浏览历史、书签数据库、当前标签页和网站图标缓存不会上传。
- **导出与导入：** 你可以把配置导出为 JSON 文件，自行保存或在其他设备导入。导出文件不包含图片。

WebDAV 数据只发送到你选择的服务器，不经过 Lumno。WebDAV 不提供端到端加密，该服务器的管理员可以读取这些配置和图片；文件的保存、备份和删除由该服务及其政策决定。

### 官网访问统计

Lumno 官网的公开页面会加载 VibeLoft 访问统计脚本，并可能在部署时启用 Google Analytics。这些服务可能处理页面地址和标题、访问时间、来源页面、点击事件、浏览器语言、设备与浏览器类型、粗粒度位置、IP 地址和请求日志，以及 Cookie 或其他假名标识。Lumno 用这些数据了解公开页面的访问量、性能和入口，不把它们与扩展中的任何数据关联；扩展本身不加载这些脚本。

你可以使用浏览器的 Cookie、脚本或跟踪保护功能阻止官网统计；这不会影响扩展的任何功能。

## 5. 使用目的、处理依据与接收方

Lumno 只在以下目的所必需的范围内处理数据：在你的设备上提供你使用的浏览器功能；执行你发起的搜索、AI、图标和壁纸请求；按你的选择同步配置；了解官网访问情况；履行法律义务。根据你所在地区，处理依据可能包括提供你所请求服务的必要性、你可随时撤回的同意、了解官网访问情况的合法利益，以及法律义务。

| 接收方 | 可能处理的数据 | 目的 |
| --- | --- | --- |
| 浏览器厂商 | `chrome.storage.sync` 中的设置、WebDAV 服务器地址、目录和用户名，以及浏览器账号相关元数据 | 提供浏览器自带的扩展设置同步。 |
| 你配置的 WebDAV 服务（如坚果云、NAS 或自建服务器） | 完整配置、快捷方式图标、自定义壁纸、配置快照，以及用于认证的用户名和应用密码 | 按你的设置在设备和浏览器之间同步配置与图片。 |
| 你选择的搜索、AI、网站或 favicon 服务 | 查询词、所选文字、提示词、请求网址或域名及网络元数据 | 完成你主动发起的搜索、AI、网页访问或图标请求。 |
| 一言、Bing、Lorem Picsum、克利夫兰艺术博物馆 | 所选分类、语言市场、图片编号与尺寸，以及 IP 地址 | 提供你开启的每日一言和在线壁纸。 |
| [VibeLoft](https://vibeloft.ai/privacy)、Google Analytics（如启用） | 官网访问和技术信息 | 公开页面的访问量、来源与性能分析。 |

上述服务商可能在你所在国家或地区以外处理数据。Lumno 不向数据经纪商或广告平台出售或提供用户数据，也不会为了与扩展单一用途无关的目的收集或转移浏览活动。

## 6. 保存期限与删除结果

| 数据 | 保存期限或确定标准 |
| --- | --- |
| 本机设置、图片、缓存和搜索排序记录 | 保留到你在扩展中删除、在浏览器中清除扩展数据或卸载 Lumno。 |

Lumno 没有账号和云端数据库，不在任何 Lumno 控制的系统中保存你的个人数据。卸载扩展会清除本机数据；浏览器同步副本和 WebDAV 服务器上的文件需分别在浏览器设置和服务器中删除。

你可以：

由于 Lumno 不保存你的个人信息，通常没有可供访问、导出或删除的 Lumno 端数据。如果你对官网统计或本政策有疑问，或希望在适用法律规定的范围内行使访问、更正、删除、限制或反对处理等权利，请发送邮件至 [i@kubai.design](mailto:i@kubai.design)；Lumno 会按适用法律要求的期限回复。你也可以向有管辖权的隐私监管机构投诉，行使隐私权不会导致歧视性待遇。

Lumno 不使用个人信息作出对你产生法律或类似重大影响的自动化决定，也不进行此类画像。

## 8. 安全措施与责任边界

扩展在你的浏览器内处理数据，不把浏览数据交给 Lumno。WebDAV 只接受 HTTPS 地址，保留证书校验并拒绝认证跳转；应用密码保存在扩展来源专用的 IndexedDB 中，不进入浏览器同步，也不向普通网页或内容脚本开放。建议为 Lumno 单独生成应用密码，而不是使用服务的登录密码。

这些措施用于降低未经授权访问、篡改或泄露的风险，但任何网络传输、设备或存储系统都无法保证绝对安全。请保护浏览器账号、设备和 WebDAV 账号；如发现安全问题，请联系 [i@kubai.design](mailto:i@kubai.design)。

当你主动把查询词、所选文字或配置交给搜索、AI、WebDAV 或其他第三方时，其处理受该第三方的隐私政策和安全措施约束。第三方服务的可用性和政策可能变化；本说明不排除任何不可放弃的法定权利。

## 9. 跨境处理与儿童

Lumno 不运营存放用户数据的服务器，因此不会把你的数据传输到 Lumno 控制的系统。浏览器厂商、你选择的 WebDAV、搜索、AI 和图片服务，以及 VibeLoft 和 Google Analytics，可能在其他国家或地区处理数据，适用各自的政策和传输机制。

Lumno 面向一般用户，并非专为儿童设计，也不会有意收集儿童的个人信息。如果你对此有疑问，请联系我们核查。

## 10. 数据转移限制、Chrome Limited Use 与政策变更

Lumno 不出售、出租用户数据，也不将其用于个性化广告、跨场景行为广告、信用评估、放贷或其他与扩展核心功能无关的用途。扩展只在完成你发起的操作时，把必需的数据直接发送给第 4 节列出的对应服务。

如果 Lumno 新增数据类别、用途或接收方，例如重新提供账号或云端功能，会先更新本政策和应用商店披露，并按照 Chrome Web Store 规则在产品中显著说明；适用法律要求时会重新取得同意。仅有文字整理、链接更新或不减少用户权利的澄清，可能只更新页面日期。建议你在版本升级后查看本页；重大变更不会追溯授权此前未披露的处理。
