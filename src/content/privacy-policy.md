## 2. 我们如何处理信息

Lumno 的核心功能在你的浏览器内运行。为提供你在界面中看到并主动使用的功能，扩展会在本机读取或保存以下信息。**除第 4 节所列情形外，这些信息不会离开你的设备，也不会发送给 Lumno 或开发者。**

### 2.1 浏览器数据

- **标签页：** 网址、标题、分组和图标，用于搜索、切换、排序、恢复和管理标签页。使用标签切换器时，扩展会截取当前标签页的画面作为缩略图，最多保留 12 张、每张不超过 2 小时，只保存在本机。
- **浏览历史：** 网址、标题和访问时间，用于本机搜索与排序，以及按你的操作删除指定条目。
- **书签：** 文件夹结构、名称和网址，用于搜索、展示和你发起的书签管理。
- **常用网站：** 网址和标题，用于在新标签页展示；你固定或隐藏的网站卡片会作为设置保存。

### 2.2 网页内容

- **快捷键与命令浮层：** 在网页中监听 Lumno 快捷键并显示命令浮层。
- **选中文字快捷操作：** 默认关闭。开启后，扩展读取你选中的文字（最多 2,400 个字符），仅在你选择某个操作时使用。
- **自动画中画：** 在受支持的视频网站上识别页面中的视频元素，用于开启画中画。
- **进度追踪（实验功能）：** 仅对你标记追踪的网站卡片生效，读取页面中的上一集 / 下一集链接、结构化数据和媒体信息，用于更新该卡片的网址和标题。

### 2.3 搜索与设置

- **搜索记录：** 你输入的搜索词，以及你选择过的结果的网址和标题，用于在本机优化结果排序。
- **设置与媒体：** 主题、语言、布局、快捷方式、搜索提供商、黑名单、功能开关等设置，以及你上传的快捷方式图标、自定义壁纸和必要的缓存。

### 2.4 我们不收集的信息

Lumno 不要求注册或登录，不收集你的姓名、邮箱、电话、地址等身份信息，不上报使用次数、点击行为、设备标识或崩溃信息，也不以任何方式把你的浏览历史、书签、标签页列表或网页内容发送给开发者。

## 3. 浏览器权限的用途

扩展只申请提供上述功能所需的权限，不申请可选权限：

| 权限 | 用途 |
| --- | --- |

| `history` | 在本机搜索、排序历史记录，并按你的操作删除条目。 |
| `bookmarks` | 搜索、展示和管理书签。 |
| `topSites` | 在新标签页展示常用网站。 |

| `alarms` | 在后台定期检查 WebDAV 同步状态。 |
| `search` | 把你提交的查询交给浏览器默认搜索引擎。 |
| `favicon`（仅 Chromium 版） | 通过浏览器能力显示网站图标。 |
| `sessions`（仅 Firefox 版） | 新标签页为把焦点交给搜索框而重新打开时，把被替换的标签页从「最近关闭」中移除。 |

广泛的网站访问权限仅用于上述功能，不代表 Lumno 会批量读取、收集或上传网页内容。

## 4. 会离开你设备的数据

以下请求由扩展直接发送给对应的第三方服务，**不经过 Lumno 的服务器**。接收方会同时看到网络请求通常包含的 IP 地址和浏览器信息，并按其自己的隐私政策处理。

### 4.1 在线搜索建议

当你在 Lumno 的搜索框（新标签页或命令浮层）中输入时，输入内容会实时发送到当前搜索引擎的搜索建议接口，用于显示联想词。支持的服务包括 Google、Bing、百度、搜狗（由腾讯的 `sor.html5.qq.com` 提供）、DuckDuckGo、Yandex、夸克与神马（`sugs.m.sm.cn`）以及 Yahoo。你可以在设置中更换搜索引擎来改变接收方。

### 4.2 网页搜索、站内搜索与 AI

- **网页搜索与站内搜索：** 你提交的查询会交给浏览器默认搜索引擎，或在新标签页中打开你选择的搜索服务或网站。
- **AI 搜索与选中文字快捷操作：** 只有在你选择相应操作后，扩展才会打开你选择的 AI 服务页面（例如 ChatGPT、Gemini、DeepSeek、豆包、Kimi 等），并把你的查询或所选文字连同 Lumno 为该操作生成的提示词填入页面。

这些操作等同于你直接访问对应网站：该网站会收到你提交的内容，并可能关联你在该网站上的登录状态。

### 4.3 网站图标

获取网站图标时，Google 图标服务（`www.google.com` / `gstatic`）会收到目标页面的网址；如果你选择 Favicon.is，则只发送目标域名。这些请求不携带 Cookie 和来源页信息（Referer），获取的图标缓存在本机。你为快捷方式设置的自定义图标地址，会由浏览器直接从该地址加载。

### 4.4 在线壁纸与每日一言

- **每日一言：** 默认关闭。开启后，扩展向一言（`v1.hitokoto.cn`）获取所选分类的语句，并按天缓存在本机。
- **Bing 壁纸：** 向 `www.bing.com` 获取壁纸信息和图片，请求只包含语言地区和图片标识。
- **精选与艺术壁纸：** 照片来自 Lorem Picsum（`picsum.photos`，图片源自 Unsplash），艺术作品来自克利夫兰艺术博物馆开放馆藏（`openaccess-cdn.clevelandart.org`），请求只包含图片编号和尺寸。
- **图片链接壁纸：** 你粘贴的图片链接会随设置同步，每台设备向该地址请求一次图片，并压缩后缓存在本机。

下载壁纸和每日一言时，请求不携带 Cookie 和来源页信息；壁纸选择面板中的预览缩略图按普通网页图片加载。

### 4.5 更新说明与官网资源

- **更新提示：** 扩展更新后，会向 GitHub（`api.github.com`，必要时为 `github.com`）请求该版本的发布标题，用于显示更新提示。你可以在设置中关闭“更新提示”。
- **近期更新页：** 扩展更新后可能打开官网的近期更新页，网址中包含来源、更新原因和扩展版本号；该页面适用第 6 节的官网统计。
- **反馈入口：** 打开反馈或社区入口时，扩展会从官网获取社区链接配置（`community-links.json`）和社群二维码图片。
- **帮助中心搜索：** 在“Lumno 帮助中心”站内搜索中输入时，扩展会从官网下载当前界面语言的帮助中心搜索索引（`search-index.json`），在本机匹配结果，并缓存最多 10 分钟。你输入的内容不会发送给官网。

官网托管在 GitHub Pages，GitHub 作为托管服务商可能记录访问请求的 IP 地址等日志。

## 5. 配置同步

Lumno 不提供云端同步。你的配置只通过以下由你选择的方式在设备之间传递：

- **浏览器内置同步：** 主题、搜索提供商、快捷方式（标题和网址）、固定或隐藏的网站卡片（网址和标题）、黑名单规则、壁纸选择与图片链接、每日一言偏好，以及 WebDAV 服务器地址、目录和用户名，保存在 `chrome.storage.sync` 中，由浏览器厂商按你的浏览器账号和同步设置在设备之间同步。上传的图标、自定义壁纸和 WebDAV 应用密码不会进入浏览器同步。
- **WebDAV 同步（可选）：** 默认关闭，需要你自行添加服务器后才会开启。开启后，完整配置、上传的快捷方式图标、自定义壁纸以及覆盖前的配置快照，会通过 HTTPS 保存到你指定的服务器和目录。浏览历史、书签、当前标签页和网站图标缓存不会上传。WebDAV 不提供端到端加密，该服务器的管理员可以读取这些文件。
- **导出与导入：** 你可以把配置导出为 JSON 文件，自行保存或在其他设备导入。导出文件不包含图片。

## 6. 官网访问统计与 Cookie

官网公开页面会加载 VibeLoft 访问统计脚本，并可能在部署时启用 Google Analytics（已开启 IP 匿名化）。这些服务可能处理页面地址（包括网址参数）和标题、访问时间、来源页面、点击事件、浏览器语言、设备与浏览器类型、粗略位置、IP 地址，以及 Cookie 或类似的假名标识。

我们仅将这些数据用于了解官网的访问量、来源和性能，不会将其与扩展中的任何数据关联。扩展本身不加载这些脚本。你可以使用浏览器的 Cookie、脚本拦截或防跟踪功能阻止官网统计，这不会影响扩展的任何功能。

## 8. 存储位置与保存期限

扩展使用浏览器提供的 `chrome.storage.local`、`chrome.storage.sync`、会话存储，以及扩展专属的 IndexedDB 保存数据：上传的快捷方式图标保存在 `chrome.storage.local`；自定义壁纸、WebDAV 配置、应用密码和恢复备份保存在 IndexedDB。

| 数据 | 保存期限 |
| --- | --- |
| 本机设置、图片、缓存和搜索排序记录 | 直到你在扩展中删除、在浏览器中清除扩展数据，或卸载 Lumno。 |
| 标签切换器缩略图 | 每张最多保留 2 小时。 |
| 浏览器同步中的设置 | 由浏览器厂商按你的浏览器账号和同步设置保存与删除。 |
| WebDAV 服务器上的文件 | 保存在你的服务器上，直到你自行删除。暂停同步、删除连接或卸载 Lumno 都不会删除服务器文件。 |
| 导出的配置文件 | 由你自行保存和删除。 |
| 第三方服务和官网统计数据 | 由对应服务按其政策保存。 |

Lumno 不在任何由 Lumno 控制的系统中保存你的个人信息。

## 9. 你的权利与选择

你可以：

- 无需注册或登录即可使用 Lumno 的全部功能；
- 在设置中更换搜索引擎、AI 服务和图标来源，或关闭选中文字快捷操作、每日一言、在线壁纸、更新提示等功能；

Lumno 不会基于你的个人信息进行画像，也不会作出对你产生法律影响或类似重大影响的自动化决策。

## 10. 数据安全

我们采取以下措施保护你的数据：

- 浏览数据只在你的浏览器内处理，不传给开发者；
- WebDAV 只接受 HTTPS 地址，保留证书校验并拒绝认证跳转；
- WebDAV 应用密码只保存在当前设备的扩展专属存储中，不进入浏览器同步，也不向网页或内容脚本开放；
- 网站图标和壁纸下载请求不携带 Cookie 和来源页信息。

建议你为 Lumno 单独生成 WebDAV 应用密码，并妥善保护设备、浏览器账号和 WebDAV 账号。任何网络传输和存储方式都无法保证绝对安全；如果你发现安全问题，请通过 [i@kubai.design](mailto:i@kubai.design) 告知我们。

## 11. 未成年人保护

Lumno 面向一般用户，并非专为未成年人设计，也不会有意收集未成年人的个人信息。不满 14 周岁的未成年人应在监护人的同意和指导下使用。如果你认为我们误处理了未成年人的信息，请联系我们核实。

## 12. 跨境处理

Lumno 不运营存放用户数据的服务器，因此不会把你的数据传输到由 Lumno 控制的系统。浏览器厂商、你选择的搜索、AI、WebDAV 与图片服务，以及 GitHub、VibeLoft 和 Google Analytics，可能在你所在国家或地区以外处理数据，并适用各自的隐私政策和数据传输机制。

## 13. 应用商店用户数据政策

Lumno 对从浏览器 API 获取的信息的使用，遵守 [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies)，包括其中的 **Limited Use**（有限使用）要求：

- 仅为提供或改进扩展面向用户的单一用途功能而使用这些数据；
- 仅在完成你发起的操作时，把必需的数据发送给第 4 节所列的服务；
- 不将这些数据出售、转让给第三方，不用于个性化广告，不用于确定信用资质或放贷；

Firefox 版同样遵守 Mozilla 的[附加组件政策](https://extensionworkshop.com/documentation/publish/add-on-policies/)：只传输功能所需的数据，且只把这些数据用于传输时的用途。
