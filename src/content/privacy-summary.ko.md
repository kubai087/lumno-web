## 요약

Lumno에는 계정 시스템도, 사용자 데이터를 저장하는 서버도 없습니다. 탭, 북마크, 방문 기록은 사용자의 브라우저 안에서만 처리되며 Lumno 측으로 전송되지 않습니다.

- 가입이나 로그인이 필요하지 않습니다. Lumno는 이름이나 이메일 주소를 수집하지 않으며, 사용 횟수, 클릭, 기기 식별자, 오류 정보도 전송하지 않습니다.
- 테마, 바로가기, 배경화면 선택 등의 설정은 브라우저 계정을 통해 동기화됩니다. WebDAV 동기화는 기본적으로 꺼져 있으며, 켜면 전체 설정, 직접 올린 아이콘과 배경화면이 지정한 서버에 저장됩니다. 방문 기록, 북마크, 탭은 업로드되지 않습니다.
- 이 웹사이트는 방문자 수와 유입 경로를 파악하기 위해 분석 도구를 사용합니다. 이는 확장 프로그램과는 별개이며, 확장 프로그램은 분석 스크립트를 전혀 불러오지 않습니다.

다음 요청은 확장 프로그램에서 해당 서비스로 직접 전송되며, Lumno 측을 거치지 않습니다.

| 요청 | 받는 곳 | 전송 시점 |
| --- | --- | --- |
| 추천 검색어 | 사용 중인 검색 엔진(Google, Bing 등) | Lumno 검색창에 입력할 때 |
| 검색과 AI 질문 | 사용자가 선택한 사이트 또는 AI | Return 키를 누를 때 |
| 사이트 아이콘 | Google 파비콘 서비스 또는 Favicon.is | 사이트 아이콘을 표시할 때 |
| 배경화면 | Bing, Lorem Picsum, 클리블랜드 미술관 | 온라인 배경화면을 사용할 때 |
| 업데이트 안내 | GitHub | 확장 프로그램이 업데이트된 후 |

이 요약은 이해를 돕기 위한 것이며, 아래의 전체 조항이 우선합니다.
